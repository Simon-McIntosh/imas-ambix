§1 — Objective & scope

Build the shared hybrid latent and its two physics anchors:

  • Hybrid latent. An anchored block supervised only on genuinely raw measured quantities (Ip from the Rogowski coil, coil currents, line-averaged density, raw field magnitudes) and carrying a poloidal-flux ψ representation; a free block for the closure physics; both in dimensionless coordinates.
  • Spatial anchor — GS observation operator (§8). Our EFIT-free Grad-Shafranov Green's-function operator (gs/operator.py) maps latent ψ → predicted magnetics at the (freely-known) sensor locations; trained to match the raw measured magnetics. The boundary / X-point / magnetic axis are readouts of ψ (geometric features), never supervised labels.
  • Temporal anchor — transport + irreversibility (§7a). A soft, learned-closure flux/current-diffusion prior on ∂ψ/∂t (η∥ and non-inductive sources learned; the command enters via the loop-voltage / current-drive source term), plus sign/inequality constraints that encode the arrow of time: η∥ > 0 ⇒ D ≥ 0 (parabolic, forward-well-posed), non-negative resistive dissipation, and the Volt-second / flux budget. Guard-rails, not rails — they forbid the unphysical and prescribe no trajectory, so they cannot over-constrain. Builds on the learned-closure-current-diffusion-v0 ψ-diffusion filter (reused asset).

§2 — The gate (verifiable done-when)

  1. Hybrid latent + GS operator wired; anchored block supervised on raw scalars; the ψ readout produces boundary / X-point with no EFIT labels.
  2. From raw magnetics, the GS-readout axis / X-point / boundary skill matches the absolute-magnetics oracle (~0.5–0.7) — report per-quantity.
  3. Transport anchor wired: learned diffusivity verified D ≥ 0 (strictly positive); dissipation-≥-0 + Volt-second-budget priors active and falsifiable (residuals monitored as discovery signals); a load-bearing test — zero the command source ⇒ the ψ evolution changes.
  4. Tests green; outcome recorded; plan collapsed to a landed summary.

§3 — Approach

  1. Encoder: tokens (absolute + geometry, from stage 1) → belief over the hybrid latent; anchored block regressed to raw scalars; ψ field representation in the latent.
  2. Wire gs/operator.py as a differentiable observation operator: latent ψ → magnetics at sensor locations; GS soft-prior residual loss against raw magnetics.
  3. Transport prior: a learned dissipative flux-diffusion term on ∂ψ/∂t (strictly-positive diffusivity via softplus/exp; learned non-inductive sources incl. the loop-voltage/current-drive command channel); add the dissipation-≥-0 and Volt-second-budget soft penalties.
  4. X-point / boundary readout: compute geometric features (off-axis saddle of ψ, LCFS) from the learned field; score against the firewalled absolute-magnetics oracle.

§4 — H200 footprint

Moderate. Latent encoder + GS operator (differentiable, modest cost) + transport-anchor development; the work is overfit/smoke-scale plus the GS-readout oracle eval — a few cards, not the full corpus run. Heavier than stage 1, lighter than stage 4. Per AGENTS.md §2a/§2b: in-process, SIGTERM-clean, resume-safe; keep DeepSeek up (no ~4-GPU run needed here).

§5 — Inherited decisions

Locked in the parent: latent-structure = hybrid-anchored-free; physics-scaffold = GS observation-operator grounding; temporal-transport-anchor = soft-learned flux-diffusion + sign constraints; firewall-definition = code-outputs-only. The open dimensionless-coordinate-set decision (learned-soft vs hard-imposed basis) is resolved here when the encoder is built — surface it, recommend learned-soft.
