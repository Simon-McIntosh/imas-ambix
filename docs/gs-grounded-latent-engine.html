§1 — Objective & scope

Build the shared hybrid latent and its two physics anchors:

  • Hybrid latent. An anchored block supervised only on genuinely raw measured quantities (Ip from the Rogowski coil, coil currents, line-averaged density, raw field magnitudes) and carrying a poloidal-flux ψ representation; a free block for the closure physics; both in dimensionless coordinates.
  • Spatial anchor — GS observation operator (§8). Our EFIT-free Grad-Shafranov Green's-function operator (gs/operator.py) maps latent ψ → predicted magnetics at the (freely-known) sensor locations; trained to match the raw measured magnetics. The boundary / X-point / magnetic axis are readouts of ψ (geometric features), never supervised labels.
  • Temporal anchor — transport + irreversibility (§7a). A soft, learned-closure flux/current-diffusion prior on ∂ψ/∂t (η∥ and non-inductive sources learned; the command enters via the loop-voltage / current-drive source term), plus sign/inequality constraints that encode the arrow of time: η∥ > 0 ⇒ D ≥ 0 (parabolic, forward-well-posed), non-negative resistive dissipation, and the Volt-second / flux budget. Guard-rails, not rails — they forbid the unphysical and prescribe no trajectory, so they cannot over-constrain. Builds on the learned-closure-current-diffusion-v0 ψ-diffusion filter (reused asset).

§3 — Approach

  1. Encoder: tokens (absolute + geometry, from stage 1) → belief over the hybrid latent; anchored block regressed to raw scalars; ψ field representation in the latent.
  2. Wire gs/operator.py as a differentiable observation operator: latent ψ → magnetics at sensor locations; GS soft-prior residual loss against raw magnetics.
  3. Transport prior: a learned dissipative flux-diffusion term on ∂ψ/∂t (strictly-positive diffusivity via softplus/exp; learned non-inductive sources incl. the loop-voltage/current-drive command channel); add the dissipation-≥-0 and Volt-second-budget soft penalties.
  4. Topology as a deterministic read of the solved ψ (not separate regression heads — see the locked decision below). Axis = O-point (ψ extremum); X-points = saddles (∇ψ = 0, indefinite Hessian); LCFS = the separatrix through the active null; public vs private = the contour-tree structure of ψ. Build our own routines steered by nova/biot/fieldnull.py (critical-point finding) and imas-efit src/EFIT/contour_tree.f90 (rigorous public/private separatrix structure); score against the firewalled absolute-magnetics oracle.

§3a — The public/private caveat (binding awareness)

The flux map is multimodal: a null can sit in a private flux region and “appear” inside the LCFS. The divertor topologies we must support are not limited to simple upper/lower single-null — double-null, snowflake, X-divertor, and super-X all put multiple comparable saddles in play. This is exactly why a sign-of-Z split or a naïve ψ-proximity filter is invalid, and why topology must come from the contour-tree structure of ψ (which distinguishes public from private by connectivity, not by height or proximity). We are aware of the hard case and read it correctly from ψ; we do not attempt to shortcut it with a heuristic filter.

Green's-function kernel source + how the GS solve enters training

The lead reviewed the solver construction (grid-cell currents assigned by a jφ(ψN) flux function inside the evolving LCFS, topology read every Picard iteration; soft GS residual unchanged as THE training prior) and the nova code (author: Simon McIntosh — content freely available): nova/biot carries a closed-form FINITE-AREA cylinder Biot-Savart formulation (cylinder.py/constants.py/zeta.py: elliptic-integral + arcsinh-zeta antiderivatives, corner-evaluated over rectangular cross-sections) and a Newton-Krylov forward free-boundary solve pattern (plasma.py::solve_flux). Point-filament Green's functions are log-singular at the source (the P1-4 defect; the 3x3-subdivision + 2cm nudge is a hack). Measured solver cost: 2.4s grid build per campaign, ~1.3s per solve (14 Picard iterations).

Locked by the lead 2026-07-02 ('lock the approach and start the extraction'). Finite-area sources are smooth by construction — the correct cure for the near-field singularity everywhere it appears; extraction keeps the decoder lean, machine-agnostic and torch-portable (ellipk/ellipe/arcsinh closed forms) without pinning nova's infrastructure; Newton-Krylov robustness targets the 48% masked-slice fraction; fit amortization keeps the solver forward-only (firewall-clean label-free targets derived purely from raw measurements), reserving implicit-diff for a later end-to-end upgrade if warranted. Nova's ITER machine description is additionally the transfer-stage asset.
