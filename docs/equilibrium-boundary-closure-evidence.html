Soft-prior interior solve — evidence

What this is. The §3 deliverable of equilibrium-boundary-closure: the landed source-free toroidal-harmonic annulus read is coupled back into the free-boundary Grad–Shafranov interior solve as a soft prior — never a fixed Dirichlet boundary. This document records what was built, the gauge measurement that fixed the penalty form, the held-out ablation-ladder numbers, and the poloidal flux maps against the firewalled EFIT reference (EFIT is referee/scoring only — never an input to any solve here).

§1 — What was built (all EFIT-firewalled, machine-agnostic)

  • Gauge-preserving harmonic read. The toroidal-harmonic read now exposes an analytic point-wise ∇ψ and an optional Ip-circulation gauge tie, and a frozen per-slice prior artifact (coeffs, coeff_cov, pole, dyn_range) pins it against editable-install drift.
  • Annulus boundary anchor (the load-bearing ingredient). A whitened ψ-consistency penalty ties the interior solve's plasma+passive ψ to the source-free harmonic ψ in the shared vacuum annulus. The coil field is identical on both sides and cancels (like-for-like flux). The penalty keeps the flux-loop gauge: absolute-ψ matching with a single fitted rank-1 offset DOF (see §2), robust-clipped for the read's heavy-tailed consistency, weighted by each slice's own fit uncertainty.
  • Soft SOL edge. A C¹ value-and-slope-matched decay foot admits public-SOL current through a smooth edge to ψN≈1.1 (axis-connected common-flux region only, private flux excluded), replacing the hard ψN<1 mask discontinuity.
  • Discovered profiles + regularisation. p′/FF′ are discovered by the per-sweep coefficient LSQ against the raw magnetics (not fixed analytic forms), with second-difference smoothness and monotonicity regularisers available.
  • q ≥ 1 sawtooth clamp. A soft one-sided bound jφ,axis ≤ 2Bφ0/(μ₀R₀) (⇔ q₀ ≥ 1), active-set (only when the iterate violates it).
  • Moment / pressure priors. An opt-in soft Ip prior, a βp+li/2 magnetics-derived moment-consistency prior, and a pressure-gradient prior that pulls the p′-family coefficients toward a target — the lever that breaks the p′/FF′ degeneracy.

§3.5 — The LCFS scoring-read correction (the load-bearing finding)

The ablation-ladder LCFS numbers above (−3.6 to −4.1; ~28–30 cm) are an artifact of the scoring read, not of the interior solve. The closure gate scored the interior LCFS with the historical innermost-X-point / limiter-contact read (geometry_target), which locks onto a discretisation-scale saddle and under-sizes the boundary by tens of cm — while §2 uses the LANDED outermost-axis-enclosing push-out reader (lcfs_contour).
