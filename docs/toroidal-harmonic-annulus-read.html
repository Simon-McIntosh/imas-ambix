§1 — Design (from the grounding review and thread-1 findings)

  • Representation: ψplasma(R,Z) expanded in the Δ*-eigenfunctions — half-integer-degree Legendre functions Pn−½, Qn−½ in toroidal coordinates about a suitable pole (Alladio–Crisanti 1986; Braams 1991; refs in equilibrium-topology-fidelity §11) — fitted by whitened least squares to measured − vacuum on the raw magnetics, with the known coil field added analytically.
  • Validity domain is the ANNULUS ONLY. Inside the plasma the expansion is meaningless and that is correct — the boundary/X-point/LCFS are read in the annulus; the axis and the confined-side flux reference come from the interior carrier. The review's design note is binding: the confined-side flux reference must NOT be taken from the harmonic field's own extremum (the failed hybrid pattern read axis_psi off the moment ψ).
  • Interior carrier (new, from the f-pcph-04 evidence): the calibrated R1+R2 patch arm (axis median 3.1–3.8 cm, X-point-set skill +0.14…+0.29) or the calibrated closure arm — whichever the force-balance-spine representation-default decision selects — supplies the axis and ψaxis. Apply the frozen offset-only static calibration to the payloads (--calibration static_calibration_offset_only.json); do not measure the harmonic fit against an instrument-error floor.
  • Consistency condition: patch-ψ (or closure-ψ) vs harmonic-ψ RMS agreement in the shared annulus — the checkable condition both representations must satisfy where both are valid (Gate C of the prior ladder).

§3 — Implementation architecture (frozen interface, refined 2026-07-14)

  • New module imas_ambix/latent/boundary_harmonic.py, beside boundary_moment.py. Fits the PLASMA-produced vacuum flux ψp(R,Z) in the annulus in source-free toroidal harmonics about a fixed pole (locked pole-and-truncation). The total field read for topology is ψtot = ψp(harmonic) + ψcoil, where the coil term is the harness's existing thick-cylinder Biot column (EquilibriumGrid._coil_psi_columns via hybrid_greens) — never a point-filament coil term (binding user directive 2026-07-14; the whole harness is already cylinder-sensors-v4).
  • Analytic sensor prediction. Each harmonic column contributes ψk to flux loops and the orientation-projected field (BRcosθ + BZsinθ) to B-probes, computed from the analytic ψk and its gradient. Sensor geometry (R, Z, angle, kind) comes from table.sensor_map, in the SAME row order as the payload's measured/vacuum vectors. The harmonic basis carries NO current on cells, so m_sens is not used (unlike the moment read) — the source-free premise is structural, not merely low-order.
  • Fit. Whitened least squares of the harmonic coefficients to the plasma sensor signature measured − vacuum on trusted rows, tiny ridge floor in a column-normalised frame. Ip enters as an optional (ablatable) virtual constraint — the poloidal-field circulation ∮B·dl = μ0Ip on a loop enclosing the plasma is a linear functional of the coefficients — mirroring the moment read's ip_anchor.
  • Hybrid read. Reuse hybrid_target(): the ray-cast AXIS comes from the calibrated interior carrier (patch arm, offset-only static calibration), boundary / X-point set / LCFS radii from ψtot. The confined-side flux reference is NEVER the harmonic field's own extremum (binding review note) — it comes from the carrier.
  • Gate script scripts/boundary_harmonic_gate_eval.py clones boundary_moment_gate_eval.py: reuses patch_gate_eval.score() (paired-bootstrap CIs, saddle-excess), shot_payloads(), the 160-slice held-out protocol; sweeps the harmonic order on train shots (CI-gated ladder), freezes, scores once held-out; records the vacuum-annulus consistency RMS (carrier-ψ vs harmonic-ψ in the shared annulus).

§ Decisions

Where does the toroidal-coordinate pole sit, and how is the harmonic order chosen?

Per-slice pole tracking a MAGNETICALLY-CONSTRAINED origin, placed a dimensionless FRACTION of the origin radius inboard (pole_r = origin_R*(1-0.41), pole_z = origin_Z; machine-agnostic, R/R0-scaled). ORIGIN = the Ip-anchored current CENTROID (moment fit), NOT the free-current patch carrier O-point: the flat-top-tuned carrier mislocates the axis ~30 cm outboard at ramp-up (Ip 21-66%), collapsing the boundary (LCFS 41-52 cm); the centroid tracks the plasma inboard and gives a robust boundary at ALL phases. Isolation test (origin = EFIT axis, diagnostic) proved the harmonic BOUNDARY read itself recovers ramp-up to 3-6 cm when correctly anchored — the failure was purely the origin. The centroid needs no interior carrier (pure external magnetics: Ip + moments -> centroid -> source-free boundary), removing the ~13-min patch inverse. Mask/exclude radii size-adaptive (fractions of pole-to-origin distance) so they never reach the axis as the plasma shrinks. Order 3, ridge 1e-8, fraction 0.41. Held-out (n=160): LCFS 6.8 cm all / 5.4 cm flat-top (nearly HALVED vs the carrier's 11.8/10.7), lcfs_skill -2.48, consistency 0.068; ramp-up LCFS 7-14 cm. Tradeoff: X-point-set -4.54 and axis -1.58 regress vs the carrier per-slice run (centroid sits inboard of the flux axis by the Shafranov shift; and the more-robust centroid now FINDS ramp-up X-points that get imperfectly matched where the carrier found none -> a scoring artifact). Flat-top X-points remain ~5 cm.

Does the fitted origin correction become this arm's frozen default, given it trades X-point-set skill for LCFS fidelity?

The train-fitted signed displacement (ΔR/R = −0.10338 inboard, ΔZ/R = +0.00232) recovers held-out LCFS median error 11.52 → 4.51 cm — the best this arm has recorded, past the 6.7 cm of 2026-07-14 — cuts the radial axis bias +0.0874 → −0.0098 m, improves axis skill −1.896 → −1.559 and LCFS skill −3.900 → −2.466, with the annulus-consistency guard holding at 0.0816. It costs X-point-set skill: +0.689 [0.309,0.773] → −2.719 [−4.575,+0.425]. The regression was tested for a matching-permutation artifact and is REAL: both scores were already computed by the permutation-invariant matched_xpoint_error, so the full 3.4085-point gap survives permutation-invariant matching. Neither option dominates.

Lead decision, on the precedent the locked pole-and-truncation decision already set: the centroid origin was adopted BECAUSE it halved the LCFS error even though X-point-set and axis both regressed against the carrier run, recorded at the time as the gate for progressing. The same weighting applies here, and the gain is larger — LCFS median error 11.52 → 4.51 cm is the best figure this arm has produced, and the radial axis bias falls from 8.7 cm to 1.0 cm, while the source-free premise is undisturbed (consistency 0.0850 → 0.0816). The X-point-set cost (+0.689 → −2.719) is accepted with its eyes open: it was confirmed real rather than a bookkeeping artifact, and it is concentrated in xpt0_R while the other X-point improves in both components (xpt1_R −1.874 → −0.126, xpt1_Z −15.42 → −7.23). Two residual caveats stay on the record: the ΔZ component does not transfer held-out (vertical bias −0.0411 → −0.0388 m), so the vertical residual is unaddressed; and this cohort has now been scored three times, so any further scored variant — including the split-axis option, which remains the live alternative if the X-point cost later proves binding — needs an untouched cohort.
