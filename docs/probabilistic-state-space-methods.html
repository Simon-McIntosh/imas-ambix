Probabilistic State-Space Methods & Fusion Precedents

Research survey informing physics-world-model-strategy and plasma-state-space-v0. Last updated: 2026-05-29. Verification status is noted inline: [✓] = primary source confirmed, [~] = secondary source / broadly confirmed, [?] = unverified / from training.

Scope. The imas-ambix objective has been reframed from a generative video model toward a learned probabilistic state-space model: an encoder that maps raw diagnostic measurements to a latent plasma state; a stochastic transition kernel that captures the dynamics (the physics to be discovered, not imposed); and an observation model that maps the latent state back to raw signals. This architecture supports Bayesian filtering/smoothing for state estimation, what-if forecasting, and structure discovery. Three binding principles shape every method choice:

  1. Physics as soft, falsifiable priors. A persistent physics residual is a discovery signal, not an error to fit away. Hard boundary conditions are banned.
  2. Train on raw measured signals only. Never on regression/solver outputs (e.g. not EFIT-reconstructed equilibrium — those carry solver assumptions). Grad-Shafranov enters as our own soft prior instead.
  3. Data-scarce / extrapolation-to-ITER regime. Data-efficiency and calibrated uncertainty for safe extrapolation dominate over peak in-distribution accuracy.

First concrete experiment. Predict plasma separatrix shape parameters (volume, elongation, triangularity, …) from raw diagnostic measurements including camera, with calibrated uncertainty. Everything in §§4–7 is assessed against this target.

1. Overview and Architecture

A probabilistic state-space model (PSSM) over a sequence of observations y1:T has three components:

  • Encoder / recognition model q(zt | y1:t): maps raw diagnostics to a distribution over latent plasma state zt.
  • Transition kernel p(zt+1 | zt): the learned dynamics — the thing we are most interested in discovering.
  • Observation model p(yt | zt): maps latent state back to measurements.

Inference in this model is Bayesian filtering (online, causal) or smoothing (offline, full-sequence). The posterior over zt is the "plasma state estimate with uncertainty". Forecasting means rolling out p(zt+k | zt) and pushing through the observation model. Structure discovery means reading off the learned transition kernel — ideally in interpretable coordinates (§5).

The key design choice is where on the deterministic–probabilistic spectrum to sit (§3), and how deep/nonlinear to make each component (§2). The fusion precedents (§6) clarify what has already been solved and what remains open.

Synthesis. The KVAE/DVBF/RKN family — which keeps explicit Gaussian beliefs updated by learned NN transitions — is the most natural starting point for a plasma PSSM. Latent SDE is the principled upgrade once the Gaussian assumption needs relaxing (e.g. for ELM bifurcations). Differentiable PFs remain the gold standard for non-Gaussian posteriors but are expensive. Classical KF/EnKF remain important as calibration baselines and as priors for the Grad-Shafranov residual.

3. The Uncertainty-Quantification Spectrum

"Probabilistic" is a means to an end — honest uncertainty for safe extrapolation and optimal data assimilation — not a commitment to full Bayes everywhere. The spectrum below runs from cheapest/least expressive to most expressive/most expensive. The data-scarce, extrapolation-to-ITER regime imposes a specific constraint set that narrows the recommended first cut considerably.

3.1 The Spectrum

Deterministic observer / point predictor
A single neural network (MLP, CNN, LSTM) trained with MSE. Zero uncertainty. Calibration is impossible by construction. Appropriate when: proof-of-concept only; never for safe extrapolation. For the separatrix experiment this is the "does learning work at all?" baseline, nothing more.
Monte-Carlo Dropout (MC-Dropout)
Gal & Ghahramani 2016 [~]. Dropout at test time provides a cheap approximate posterior. Well-known to be poorly calibrated in practice — uncertainty does not grow reliably OOD. Low implementation cost but unreliable for safety-critical UQ. Not recommended as a primary method; acceptable as a cheap sanity check.
Deep Ensembles
Lakshminarayanan, Pritzel, Blundell 2017 NeurIPS, arXiv:1612.01474 [✓]. Train M ≥ 5 independent networks with random initialisation + adversarial training. Ensemble disagreement estimates epistemic (model) uncertainty, which is exactly what grows at OOD inputs and toward ITER operating conditions. Empirically the best-calibrated method on regression benchmarks, beating MC-Dropout and Bayesian NNs (Lakshminarayanan et al. Table 1). Cost = M × single-model cost. Appropriate for data-scarce regimes because it captures model uncertainty without requiring a hand-specified prior over weights.
Conformal Prediction
Angelopoulos & Bates 2021 tutorial [~] (arXiv:2107.07511). Distribution-free coverage guarantee: given a calibration set and a nominal coverage level (1−α), the resulting prediction interval contains the true value with probability at least 1−α, for any exchangeable data. Requires only a scoring function — the base predictor can be any model (including a deep ensemble). Split conformal is a single model-fit step + calibration; computationally trivial. Key limitation: provides marginal (not conditional) coverage; does not provide a full predictive distribution; does not capture epistemic uncertainty beyond what the score function reflects. Appropriate as a calibration wrapper around any base model to guarantee the coverage numbers reported in the experiment.
Variational Inference / VAE-based PSSM
The latent SSM models in §2 (DKF, DVBF, RKN, KVAE, Latent SDE) all use variational inference with an ELBO objective. This provides a full predictive distribution, not just intervals. The posterior is approximate (factorised Gaussian in most cases). Training cost is moderate. Appropriate as the core dynamics model once the point-predictor baseline is established.
MCMC / Full Bayes
HMC, NUTS (Stan, NumPyro), or Stein VI. Asymptotically correct posterior; extremely expensive for neural network parameter spaces. Not appropriate as the primary method in a data-scarce NN context; may be relevant for small, interpretable models (e.g. a Gaussian process transition in a very low-dim latent space).

3.2 Recommended First Cut for imas-ambix (data-scarce regime)

Four constraints discriminate the methods above for the separatrix experiment:

  1. Data scarcity favours robust, cheap methods. Full MCMC and large ensembles are expensive; M=5 ensembles add only 5× training cost, which is acceptable.
  2. "Probabilistic is instrumental." We need epistemic uncertainty (grows OOD toward ITER) and a calibration guarantee — not a philosophically correct posterior. Full variational inference is not required at the first experiment stage.
  3. Extrapolation requires epistemic uncertainty. Conformal alone does not capture model uncertainty — it only redistributes the residuals of whatever model it wraps. Single-model conformal on a deterministic predictor will have narrow, overconfident intervals at OOD inputs. An ensemble base predictor is required before conformal provides meaningful extrapolation guarantees.
  4. Coverage guarantee is required to turn the first experiment into a publishable/deployable safety statement. Conformal delivers this distribution-free; no other method does at finite sample sizes.

Recommended first cut: Deep Ensemble (M=5) + Split Conformal wrapper.

  • The ensemble base model is trained on raw diagnostic signals → separatrix shape parameters (the deterministic point predictor, replicated M=5 times).
  • Ensemble variance provides epistemic uncertainty signal that grows at OOD (e.g. unusual plasma configurations or simulated ITER-scale conditions).
  • Conformal calibration on a held-out calibration set converts the ensemble score into prediction intervals with provable marginal coverage (e.g. 90%).
  • The full variational PSSM (DVBF or Latent SDE) is the principled next step — it handles temporal dependencies properly and captures the dynamics — but requires first knowing that the point-predictor task is learnable.

Path to the full PSSM. Once the ensemble baseline is established: (1) wrap in a KVAE or DVBF to add proper temporal state estimation; (2) replace Gaussian transitions with a Latent SDE if ELM / bifurcation behaviour needs non-Gaussian diffusion; (3) layer structure discovery (§5) onto the transition kernel. The full Bayesian smoother (EnKF or DPF) becomes relevant when we have a forward model to assimilate against (e.g. the Grad-Shafranov soft prior).

Recommended acceptance-criterion set for the first experiment:

  • Empirical PI coverage @ 90% ≥ 0.90 (with conformal guarantee).
  • PI width < 5% of the quantity's range for in-distribution shots (sharpness requirement — wide intervals trivially pass coverage).
  • CRPS lower than a Gaussian baseline trained on marginal statistics (i.e. the model adds value over "predict the mean with training-set variance").
  • Reliability diagram ECE < 0.05.
  • Ensemble disagreement positively correlated (Spearman ρ > 0.3) with absolute prediction error on a held-out OOD set (e.g. shots with unusual triangularity or near-L-H transition).

5. Structure and Equation Discovery on Latent Dynamics

Once a PSSM is trained, its learned transition kernel is a black box. The methods below aim to make it interpretable — ideally recovering dimensionless groups, conservation laws, or closed-form equations. This is the "physics residual as discovery signal" principle in action: if the model needs more than the Grad-Shafranov ansatz to explain the data, the excess is new structure.

Recommended discovery pipeline: (1) Train PSSM to convergence (§3). (2) Extract latent state trajectories z(t) over all shots. (3) Apply SINDy Autoencoder jointly on encoder + dynamics to search for a sparse ODE in the latent space — the Grad-Shafranov constraint enters here as a term in the candidate library. (4) Residuals that SINDy cannot explain are flagged as novel structure for symbolic regression (PySR). (5) Check whether discovered conserved quantities match known MHD invariants (magnetic helicity, energy) — this is the "physics residual as discovery signal" test.

7. Recommendations for imas-ambix

Note: this section identifies method options grounded in the survey and flags the key decision points. The coordinator owns final decisions for the sibling plans.

7.1 First experiment: separatrix shape prediction with calibrated UQ

  1. Base predictor: small deep ensemble (M = 5), raw-signal inputs. Input: concatenated raw diagnostic time-series (poloidal field probes, Rogowski coils, visible camera features). Output: vector (Vplasma, κ, δupper, δlower, …). Train with NLL loss on Gaussian predictive. No EFIT labels. A Grad-Shafranov residual term (computed from the predicted shape + plasma current) enters as an additional soft-prior regulariser. Reason: ensemble is the most data-efficient method for epistemic UQ; NLL loss encourages calibrated variances; the GS residual tests principle #1.
  2. Calibration wrapper: split conformal prediction. Reserve ~20% of shots as calibration set. Apply split conformal to convert ensemble outputs to prediction intervals with provable marginal 90% coverage. Report empirical coverage, CRPS, NLL, reliability diagram, and PI width against the acceptance criteria in §4. Reason: distribution-free coverage guarantee for the safety statement; free to add after any base model; interpretable.
  3. Baseline to beat: a single-slice Kalman filter / Gaussian process on engineering parameters (magnetics only, no camera), trained with EFIT labels. This quantifies the cost of the "no-EFIT" constraint and the value of the camera modality.

7.2 Path to the full temporal PSSM

  1. Temporal state-space model: RKN or DVBF. Once the point-predictor baseline is established, wrap the encoder in a Recurrent Kalman Network (RKN, Becker 2019) or Deep Variational Bayes Filter (DVBF, Karl 2017). Both maintain explicit Gaussian belief states updated at each new diagnostic observation — enabling Bayesian filtering along a shot. RKN is preferred for the first step because its factorised covariance avoids expensive matrix inversions and it outperforms LSTM on uncertainty quality.
  2. Continuous-time extension: Latent ODE → Latent SDE. MAST data has irregular sampling and multi-rate diagnostics. Latent ODE (Rubanova 2019) handles irregular time naturally; Latent SDE adds intrinsic stochasticity for ELM/bifurcation regimes.
  3. Data assimilation mode: EnKF around the learned PSSM. The trained PSSM forward model (encoder + transition) can serve as the "numerical model" inside an Ensemble Kalman Filter for assimilating real-time diagnostics during a shot. This is the path to online plasma state estimation.

7.3 Structure discovery (later stage)

  1. Apply SINDy (PySINDy) to latent trajectories from the trained PSSM. Candidate library should include dimensionless MHD invariants.
  2. Use PySR for symbolic regression on any residuals SINDy cannot explain.
  3. Test whether discovered conserved quantities match known MHD invariants (magnetic helicity, energy). Any excess is the discovery signal.

7.4 Key open questions for the sibling plans

  • Latent dimension. How many latent state variables are needed? Start with a sweep [4, 8, 16, 32]; monitor CRPS vs. latent dimension.
  • GS soft-prior weight. The Grad-Shafranov residual loss weight λ controls how strongly physics is asserted. This is the tunable "soft" vs. "hard" knob — set too high, it regresses to EFIT; set too low, it adds no information. Sweep λ ∈ {0, 1e-3, 1e-2, 1e-1}.
  • Camera feature extraction. Concatenate raw pixel frames (expensive), CNN features (moderate), or only camera-derived boundary coordinates (cheap)? Recommend CNN features as default — avoids the high-dim pixel space while preserving spatial structure.
  • OOD test set. What qualifies as an OOD shot for MAST? Near-disruption, high-β, snowflake, or negative-triangularity configurations are natural candidates. Needs explicit labelling before the experiment begins.
