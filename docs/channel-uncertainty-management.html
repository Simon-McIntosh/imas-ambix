§1 — Motivation & evidence

The boundary-read investigation (th-boundary-robustness, §16) measured the vacuum-span projector on the full held-out cohort: projecting each slice's coil-subtracted plasma signature onto the span of all interior currents (rank-truncated SVD of the whitened cell→sensor matrix, rank 60–64) rejects only 2.5–7.8% of signal energy, roughly uniform across every slice and regime. Three conclusions were locked by that measurement:

  • Sensor noise / calibration error is a small, near-constant floor — it is NOT what makes ramp-up slices poorly-conditioned (that is model-form error), so the projector residual is not an order gate (the boundary-shift gate owns that role).
  • Signal rewriting (de-noising sensors with Ip/li-constrained physics) is the wrong route: the achievable gain is bounded by that few-% floor, and it risks circularity — de-noising with the same physics we then fit. Ip is already applied exactly (measured Rogowski, pinned, never fit); li here is an output, not an independent measurement.
  • The per-channel components of the rejected residual (I−P)b ARE informative: a channel that persistently holds signal no interior current can produce is miscalibrated (gain/offset/geometry), and should carry less weight. That is uncertainty management — adjust the whitening, never the signal.

§2 — Design: a campaign-level channel-weight layer

One new, flag-gated layer between the payload build and every whitened fit (boundary reads, soft-prior anchor, interior LSQ): 

  payload build ──► channel-weight layer ──► whitened fits (reads / anchor / solve)
                     │
                     ├─ P  = projector onto the interior-current sensor span
                     │      (rank-truncated SVD of W·m_sens, ONE per campaign)
                     ├─ s_i = robust per-channel stat of |(I−P)·W·b|_i across
                     │      MANY train-split slices (median over slices)
                     └─ scale_i ← scale_i · f(s_i)   (inflate outliers only;
                            f = 1 below threshold, smooth ramp above)
  • Campaign-level, not per-slice: the statistic is aggregated over many train-split slices so a transient event never reweights a channel; the weights are frozen per campaign (leakage-free — never computed on eval).
  • Inflation only: weights only go down (scales inflate) for flagged channels; no channel is ever up-weighted, no signal value is modified.
  • Composes with what exists: the layer feeds the existing per-channel payload.scale, so the Huber robust clips, the misfit-weighted anchor uncertainty, and every read inherit it with zero interface change.
  • Flag-gated, OFF by default until validated (A/B on the closure gate); byte-identical results when off.

§3 — Deliverables & validation

  1. imas_ambix/latent/channel_weights.py: projector build, per-channel residual statistics, weight map artifact (per campaign, JSON), scale-inflation hook; unit tests (synthetic miscalibrated channel is flagged; clean channels untouched; off = byte-identical).
  2. Diagnostic figure (mandatory): per-channel non-representable residual bars across the train split, flagged channels highlighted — docs/figures/channel-uncertainty-management/.
  3. A/B validation: staged-disc boundary read + closure gate with weights ON vs OFF on the held-out cohort (paired bootstrap). Done-when: no metric regresses, and either (a) ≥1 channel is flagged with physical justification, or (b) the null result (no channels flagged → layer unnecessary) is recorded and the plan retired honestly.
