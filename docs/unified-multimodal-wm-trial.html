§1 — What this trial was

This records the unified multi-modal controllable world-model trial run 2026-06-22/23 — the consolidation of the "ingest all the MAST data" push into a single trained model, and the A/B that isolates the value of direct plasma-position diagnostics. Two 8×H200 runs share an identical recipe and differ only in the conditioning set:

  • Baseline — job 1221563 (9 signal streams). The first complete 6-camera, multi-timescale run: summary, pf_active (coils), interferometer (density), gas_injection, soft_x_rays, xma (Mirnov), xsx, xim, ait (divertor heat-flux).
  • Enriched — job 1221741 (13 signal streams). The same model + four added measured position streams: ada (Dα-peak radius = boundary location), adg (edge-gradient position), aim (Dα emission), and calibrated L2 magnetics (94-channel flux loops + poloidal B-field probes — the direct position/shape sensor).

The question: does giving the model the plasma's position as an observation make it more controllable — i.e. does its dream respond to the demanded actuator plan? It is the entry baseline for the joint multi-modal generative world model plan.

§2 — Architecture

A decoder-only factorised space-time transformer over frozen Open-MAGVIT2 camera tokens (16×16 = 256 tokens/frame), 1.09 B parameters (d_model 1536, 16 layers, 16 heads, d_ff 6144), warm-started from the M2 forecaster. Conditioning:

  • Actuator plan (PF/CS coils + gas + NBI, 23-ch) injected via AdaLN-Zero at every block — the control surface; the measured states (Ip/density/tf) are masked out so the model cannot read the answer off the state.
  • Camera history through a per-frame history bottleneck (noise + masking) that breaks latent-action collapse, with observation_dropout = 0.8 (all-or-nothing) so the model is trained to dream from the plan alone.
  • Δt (timescale) + camera-id embeddings — one model spans all 6 cameras (rbb/rco/rgb/rgc/rba/rbc) and both cadence regimes (fast bursts ~3.5 ms/frame, slow full-shot ~16.7 ms/frame).
  • Measured signal streams (9 → 13), each quantised to the L2 257-id vocab, resampled to the camera window, omit-when-absent. The four new position streams were staged label-agnostically from raw L1 (Dα) and calibrated L2 (magnetics), ignoring the unreliable IMAS dd-path semantics.
  • Inverse-dynamics auxiliary + scheduled sampling + excitation-weighted next-frame CE (coil |dI/dt| up-weighting so flat-top frames don't drown the control gradient).

Corpus. curated_windows_unified_6cam.json — 33,111 windows over 8,730 shots, all 6 cameras, fast 2,614 + slow 30,497, held-out 18502–05 disjoint (leak NONE). The model trained on 32,306 windows after the frame-count filter.

§3 — Training & objective

Both runs: 8-card DDP, 12,000 steps, warm-start the M2 forecaster, excitation-weighting ON, the M4 controllability machinery (history bottleneck, inverse-dynamics, scheduled sampling, control-dropout/CFG), baked-in held-out eval. The training objective is next-frame camera-token cross-entropy only — the diagnostics are conditioning inputs, never prediction targets (the central limitation this trial exposes). Final training loss ~4.3 (both runs converged cleanly, 100 → 4). The success objective is the held-out controllability gate ΔN-M: roll the dream forward under the true actuator plan and under random perturbed plans, decode to pixels, and require the true-plan rollout to diverge from a random sibling by ≥1.5× the random-vs-random noise floor — i.e. the demanded plan must move the dream more than noise does.

§4 — Outcome

Adding the position diagnostics flipped the controllability margin and produced the first clean held-out gate pass — but with an important and honest caveat on single-coil responsiveness.

The headline. On the driveable exemplar 18502 the gate went from a clear fail (1.33×) to a clean pass at 3.18× — under the true plan the dream diverges from a random sibling more than three times the noise floor. 18503 improved markedly (−52 → −13); the mean margin flipped from −9.5 to +18.1; the random-vs-random noise floor dropped (60 → 36), i.e. the model became more stable. Direct position observation works.

The honest caveat. The single-coil-edit response collapsed: a ±30% edit of one coil moved the 18502 centroid only 0.78 px, versus 15.96 px in the baseline (~20× less). So the enriched model responds to the whole plan (the full-vector perturbation that ΔN-M applies) but no single coil is individually load-bearing. This is a latent-action-collapse signature: with rich always-on position diagnostics, the model gets a redundant readout of the state and leans on it, so the demanded plan — especially any one coil — carries less of the prediction. It is a clean, expected consequence of using the diagnostics as conditioning inputs, and it is exactly what the next plan's per-modality masking (force the plan to carry the state) + action-contrastive objective (make individual plan edits discriminative) are designed to fix.

§6 — Interpretation & what it motivates

The trial settles two things. (1) Position observation helps controllability — the Dα-boundary + magnetics signals flipped the mean margin and gave the first clean held-out gate pass (18502, 3.18×). The "9 signals is light" instinct was correct. (2) Conditioning is not enough — feeding the position as an always-on input induced a latent-action-collapse: the model leans on the readout, single coils stop being load-bearing (0.78 px), and 2/3 held-out shots still fail the gate. A camera-only generative objective with diagnostics as crutches cannot, by itself, become robustly driveable.

This is precisely the motivation for the joint multi-modal generative world model: make the diagnostics generation targets (dream the full plasma state, not just cameras); replace all-or-nothing observation dropout with per-modality masking so the plan must carry the state; add the action-contrastive objective that directly trains the gate this trial sits at the edge of; and route the dynamics through an RSSM compact latent so the model learns reduced physics rather than leaning on a memorised readout. Entry baseline for that work: 1/3 gate, mean margin +18.1, 18502 at 3.18×, single-coil 0.78 px.
