§1 — Orientation: why this, why now

The 4×H200 Group-A reservation has been idle since S12 closed (2026-06-05) with a qualified negative and "no clean H200 GO". Meanwhile the project's single largest prepared asset sits unused: 9,527 shots of the MAST rbb wide-angle visible camera, encoded to 4.02B Open-MAGVIT2 tokens (S2–S4 era, in-process stream_encode.py path, 308 fps/GPU peak). The camera is unique in this dataset — it views essentially the whole machine: centre column, plasma boundary, both divertors, in one frame.

User directive (2026-06-10): scope fast-return, physics-backed world-model builds that properly use the reservation. The first is this plan: reconstruct the full time-dependent camera stream from a clipped sub-view, and make the reconstruction dynamics-backed — the infill must flow through a learned temporal latent state, not per-frame spatial pattern completion.

Two prior results discipline this plan. (1) S5's honest negative: fine-tuning the 2-D decoder against rFID was a dead end, and rFID is the wrong north-star for a dynamics model — so this plan trains and evaluates in token space with the decoder frozen (baseline imagenet OMAG2), and rFID is banned as a primary metric. (2) The strategy lock camera-role = one-modality (2026-05-29): generative video is a byproduct, never the guiding goal. This plan honours that lock — masked full-stream reconstruction is the training objective; the product is the dynamics-bearing latent state and what it knows about the plasma (§5 D4 probes). The decoded full-stream demo is the byproduct that falls out for free.

§2 — Thesis and pre-registered win condition

Thesis. The full-machine camera stream is governed by a low-dimensional latent plasma state evolving in time (boundary shape, emission front positions, filament/ELM activity, divertor attachment). A model that carries an explicit temporal latent state can therefore reconstruct what a clipped view does not see — including forward in time — where a per-frame spatial inpainter cannot. If true, the latent is a learned reduced-order dynamics extracted from raw data, and it should read out other diagnostics it never saw.

Pre-registered win condition (locked before any model number, per project practice):

  • W1 — dynamics beat statics. At matched parameter count and matched training tokens, the temporal model beats the per-frame spatial-inpainting baseline on masked-token NLL / top-1 accuracy over the held-out shot split, with bootstrap CI clear of zero.
  • W2 — forward-horizon reconstruction. Conditioned on the clipped stream up to time t only, the temporal model reconstructs full frames at t+h (h = 10, 50, 200 ms) better than (a) persistence of its own t-frame reconstruction and (b) the per-frame baseline given the t-clip. This is the axis where a spatial inpainter has no mechanism at all.
  • W3 — the latent knows physics. A frozen linear/shallow probe from the temporal model's latent predicts held-out raw diagnostics (Dα ada, line-integrated density ane, Thomson Te_core, n=2 mode amplitude ama) better than the same probe from the per-frame baseline's representation.
  • Stretch (honest-low prior) — interior probe. The same frozen probe scored on the S9 oracle sightline-pitch metric (D1 harness, 112 held-out MSE shots). Every multimodal arm so far has returned ~0.41 rad near-axis / no win over processed magnetics; expectation is a clean negative, and a clean negative is a result. No win is claimed in advance.

Primary metrics are token-space (NLL, masked-token accuracy) plus probe RMSE/CRPS on raw signals. Pixel-space L1/SSIM via the frozen decoder is reported as a secondary diagnostic only. rFID appears nowhere.

§4 — Architecture

Masking design: training uses random spatial clip windows (position + size jittered per sample) plus a temporal-frontier mode (clip visible up to t, everything masked after t) so a single model serves both W1 and W2. Evaluation uses a frozen clip geometry (the §2 figure window) for comparability. The 218 LFQ vocab is predicted with a factorized bit-head (18 binary logits or 2×9-bit factorization) rather than a 262k softmax — decision vocab-head.

§6 — Compute plan and GPU safety (binding)

Sizing: ~150–300M-parameter transformer over 4.02B tokens ≈ 4–8 h/epoch on 4×H200 with bf16 + FSDP — a 2–4 day fast-return project including ablations, not a month-long pretrain. Token shards staged from GPFS to /scratch_local at job start. Model loaded once, in-process torch DataLoader with bounded queues (AGENTS.md §2b); no subprocess-per-item, no file-IPC daemons.

Every sbatch clones the hardened header verbatim (AGENTS.md §2a-cancel-time): STOP-FILE (AMBIX_STOP_FILE, checked at every optimiser-step boundary), --signal=B:USR1@600 + bash trap touching the STOP-FILE, AMBIX_SOFT_TIME_LIMIT at ~85% of the ceiling, --time set to 2–4× expected runtime as ceiling only. SIGTERM/SIGINT handler exits clean in <5 s. Never scancel. Checkpoint every N steps so any clean stop resumes without loss.

§7 — Risks and honesty

  • Static-scene degeneracy. Much of each frame is vessel background — a spatial inpainter may do well on bulk masked tokens. This is exactly why W1 is matched-arm and W2 (forward horizon) exists: the dynamics claim must be earned where statics cannot compete. Metrics are additionally reported on a motion-weighted token subset (tokens whose identity changes within ±50 ms).
  • S5 shadow. No decoder tuning, no rFID. Token-space + probes only.
  • Interior-information wall. Three sprints (S8/S9/S12) say the interior current is not recoverable from edge-view modalities; the stretch pitch probe is framed as a clean test and its prior is low. The plan's primary value does not depend on it.
  • Cadence heterogeneity. rbb frame rates vary 100–400 Hz across the corpus; the dataset carries per-frame timestamps and the model conditions on Δt (or resamples to a common grid — D0 decides and documents).
  • Camera-role lock. Generation stays a byproduct. If the project drifts toward video quality for its own sake, that is scope failure — the deliverable is the latent and its probes.
