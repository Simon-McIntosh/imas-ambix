Recovered Current-Density Evolution — MSE-Free Current Recovery (S9)

An illustrated record of what the S9 current-recovery sprint actually recovers: the internal toroidal current-density profile jφ(ρ, t) of a tokamak discharge, inferred from raw measured diagnostics with no MSE on the input side. The figures are the classical D2 baseline — a parameter-space ensemble smoother over the validated TORAX current-diffusion solver — which is THE BAR the S9 neural filter (D4) must beat. The current evolution shown here is genuinely dynamic, in sharp contrast to Stage-1's near-stationary Dα target where dynamics did not pay (Stage-1/2 results). Every figure is plotted directly from a re-run of the committed baseline ensemble; the source artifact, config, and per-shot member counts are recorded in docs/figures/current-recovery/generation_manifest.json.

§1 — What is plotted, and where the data comes from

The committed metrics artifact (imas_ambix/statespace/artifacts/enkf_baseline_metrics_v0.json) persists only scalar per-shot diagnostics — q0 medians, magnetics innovations, the bootstrap-CI metric blocks. It does not store the per-shot current-density trajectories. So the figures below were produced by re-running the baseline's prior (forecast-arm) TORAX ensemble for four representative held-out shots, using the exact committed configuration (n_ensemble=32, seed=1234, RNG seeded default_rng(seed + shot_id)), so the plotted ensemble is the one behind the committed bar. The extraction + plotting script is scripts/plot_current_recovery_findings.py; all 4 shots ran to completion with 32/32 members OK in 13–21 s each (no wall-clock-guard trips).

The recovery is MSE-free by physics. Each ensemble member is one full TORAX trajectory: only the poloidal-flux (current) equation evolves, driven by the measured plasma current Ip(t) and a neoclassical conductivity σ(Te) closure built from the measured Thomson Te(ρ) — the channel that breaks the Stage-2 magnetics under-determination. No MSE, no pitch-angle, no internal-current diagnostic touches the input side. MSE enters in §4 only, as held-out eval truth.

Which arm. The figures show the prior / forecast ensemble (measured inputs only, external magnetics not assimilated). The artifact's own verdict is that the single EKI magnetics update moves the internal current negligibly (analysis pitch RMSE 0.225 ≈ forecast 0.233) — the Stage-2 under-determination thesis: external magnetics fix the boundary and Ip, not the interior j(ψ). So the prior ensemble is the recovered MSE-free current; the resistive transition does the work, not the magnetics update.

Shots. 24443, 24148, 24065, 22329 — chosen for finite magnetics innovation, full 32/32-member success, and a forecast arm free of q0 pathologies, spanning the dynamic high-Ip OOD flat-top q0 band (~0.25–0.6). (Shots 22086 and 22759 were deliberately excluded — their forecast-arm q0 blows up to ~3.0 / ~2.3 and would mislead.)

§2 — The headline: jφ(ρ, t) is genuinely dynamic

At five discrete flux surfaces (ρ = 0, 0.2, 0.4, 0.6, 0.8) the recovered current density rises through the current ramp, develops radial structure (peaked near the axis), and evolves continuously over the ~0.5 s discharge. The ensemble 1σ band shows the spread across the 32 sampled parameter vectors (Zeff, resistivity multiplier, initial-current peaking, Ip-boundary scale). This is the contrast that motivated the whole pivot: unlike Stage-1's ~96.8 %-quiescent Dα target — where a frozen nowcast beat the dynamics — the current profile here is non-stationary, so a model that captures the transition has something real to recover.

§3 — The spatial profile evolving in machine R

The same trajectories, viewed as the radial profile jφ(R) at three snapshot times (early ramp / flat-top / late), show the current concentrating toward the magnetic axis as the discharge develops. The major radius here is the nominal circular-geometry mapping R = R0 + ρ·a (R0 = 0.85 m, a = 0.5 m) — the outboard midplane of the circular TORAX geometry, not a reconstructed flux-surface R; it is plotted to give a sense of where in the machine the current sits, with the magnetic-axis radius marked.

§4 — On-axis q0(t): recovered vs held-out MSE truth (eval-only)

The decisive eval check. The recovered on-axis safety factor q0(t) (blue) is obtained by reading the ensemble-mean predicted pitch out of the recovered current through the shared invert_pitch_to_q0rax inverter, and is compared against the held-out MSE-derived truth q0 (red) obtained by passing the measured MSE pitch through the identical inverter and eval geometry (R0 = 0.85 m, Bt0 = 0.5 T). Because both q0 use the same inversion, the gap between them is model error, not method mismatch — and is consistent with the scored secondary q0_rmse ≈ 0.52 (analysis arm, N = 112; the figures show the forecast arm on 4 shots, so a slice-level RMSE will differ). A third, dotted line shows the TORAX-free on-axis q(ρ=0) (the free non-vacuity quantity) — a different construct, unbounded as Ip → 0 on residual ramp slices, so the view is clipped to a physical window. MSE is held-out eval truth only — it never enters the recovery.

Two honest readings. First, the recovered q0 sits in the low ~0.3–0.5 band — the flat-top q0 on this high-Ip OOD held-out set is genuinely low (a sawtoothing / high-current regime), not ~1; non-vacuity is shown by recovering an order-unity, radially-structured internal current with no MSE input, not by hitting q0 = 1. Second, the recovered line sits systematically below the MSE truth and is smoother — it captures the slow trend but not the truth's slice-to-slice excursions. That residual gap is what a richer multi-modal filter is meant to close.
