§1 — agent restart runs the paused cycle as one command

Run r-20261020T073720209200-restart-paused-cycle, merged at 1cd328af. imas_ambix/agent/reload.py holds the cycle behind injected interfaces, and restart in imas_ambix/agent/cli.py wraps it:

  • it pauses through the same _pause_gate helper agent pause uses, which clears any stale cut, then drains to a measured zero;
  • it cancels the old serve by job id, submits the replacement, waits for readiness through _probe_endpoint, and validates with a completion of at least 200 tokens;
  • any failure after the cancel resubmits the replaced job's own batch script;
  • the new settings must validate within 22 minutes of the pause and the rollback within 40, and the command always resumes unless an operator had already paused the lane;
  • each cycle appends a UTC record to lane-cycles.jsonl, and --reason is required.

shutdown, key --rotate and restart select a profile's jobs through one helper, _profile_jobs, over _running_jobs.

§2 — overlap reload: the replacement takes traffic only after it has generated

Run r-20261020T120846946587-restart-overlap, merged at a462d286, with two follow-ups merged at 39bd6932: the fold run r-20261020T133959926152-restart-drain-reuses-engine-metrics and its repair r-20261020T141836671772-restart-drain-metrics-repair.

  • agent restart --mode auto|overlap|pause: the overlap path writes the replacement's registration held, before its engine launches. Only registry release clears the hold, and both resolver paths skip a held job.
  • auto takes the overlap path only when two conditions hold. The router must advertise held-registrations in x-ambix-router-features, and the node-wide room check must find cards, cores and memory: scontrol node totals, plus the grpA core ledger over every user's jobs.
  • The swap is confirmed by a completion through the router whose x-ambix-upstream header names the replacement.
  • The old engine is then drained of running requests, for at most 10 minutes, through the shared engine_metrics reduction. A missing or undecodable reading counts as unknown, never as zero. Only then is the old job cancelled, by id.
  • shutdown refuses while a profile has two live jobs, unless given --all.
