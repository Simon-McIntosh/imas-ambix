Global router generation gate

Commits 4bb11e89, da60421b and 7ecfec3b added and hardened a single FIFO admission point shared by both generation paths. The runtime file router-gate.json, beside lane.json, carries width and wait_seconds; it is re-read when replaced or edited. One gate-wide monotonic deadline limits file metadata and content reads to once per second regardless of waiter count. Missing or invalid configuration uses the launch defaults of 22 in flight and 300 seconds, while width 0 disables admission. Catalog and /v1/messages/count_tokens traffic does not consume a generation slot.
