§2 — The guard: inventory, allowlist and silent shapes

A test that compares a produced value against the very constant the code under test reads cannot fail on that constant's value, and the guard that finds those comparisons now runs from the repository root. Commit 0574f371 adds scripts/circular_assertion_audit.py, its TOML allowlist scripts/circular_assertion_audit.toml, and tests/test_circular_assertion_audit.py.

The scan walks every module under tests/, parses each with ast, resolves which local names it imports from imas_ambix and which it binds to a literal, and reports an assert whose all-== chain has no anchor: no operand is a literal, no operand names a literal-bound binding or a reference pinned against a literal elsewhere in the file, and at least one side is a bare name reference into the package under test. A call or a subscript is not a reference for this purpose — the defect compares a produced value against an imported constant, and a call is the thing under test rather than the constant.

The three silent shapes and the allowlist

Each shape below is exercised by a named test that hands the scan a tmp_path tree as its root, so the guard's silence is measured rather than asserted:

  • written-out literal — assert _CARD_QUERY_FIELDS_LITERAL == LaneCapacity.CARD_QUERY_FIELDS is silent when the left name is a literal tuple bound in the test module.
  • pinned once — assert rows[0]["upstream"] == SELF_ANSWERED_UPSTREAM is silent when the same file elsewhere asserts SELF_ANSWERED_UPSTREAM == "(router)".
  • literal in the chain — assert LaneCapacity.OCCUPANCY_TARGET == 0.9 is silent, the comparison having pinned the value.

The remaining shape, wiring, is reported and recorded per site. A test plants assert derived["occupancy_target"] == LaneCapacity.OCCUPANCY_TARGET, observes it reported with symbol LaneCapacity.OCCUPANCY_TARGET, then observes it silent once an entry matching that file and symbol exists. The TOML allowlist carries [[entry]] tables of file, symbol, shape and reason; shape is one of wiring, pinned-once or written-out-literal. An entry with an empty or missing reason, or with a shape outside that vocabulary, makes the audit refuse with exit 2 and a message naming the entry — the reason is the thing a later reader checks, so its absence is a failure of the guard rather than an exemption from it.
