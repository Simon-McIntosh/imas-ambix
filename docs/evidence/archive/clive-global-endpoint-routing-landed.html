Reuse map and server extension seam

Passed. The read-only reuse scout classified 20 existing seams: 8 keep, 6 adapt, 4 delete, and 2 replace. The existing generated launcher and serving-script construction are reusable, while the scheduler-derived consumer route, key-file read, personal environment overrides, and per-user operator CLI dependency must leave the shared launch path.
