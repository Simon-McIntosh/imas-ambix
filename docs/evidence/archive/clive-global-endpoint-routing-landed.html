Server-owned catalog provider

Landed and independently verified. Commit 8d27afa1e704862d241bac62bc6747c3890bfa79 adds the pure-ASGI middleware, explicit checkpoint-precision profile field, generated vLLM middleware registration, and focused contract tests. The middleware rewrites only successful GET /v1/models responses and returns the intersection of native vLLM model cards with explicit launch metadata. It cannot advertise a configured model that the running engine did not report.

  • Native release ids, context limits, and other model-card fields are preserved.
  • Accelerator count accepts only integer values 2, 4, 6, or 8.
  • Accelerator family and checkpoint precision must be explicit, non-empty site facts.
  • Duplicate ids, unmapped cards, missing metadata, and invalid metadata fail closed.
  • Successful multi-frame catalog responses are buffered and emitted with a corrected content length.
  • Every non-catalog route, method, error response, and streaming message passes through unchanged.
