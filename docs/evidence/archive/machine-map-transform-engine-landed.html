§3 existed to replace a convention held in someone's head with a declared boundary. It did that, and in doing so it produced the evidence §2's map-expressiveness decision was waiting for — which is the more consequential result.

What the boundaries say about campaign as a key

Boundaries: 11766, 12417, 12533, 12561, 12878, 12905, 12964, 12990, 13021, 13049, 13379. Only 11766 coincides with a campaign boundary. Campaign is therefore not a usable key for geometry — a map keyed per campaign would smear ten distinct machine descriptions into one. Shot range is a usable key: the ranges partition the corpus exactly, so the design rule §2 states (one map per shot range, no conditionals) is sufficient here and needs no conditional expressions. It simply needs more maps than there are campaigns.

Qualification carried forward

The repeated 1004↔938 filament-count alternation is not physical. A machine does not swap PF filament counts back and forth across adjacent shot ranges, so at least some of these boundaries record variation in the EFIT setup arrays the signature is sampled from rather than a change in the machine. The partition and lookup invariants hold either way, but the transition count is an upper bound on real machine changes and must not be read as eleven distinct machines. Separating setup-file churn from machine change is work the map authoring node inherits.

The boundaries stopping at 13379 is consistent with the independently recorded frozen efm signature from 13370 onward.
