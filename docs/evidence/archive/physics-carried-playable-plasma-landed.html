§4b — Camera topology targets (landed 2026-09-02)

Codex implement node pcp-topology-targets (run r-20260902T135140055700-pcp-topology-targets, gate passed) added imas_ambix/worldmodel/camera_topology_targets.py with tests/worldmodel/test_camera_topology_targets.py — commit b7a0567, merged 4a29600. 5 tests pass; the whole-tree ruff check imas_ambix tests gate stays at exit 0.

Why the node existed. §4b names strike-point error and topology-class accuracy in its gate, and neither label is on disk: the level-2 equilibrium group carries no strike point and no class, and its two null slots are order-invariant, so even the primary null is not directly available. All three are derived here from what the group does carry — the flux map, the boundary contour, the null coordinates and the wall — reusing the existing topology authority (read_topology, boundary_flux, lcfs_contour, classify_regions) rather than a second critical-point finder. Targets stay metre-valued with masks preserved, never imputed.

The derivation corroborates itself. In every one of the four shots the non-yielding frame count equals the limited-class count exactly (58/58, 55/55, 44/44, 54/54). The class read and the null/strike read are computed by different routes, so their agreement is independent evidence that limited configurations correctly carry no primary null and no strike points, and that every diverted frame carries both. Class thresholds sit on XPOINT_BIND_TOL = 0.005 of the axis-to-boundary flux span; strike points are radially ordered separatrix–wall intersections in inner/outer slots.

Negative finding: one class has no support. disconnected-double-null occurs in 0 of 1,360 frames while connected-double-null carries 621. Its branch requires exactly one binding null, a second valid null, and a private region; the 0.5% binding tolerance is tight, so this reads as a property of these four carriers rather than a mislabel. The consequence is for the gate, not the module: the §6 class-accuracy measure can presently score four classes, not five, so the labeller must report per-class support beside accuracy — a zero-support class averaged into an aggregate is a passing number that means nothing. Artifact: frozen-six-topology-census.json in the run directory.
