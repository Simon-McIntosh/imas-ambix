The union catalog, and what it refuses

The union preserves each upstream card unchanged — native id, engine-reported max_model_len, and the complete ambix block — validated through the schema validator the engines already use rather than a second one. Three refusals are the substance, because a merge that resolves ambiguity silently is worse than one that stops:

  • a native id two upstreams both claim returns 409 rather than picking one;
  • an unknown id returns 404 rather than falling back to a default upstream;
  • one upstream being unreachable degrades the union to its reachable peer instead of failing the whole catalog.

Streaming fidelity is asserted at byte level: the fixture pins an exact thinking signature and an exact tool_use identifier surviving the relay, an upstream 429 and its headers passing through unchanged, and a downstream disconnect closing the upstream response. No protocol translation exists anywhere on the path, per the locked decision.

Upstream resolution

Locked to a registration record preferred with scheduler discovery reconciling it. A record becomes a candidate only after its job is still running and an anonymous probe returns the same native model id, so a record never establishes availability on its own — which is what stops a stale file becoming a phantom upstream. Records win over scheduler rows describing the same allocation, producing no duplicate engine, and job-id reconciliation is owner-independent so the router is not limited to one operator's queue. A stale allocation beside a running replacement resolves only the replacement's new port, with no configuration edit and no launcher redeploy — the acceptance property the plan named.

The defect this work exposed

A module's unit tests passing proved nothing about the interpreter that actually imports it. The registration module used the unparenthesized multi-exception form that Python 3.14 permits; the project targets 3.14, its tests passed there, and the whole-tree lint was clean. But the generated serve script imports repository modules on the compute node, under the vLLM environment pinned to >=3.12,<3.13, where that form is a hard SyntaxError. Serve job 1260703 died two seconds in.

The first guard covered only the modules the generated script names. Widening it to the whole package immediately exposed a fourth clause that ast.parse could not report while an earlier error in the same file stood — three modules had been reported, four clauses existed. The guard now parses every module under the agent package at the serving environment's declared lower bound, derived from that environment's own requires-python rather than hardcoded, with an inline negative control proving it rejects the form that caused the failure.

Admission control

Admission sits on the router because the engine will not self-limit usefully: it accepts far more concurrency than the node serves at acceptable latency. Each consumer defaults to two in flight plus four queued, all three limits configurable, sized for the group best-effort audience. Under deliberate overload against a one-active one-queued limit, a third request receives HTTP 429 with Retry-After 7 while a second consumer completes independently — the property that makes a heavy caller degrade its own latency rather than everyone's. Capacity is released in a finally, so a client disconnecting mid-stream cannot leak a slot; the test shows the same consumer immediately reusing a one-active zero-queued router.

Whole-surface verification

Per-node gates ran only their own focused files, which is how a regression reached main unnoticed. A whole-tree node was dispatched for exactly that gap and found it: 2654 passed, 14 failed, 0 errors, 20 skipped across 212 of 221 files, with six failures in tests/test_agent.py caused by this sprint's own launch-mode work. Whole-tree lint reported 0 findings and all 16 agent modules parsed at 3.12. The nine files that exceeded the compute allocation were measured separately: 171 passed, 0 failed, 3 skipped over eight of them, leaving tests/fluxstate/test_consumer_contract.py as the only unmeasured file.
