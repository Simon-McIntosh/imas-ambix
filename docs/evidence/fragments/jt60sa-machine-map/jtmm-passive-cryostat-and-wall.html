passive cryostat and wall: the vessel, cryostat and first wall separated in the store

Node jtmm-passive-cryostat-and-wall · date 2026-10-06 · plan jt60sa-machine-map §4

The SELENE passive block carries two contiguous resistivity runs. The first is the vacuum vessel (EQSLE.DATA lines 293–355, 63 filaments at 7.76e-7 Ω·m); the second is the cryostat (lines 356–412, 57 slabs at 7.20e-7 Ω·m). The converter had named the second run VV2 — a second vessel, which it is not. The deck's trailing contour table interleaves the two vessel skins with the first wall, and had been written as one limiter polygon.

imas_ambix/data/selene_deck.py now parses the two runs into vessel and cryostat and writes two named pf_passive loops, VV and CRYOSTAT, and splits the contour table by its labels so the first wall becomes the limiter outline and the two vessel skins become the annular vessel unit's outline_inner and outline_outer.

The converter refuses to label a group CRYOSTAT unless every one of its filaments lies outside the vessel group's R and Z envelope (CryostatEnvelopeError), so a second vessel material can never be written as the cryostat. Both phases read the cryostat from the same EQSLE.DATA run, so the two phases' CRYOSTAT loops are identical; OP2 takes its own 98-filament vessel and limiter from coil_vv_OP2.dat, which carries no skins, so its wall is the limiter alone.

The store under /work/projects/imas_gpu/jt60sa/machine_description/ was re-converted from the three sha256-verified source copies (refusing on any mismatch against source/provenance.json). Every existing file's sha256 was recorded first; each new file was staged in a sibling temp directory and os.replaced into place. Every IDS reads back through imas.DBEntry at DD 4.1.1 in both phases.
