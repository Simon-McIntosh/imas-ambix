A selecting binding's source_rank counts only levels below the selected entry

Node jtmm-selector-rank-composition · date 2026-10-06 · plan jt60sa-machine-map §4

The netCDF engine's rank check subtracts the struct-array level the struct_array_entry selector consumes, so a selecting binding's source_rank counts only the levels below the selected entry. Selecting coil C (one element) reads shape (1,) at source_rank 1 and a scalar at 0; source_rank 2, which would count the consumed coil level, is refused naming the binding and the rank. A selecting binding whose first struct array is empty is refused as a BindingTransformError naming the binding rather than a bare KeyError. Bindings without the slot read as before.
