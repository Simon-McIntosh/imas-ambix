  • A drive's ampere_turns_per_ampere is the coil's total: the sum, over the coil's element connections, of turns × current_weight × direction — matching how geometry_adapter._materialise_circuit_drives sums a circuit. artifact_geometry divides a drive's weight across the elements it names in proportion to section area (_element_weights via ResolvedDrive.shares), so the per-element value would have cut every coil's current by its element count. A coil whose per-element weights disagree beyond the catalogue's two-decimal rounding band is still refused by name, so the FPPC 3.83/3.84 spread is accepted and a genuine disagreement is not.
