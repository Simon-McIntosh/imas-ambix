JT-60SA vacuum re-adjudication with corrected turns and selector angles

The JT-60SA path in scripts/vacuum_loop_adjudication.py now derives its geometry from read_geometry_table(shot, machine="jt-60sa") and takes each tangential probe's sensitive-axis angle from that table's probe_angle_source branch, so no reader opens magnetics.nc directly. The measured MMSYS coil currents are multiplied by the operator's own per-column pf_current_scales before prediction, so the deck's turn totals reach the G_pf columns. The verdict rule was corrected to test the magnitude of the Pearson correlation: slope and correlation share a sign, so a channel that tracks with slope −1 has r ≈ −1 and the previous r > 0.98 test made negate unreachable.

Over E100595, E100579 and E100642 the re-adjudication returns 3 identity, 1 negate and 40 undecided of the 27 loops and 17 probes. The CS-dominated loop magFlxLp7 is the negate, at slope −0.986 / −1.086 / −0.988 with r −1.000 / −0.995 / −0.999, within the plan's 20 % of −1 on every shot. The identity channels are the probes magPbTC8, magPbTC9 and magPbTC13. Every remaining channel is reported undecided with its per-shot slope and correlation.

The swap control is now the pair magFlxLp7 (negate) and magPbTC8 (identity), chosen so their verdicts differ. Swapping their measured channels changes both (magFlxLp7 negate → undecided, magPbTC8 identity → undecided), two changed verdicts in all, so the control fails if the fit stops responding to the measured channel. The run raises if either control channel's verdict is unchanged.

MAST's default path was run into a scratch directory (--output-root) and its verdicts compared with the committed MAST receipt. The commit is 2 nominal-table / 12 reconstruction / 5 null against the receipt's 2 nominal-table / 14 reconstruction / 3 null: every other row matches. Both differences are the single channel fl_p5l_1, in the early and late ranges, whose verdict moves reconstruction → null. Its margin is borderline in both receipts (early +0.000475 [+0.000193, +0.000785] committed versus −0.000313 [−0.000655, +0.000059] here), so the bootstrap interval crosses zero on a residual shift of order 1e−3. The JT-60SA repair does not touch the MAST prediction path; the only change that reaches it is building the candidate table from the range representative, and the machine maps declare one description per range (the representation key is equal for the resolvable shots compared, and several cohort shots, e.g. 11814 and 11909, have no level-2 store at all), so that build is neutral and the two differences predate this node.

Reproduce with python scripts/vacuum_loop_adjudication.py --machine jt60sa for the evidence JSON and HTML, and python scripts/vacuum_loop_adjudication.py --output-root <scratch> for the MAST receipt comparison. Run logs and the corrected-turn check are in the run directory.
