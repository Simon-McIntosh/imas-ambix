build_pf_active now names every conductor element {coil}_{position} with the 1-based position in its coil (CS1_1…CS1_40, EF1_1…EF1_16, FPPC_UP_1…FPPC_UP_6), and build_pf_passive names each vessel filament {loop}_{position} on the same rule. The module declares __all__ naming only write_phase_description, its one converter entry point. The tests/data/test_selene_deck.py every-entry-is-named sweep is extended to the coil-element level: a test reads pf_active back and requires every element named, in deck order, with no name repeating within its coil.

Both phases were re-converted from the sha256-verified copies already landed in /work/projects/imas_gpu/jt60sa/machine_description/source/ (all three hashes re-checked against source/provenance.json, refusing on any mismatch) by converter commit 8199811549fe423ebdd096d04aa4cdf4d97702f2, which each receipt.json names. Each output file was written under a temporary sub-directory inside its phase directory and renamed into place with os.replace, so a concurrent reader sees the old or the new file and never a partial one. Nothing outside machine_description/OP1 and machine_description/OP2 was written, and the JT-60SA server was never contacted.
