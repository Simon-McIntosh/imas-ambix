tokamap export: the packaged MAST catalogue collapses unit, sign and COCOS into one scale

Node jtmm-tokamap-export · date 2026-10-05 · plan jt60sa-machine-map §2 · new module imas_ambix/data/tokamap_export.py

export_tokamap_directory(catalog, signal_maps, directory=...) writes a tokamap directory from an ambix catalogue and its signal maps: a top-level mappings.cfg.json and globals.json, one directory per IDS group, and beneath each group one partition directory per catalogue map, named by the map's first_shot and selected by MAX_BELOW. Each leaf carries its own globals.json and mappings.json, and each leaf holds only the mappings whose Data Dictionary path belongs to its own IDS group. Every binding becomes a DATA_SOURCE mapping whose scale is the product of its unit factor, its sign-convention factor and its COCOS factor; a unknown-unvalidated binding takes no sign and says so in its comment. A mapping's tokamap key keeps its IDS prefix, so a group's file can be read for foreign bindings on its own.

Measure, run on the fleet allocation (job 1277272)

  • Each group's mappings.json holds only keys that begin with that group's IDS, no key appears in two groups, and the per-group entry counts sum to the exported entry count; the export result carries those per-group counts and the number of mappings.json files written, so a duplicated write cannot hide behind a de-duplicated total.
  • uvx --from tokamap==0.3.2 tokamap-validator <exported MAST directory> exits 0, “Validation completed successfully.”, for all four IDS groups the MAST map binds (magnetics, pf_active, pf_passive, wall; 264 entries over 6 shot partitions at 11766–22087, 24 mappings files, per-group counts 126 / 54 / 66 / 18).
  • For every exported catalogue binding the on-disk scale equals unit × sign × COCOS to 1e-12, recomputed independently from the binding's declaration; a degree→radian binding exports 0.017453292519943295 and an ip_like target from source COCOS 6 exports −1.
  • Shot partitions follow the catalogue's map ranges: the set of partition directories under every group equals the set of map first_shot values.
  • Negative control: omitting the COCOS factor from the exported scale fails the scale round-trip test on the COCOS-dependent binding (1 failed, 4 passed; exit 1).
