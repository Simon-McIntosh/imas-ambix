the SELENE PSRC reference loader behind the referee's gated seam

Node jtmm-selene-reference-loader · date 2026-10-09 · plan jt60sa-machine-map §7

The firewalled referee (imas_ambix/eval/efit_referee.py) gains one private loader, _selene_psrc_loader, with the seam's signature (shot_id, frame_times, **kwargs) -> EquilibriumGeometry. It is reached only through read_efit_geometry(..., loader=_selene_psrc_loader), so it inherits the evaluator_context firewall unchanged: a call outside the context raises FirewallViolation before the loader runs. The loader adds no public name — __all__ is unchanged — and opens no second read path: it reads the shot through imas_ambix/data/selene_psrc.py read_psrc_record, forwarding cache_root and extractor from its kwargs, and reduces the record through imas_ambix/worldmodel/equilibrium_labels.py build_geometry_from_arrays, deriving no geometry of its own.

The boundary's own time base is the reduction base t_eq. The magnetic axis (calRp0, calZp0) and the X-point (calRX, calZX) are interpolated onto t_eq with the builder's own _interp_1d_masked (so an out-of-range frame masks rather than clamps), the X-point is passed as a one-null set with time on the last axis, and the boundary's per-slice contours — which carry different vertex counts — are NaN-padded into one (n_bdy, nt) array the builder's resample_lcfs_radii accepts. PSRC's geometric centre calCCSRc/calCCSZc is never read.
