A static netCDF binding selects one named struct-array entry

Node jtmm-static-entry-selector · date 2026-10-06 · plan jt60sa-machine-map §4

ChannelBinding gains an optional struct_array_entry slot naming one entry of the first struct array on the binding's dd_path by that entry's name leaf, declared in schema.yaml and loaded by machine_map.py. The netCDF engine reads that one entry's arrays; a binding without the slot reads exactly as before; a ragged struct array read without a selection names its dd_path and the unequal element counts; a selection matching no entry is refused; and the zarr engine refuses the slot rather than ignoring it.

Measure: this node's four new tests pass and read the twelve real OP1 coils as element lengths [40, 40, 40, 40, 16, 16, 16, 16, 16, 16, 6, 6]. ruff check imas_ambix tests exits 0. Negative control: ignoring the selection slot reddens test_netcdf_binding_reads_one_named_entry_of_a_ragged_struct_array.
