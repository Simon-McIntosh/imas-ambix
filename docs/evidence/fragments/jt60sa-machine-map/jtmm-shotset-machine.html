jtmm-shotset-machine: the frozen benchmark shot set now declares the machine each shot belongs to

Node jtmm-shotset-machine · date 2026-10-05 · plan jt60sa-machine-map §7 · imas_ambix/spine_bench/shots.py

BenchShot gains a required machine field with no default: a shot number is not unique across machines, so the catalogue a shot belongs to is declared and never inferred from the digits. MAST's six frozen shots declare machine="mast". resolve_shotset_version now compares (machine, int(shot_id), role) against MAST's FROZEN_SHOTSET, so a set whose shot ids and roles equal MAST's but which declares another machine resolves to AD_HOC_SHOTSET_VERSION and can never be stamped under the frozen MAST label. scripts/spine_benchmark.py takes a --machine argument with no default and constructs its ad-hoc BenchShots with it; the parser itself refuses --shots without --machine, so a run cannot have a machine assumed for it. With no --shots the frozen set is used and --machine is not needed. No JT-60SA shot set is added, because its shots are not yet chosen — the machine-keyed label widening and the CLI declaration are the whole change.
