Machine in-vessel X-point box, passed to the shared equilibrium-label builder

  • The shared label builder now takes the coarse in-vessel box as an argument. imas_ambix/worldmodel/equilibrium_labels.py xpoint_null_set and build_geometry_from_arrays accept an optional box=(r_lo, r_hi, z_abs) threaded to _null_in_vessel. The default is MAST's XPOINT_VESSEL_R_RANGE=(0.1, 2.0) and XPOINT_VESSEL_Z_ABS=2.0, so every existing MAST caller and label is unchanged; a caller-supplied box overrides it.
  • The box is derived, never typed. _widen_limiter_box takes a limiter contour's R extent and |Z| extent and widens them by the margin MAST's box carries over MAST's measured extent (R∈[0.20, 1.90], |Z|≤1.83 against 0.1/2.0/2.0): +0.10 m on each R side and +0.17 m on |Z|. The margins are computed from the named MAST constants, not re-typed.
  • The OP1 phase store's wall limiter contour (maps/jt-60sa/machine_description/OP1/wall.nc, read through imas at DD 4.1.1 and reduced by imas_ambix.gs.artifact_geometry.read_artifact_limiter) spans R∈[1.705, 4.483] and |Z|≤3.0191 m (51 vertices).
  • The derived JT-60SA box is (1.605, 4.583, 3.1891) — R∈[1.605, 4.583] m, |Z|≤3.1891 m. It contains the whole OP1 limiter contour. An X-point at R=2.6 m, inside the limiter but outside MAST's R≤2.0 box, survives the loader where MAST's default would null it; an X-point at R=5.2 m, outside the limiter, is still nulled.
  • The SELENE reference loader (imas_ambix/eval/efit_referee.py _selene_psrc_loader) passes JT-60SA's box, derived once from the OP1 store via _jt60sa_xpoint_vessel_box. A caller may override it with a box keyword; the loader forwards it through the existing gated read_efit_geometry seam, so no second ungated read is added.
  • New tests: in tests/eval/test_selene_reference.py, an in-limiter synthetic X-point at R=2.6 m stays finite, an out-of-limiter X-point at R=5.2 m is nulled, and the derived box contains the whole OP1 limiter contour; in tests/worldmodel/test_equilibrium_labels.py, xpoint_null_set with an explicit box keeps a null the default box rejects.
  • Negative control: dropping the box argument from the loader's build_geometry_from_arrays call so MAST's default applies fails the in-limiter X-point test with a nulled slot (see the manifest's negative_control_log).
