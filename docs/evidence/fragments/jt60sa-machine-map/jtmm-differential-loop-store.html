The index convention and where it is stated

DD 4.1.1 documents magnetics/flux_loop/indices_differential as: “Indices (from the flux_loop array of structures) of the two loops used to build a differential measurement: loop(second index) − loop(first index). Use only if ../type/index = 6, leave empty otherwise.” The entry therefore names the two loops [first, second] and the value is loop(second) − loop(first). The indices address the flux_loop array of structures, whose own index runs 1...N in the DD (path_doc flux_loop(i1)/indices_differential(:)), so the values are 1-based loop numbers. Naming the reference loop 7 first makes each entry loop L minus the reference, matching the raw channel's measured difference. flux_loop/type/index = 1 is poloidal_flux and 6 is differential (magnetics_flux_loop_type_identifier).
