A differential flux-loop mapping is no longer usable as a positioned loop's list index

A type-6 differential flux loop carries no position, so its mapping's efm_index is a sentinel with no positioned loop behind it. The defect was that the declaration pass wrote that sentinel straight into the positioned-loop list, where a negative index is the last positioned loop: a catalogue declaration naming a differential channel silently replaced the last loop's coordinates instead of erroring. Every consumer that indexes or matches by efm_index now refuses or skips a mapping whose indices_differential is set.

  • _apply_flux_loop_position_declarations (imas_ambix/data/geometry_adapter.py) — refuses: a declaration whose channel names a differential mapping raises GeometryAdapterError before any list write, so the positioned loop the sentinel would have addressed is left intact.
  • Non-unique-claim pass (imas_ambix/gs/geometry.py) — skips: the pass matches m.kind == "flux_loop" and m.indices_differential is None and m.efm_index == i, so a differential mapping is never rebuilt into a positioned claim.
  • row_of_loop (imas_ambix/gs/operator.py) — already correct, verified, no change: _apply_differential_rows builds row_of_loop only from mappings whose indices_differential is None, then subtracts the two named rows for the differential rows themselves; the reverted efm_index is not None guard proved redundant against the base once the skip is keyed on the pair.
  • EFM identity binding (imas_ambix/spine_bench/transform_geometry_source.py) — skips: both the channel population fed to _signal_identity_matches and the rebind loop exclude mappings whose indices_differential is set, because a differential entry has no EFM column of its own to bind.
  • Artifact sensor map (imas_ambix/gs/artifact_geometry.py) — no change required, verified: _sensor_map only constructs positioned mappings (efm_index=i over b_probes and flux_loops) and no path in the module indexes or matches by efm_index; no differential mapping reaches it.
  • New test test_position_declaration_naming_a_differential_loop_is_refused in tests/gs/test_operator_differential_loops.py builds a synthetic three-loop geometry table plus one type-6 mapping (efm_index=-1, indices_differential=(0, 2)) and a declaration naming the differential channel, and requires GeometryAdapterError.
