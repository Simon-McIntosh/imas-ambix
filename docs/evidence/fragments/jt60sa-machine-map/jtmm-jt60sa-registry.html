the JT-60SA geometry registry read interface and its moved representation digest

Node jtmm-jt60sa-registry · date 2026-10-08 · plan jt60sa-machine-map §7

Jt60saGeometryRegistry (imas_ambix/gs/description_artifact.py) now exposes the five members the identity resolvers read from Nova's MachineGeometryRegistry: registry_digest and dd_version (already present); configurations keyed by physical digest, each entry a Jt60saConfiguration carrying that phase's physical_digest, its geometry and its authoring_gaps (that phase artifact's unresolved_gaps); select(shot), which returns a Jt60saSelection with .configuration and .evidence for the one phase range holding the shot and raises KeyError outside both ranges; and resolve_representation(digest), which returns the configuration a phase's representation alias names and raises KeyError for any other digest.

The two phase ranges are OP1 100001–101173 (observed) and OP2 101174–999999 (inherited). select(101173) returns OP1 with evidence observed; select(101174) returns OP2 with evidence inherited; select(99999) raises KeyError.

The setup representation digest formula that MachineArtifactGeometryReader.read held inline is now the public representation_digest in imas_ambix/gs/artifact_geometry.py: round_geometry_hash over the probe r, z and angle, the flux-loop r and z, the filament r, z, width and height, and the limiter r and z. The reader calls it with its output unchanged and the producer calls it over the same extracted parts, so a phase's alias cannot drift from the signature a reader stamps from the authored artifact. The aliases are hashed into the registry payload, so both phase artifacts carry the moved registry digest.

Each phase's alias is the signature digest a MachineArtifactGeometryReader stamps from that phase's authored artifact, and resolve_representation maps it back to the phase's configuration.

_coil_drive_weight's agreement band is now the catalogue's two-decimal rounding as an absolute 0.011 on the per-element ampere-turns, replacing the relative 1% band. The FPPC coils' 3.83/3.84 pair (one winding rounded to its last digit) is accepted; a 0.02 disagreement on a CS1 connection is refused by coil name.

build_jt60sa_registry_from_stores returns the registry built from the phase stores without materializing an artifact, so a machine-keyed identity registry can obtain the JT-60SA registry at its base rather than authoring artifacts first.
