The lead's ruling, 2026-10-06

The second reading holds. OP1 is the 2023 campaign, and the 2021 block is the integrated commissioning before it, on the same geometry. So every existing E-series pulse, E101154 and E101173 included, reads the OP1 description (EQSLE.DATA, 120-filament vessel). OP2 is the configuration after the enhancement shutdown. EDDB holds no OP2 pulse yet, so the OP2 map runs from 101174 to the top of the six-digit E-series numbering. The plan records this as the decision operating-phase-of-existing-pulses. As delivered, this record labelled the 2021 and 2023 blocks OP1 and OP2 and stamped the start times with a trailing Z. The labels above were changed at merge, and the Z was dropped because EDDB's start times carry no time zone.
