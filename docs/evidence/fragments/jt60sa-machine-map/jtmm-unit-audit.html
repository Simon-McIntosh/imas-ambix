JT-60SA unit audit

Every declared source_unit and target_unit in the three packaged signal maps (imas_ambix/data/maps/jt-60sa/*.json, 56 rules) and the machine-map catalogue (imas_ambix/data/machine_maps/jt-60sa.json, 168 bindings) resolves through the Data Dictionary unit vocabulary read from imas-python's bundled dictionaries at the catalogue's own DD version (4.1.1), and each target_unit equals the unit the DD declares on its bound leaf (a name or index leaf carries no DD unit, written as the dimensionless 1). The factor from each distinct (source, target) unit pair is derived from an SI base and prefix table and checked against one hand-computed value per pair.
