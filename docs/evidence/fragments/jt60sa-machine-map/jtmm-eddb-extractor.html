Built the ambix EDDB batch extractor and its on-demand cache: imas_ambix/data/eddb_remote.py reads a batch of (shot, category, dname) channels in one remote process over the module-loaded python 3.12, niced, with the ssh config path expanded at call time and a missing time base refused rather than invented; imas_ambix/data/eddb.py splits an EDDB shot token into its optional series letter and its digits, stores the pulse under the integer of the digits so the engine opens it as {int(shot)}.zarr, records the full token on the pulse group and refuses a second token sharing those digits, writes each raw channel with its EDDB unit, channel count and sequence number plus the EDDB time vector as a sibling array, and treats a channel as cached only when both arrays exist and agree in length — refusing an already-cached channel, completing a half-written one, and refusing a corrupt node rather than reporting it not cached; and JT60SA_ROOT is declared once in imas_ambix/data/paths.py.
