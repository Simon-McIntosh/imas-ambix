Built the ambix EDDB batch extractor and its on-demand cache: imas_ambix/data/eddb_remote.py reads a batch of (shot, category, dname) channels in one remote process over the module-loaded python 3.12, niced, with the ssh config path expanded at call time and a missing time base refused rather than invented; imas_ambix/data/eddb.py normalises the shot token to its integer form, writes each raw channel to {shot}.zarr/{category}/{dname} with its EDDB unit, channel count and sequence number plus the EDDB time vector as a sibling array, and refuses to overwrite one already cached through the one predicate the reader shares; and JT60SA_ROOT is declared once in imas_ambix/data/paths.py.
