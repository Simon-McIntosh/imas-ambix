JT-60SA OP1 plasma shot survey (nakasvr26, read-only)

Starts from the 228-shot table in imas-efit docs/jt60sa-shot-candidates.html without re-characterising it. The survey re-read the OP1 range E100001–E101173 through the EDDB library on nakasvr26 only to (a) establish plasma-shot membership by the table’s own rule (PSRC/calIp peak ≥ 50 kA) as a positive control and (b) add the one column the table lacks, peak β from the FAME category. The re-read reproduced exactly 228 plasma shots, matching the source table. calIp values are amperes (the EDDB unit label KA is a misnomer).

Catalogue tools read on nakasvr26

  • eddbreadCatTable() — lists all 73 EDDB categories (incl. FAME, PSRC) — command e.eddbreadCatTable()
  • eddbreadTable(shot, cat) — per-category catalogue: every descriptor with unit, class and description (100 FAME, 303 PSRC descriptors for E101154) — command e.eddbreadTable("E101154","FAME")
  • eddbreadChInfo(shot, cat) — per-shot channel inventory for a category — command e.eddbreadChInfo("E101154","FAME")
  • eddbreadShot(start,end) — shot list with start/end times, disruption and kind flags — command e.eddbreadShot("E100001","E101173")
  • eddbreadTime(shot, cat, dname) — one time series by category+descriptor (used for PSRC/calIp, FAME/BETA, FAME/VOLUM) — command e.eddbreadTime("E100748","PSRC","calIp")

All are methods of eddbWrapper in /analysis/src/eddb/eddb_pwrapper.py over /analysis/lib/libeddb.so (symbols eddbreadCatTable, eddbreadTable, eddbreadChInfo, eddbreadShot, eddbreadTime). Read-only; no data written to the site.

First JT-60SA plasma

E100599, 20231020 (14:17:48 JST) — the earliest EDDB shot carrying a PSRC/calIp plasma current above the 50 kA threshold: peak 76.1 kA over a 0.161 s window. Evidence: eddbreadTime("E100599","PSRC","calIp") returns a 644-point waveform rising to 76.1 kA; no earlier shot in E100001–E101173 has a calIp peak ≥ 50 kA (the 2021 E100001–E100353 block returns none). The first substantial plasma is E100613, 2023-10-23 17:30 (145 kA).
