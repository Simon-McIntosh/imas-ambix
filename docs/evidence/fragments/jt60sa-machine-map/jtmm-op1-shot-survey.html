JT-60SA OP1 plasma shot survey (nakasvr26, read-only)

Starts from the 228-shot table in imas-efit docs/jt60sa-shot-candidates.html without re-characterising it. The OP1 range E100001–E101173 was re-read through the EDDB library on nakasvr26 only to (a) establish plasma-shot membership by the table’s own rule (calIp peak ≥ 50 kA) as a positive control and (b) add the one column the table lacks, peak β from the FAME category. The re-read reproduced exactly 228 plasma shots, matching the source table. calIp values are amperes (the EDDB unit label KA is a misnomer); dates are UTC+9.

Catalogue tools read on nakasvr26

  • eddbreadCatTable() — lists all 73 EDDB categories (incl. FAME, PSRC) — command e.eddbreadCatTable()
  • eddbreadTable(shot, cat) — per-category catalogue: every descriptor with unit, class and description (100 FAME, 303 PSRC descriptors for E101154) — command e.eddbreadTable("E101154","FAME")
  • eddbreadChInfo(shot, cat) — per-shot channel inventory for a category — command e.eddbreadChInfo("E101154","FAME")
  • eddbreadShot(start, end) — shot list with start/end times, disruption and kind flags — command e.eddbreadShot("E100001","E101173")
  • eddbreadTime(shot, cat, dname) — one time series by category+descriptor (used for PSRC/calIp, FAME/BETA, FAME/VOLUM — command e.eddbreadTime("E100748","PSRC","calIp")

All are methods of eddbWrapper in /analysis/src/eddb/eddb_pwrapper.py over /analysis/lib/libeddb.so. Read-only; nothing was written to the site.

First JT-60SA plasma

E100599, 2023-10-20 14:17:48 — the earliest EDDB shot carrying a PSRC/calIp plasma current above the 50 kA threshold: peak 76.1 kA over a 0.161 s window. Evidence: eddbreadTime("E100599","PSRC","calIp") returns a 644-point waveform rising to 76.1 kA, and no earlier shot in the range reaches 50 kA (the 2021 E100001–E100353 block returns none). The first substantial plasma is E100613, 2023-10-23 17:30, peak 144.6 kA.

OP1 plasma shots by the three figures of merit

Every ranked shot carries a PSRC reconstruction — a calIp peak ≥ 50 kA is the membership criterion — so PSRC presence is universal in the tables below; the FAME column marks an additional FAME offline reconstruction.
