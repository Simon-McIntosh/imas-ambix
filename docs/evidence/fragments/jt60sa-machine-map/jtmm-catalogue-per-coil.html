The JT-60SA catalogue reads both phases through one machine-name-free path

Node jtmm-catalogue-per-coil · date 2026-10-06 · plan jt60sa-machine-map §4

imas_ambix/data/machine_maps/jt-60sa.json declares the converted SELENE-deck description under JT60SA_DESCRIPTION_DIR as a netcdf / static-over-map store with probe_angle_source description, and two range-scoped maps: OP1 (100001–101173) and OP2 (101174–999999). A shot selects the map, the map selects the phase directory, and no module compares the machine name to choose a description.

Declaration

Every ragged struct array in the five IDS is declared one binding family and one structure assembly per entry, addressed by the entry name the re-converted store carries. The twelve pf_active coils (CS1–CS4, EF1–EF6, FPPC_UP, FPPC_DOWN) each have a -coordinate-element, -r, -z, -width and -height binding with struct_array_entry set to the coil name and source_rank 1 (the leaf plus the element struct level below the selected coil). The OP1 vessel is declared per loop (VV1 63, VV2 57) and the OP2 vessel as its single loop VV1 (98); the phase-specific vessel bindings sit in the phase's own binding set, so each map reads only the loops its store holds.
