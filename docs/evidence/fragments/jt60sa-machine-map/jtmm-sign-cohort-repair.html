JT-60SA sign report states only what its own cohort measures

The sign report in imas_ambix/data/cocos_convention.py printed MAST's fixed blocks — the coefficient classification, the determinable relative-sign products, the COCOS 3 versus 4 note, the recommendation and the Ip-like consequence — for any cohort, and modelled every row's declared poloidal-flux exponent as MAST's hard-coded 0. The equilibrium JT-60SA reads through read_signal_map_observation carries no psi grid, so that exponent was never measured: the fixed 0 was an unwarranted claim. The report now prints those blocks only for the MAST level-2 cohort. For any other cohort it states the classification its own rows support, and a row whose equilibrium carries no psi records flux_exponent=None, leaves the declared-flux-exponent check unscored with that reason, and scopes the recommendation and the Ip-like consequence to MAST.

Scored against the same 16 JT-60SA rows, the repaired report's verdict is 4 conventions survive: (1, 2, 11, 12), where the hard-coded exponent had restricted it to (1, 2) by claiming a flux exponent the source cannot carry (coordinator correction at landing: the superseded report at a8c1d7a3 reads VERDICT: 2 conventions survive: (1, 2), as the independent review confirmed). The two surviving cohorts are the sigma_Bp and sigma_rho_theta_phi relations the raw absolute flux-loop response and the q relation actually measure: sigma_Bp fixed by the raw absolute flux-loop response, sigma_rho_theta_phi fixed by sign(q) = sign(Ip)·sign(B0)·sigma_rho_theta_phi, and sigma_R_phi_Z and e_Bp left undetermined because no row measures the direction of positive toroidal angle and the equilibrium carries no psi grid. The report names E101011's G-EQDSK/§7 as the source that would fix e_Bp.

MAST's report text and MAST_LEVEL2_SIGN_TABLE scores are unchanged, pinned by a test: the MAST cohort still reports 2 conventions survive: (3, 4) and the same coefficient classification and recommendation lines it reported before this change. The change is inert for MAST because the MAST level-2 cohort declares its own exponent and is recognised as its own cohort.

Two new tests pin the cohort boundaries this repair rests on. The single-absolute-loop consensus test confirms that a row with one agreeing absolute loop is not a consensus violation, while a split two-channel row still is. The interval-alignment test confirms that a loop series beginning one sampling interval after the query time is accepted and a wider gap is refused. A third test pins the no-psi row: the declared-flux-exponent relation is unscored and the report names E101011's G-EQDSK/§7 as the fix.

The cohort script scripts/jt60sa_sign_cohort.py regenerates jtmm-sign-cohort.html and its figure its per-channel vacuum slope figure, so the published artifact carries the corrected verdict and the cohort's own statement.
