selene deck converter: the facility decks become receipted per-phase IDS netCDF

Node jtmm-selene-deck-converter · date 2026-10-05 · plan jt60sa-machine-map §4

imas_ambix/data/selene_deck.py parses the three facility grammars — EQSLE.DATA (the PF COIL block, the NV vessel block, the TFC inside/outside arc segments and the limiter/first-wall segment table), geo.in (the Magnetic Probe and Flux Loop blocks) and coil_vv_*.dat (its vessel block and its limiter contour) — into provenance-carrying element types, and writes the pf_active, pf_passive, magnetics, wall and tf IDS netCDF for a phase at DD 4.1.1 alongside a receipt.json naming each source file's path, sha256, line ranges and the converter's git commit. pf_active coils carry positive turns with winding direction in pf_active/circuit/connections; the angular geo.in probe angle is converted degrees→radians for the DD leaf. The deck's extent columns (dR dZ for a PF coil, Va Vb for a vessel filament) are whole extents, so each element's rectangle width and height come straight from the column with no factor of two. Each contiguous block of vessel filaments that shares one resistivity becomes its own pf_passive loop carrying that value, so the deck's 63/57 split at 7.76e-7 and 7.20e-7 ohm m survives the round trip. Where the deck states no TF turn or coil count, the tf field is left unset and recorded in the receipt's validation_gaps rather than written as a guessed zero. Each TFC segment becomes one tf conductor element — a line runs from its first to its second point, an arc from its start to its end angle with its circle centre in the element centre and the DD arc type — so no element has zero length, and the wall outline keeps the arcs and the straight segments alike by sampling each arc along its circle. When a coil_vv deck is supplied the wall is that phase's own contour: the nlim block's vertices become the line segments of the closed OP2 limiter, while the OP1 wall stays on EQSLE.DATA's 43-segment limiter and first-wall table, so the two phases carry different outlines and each element bears the source path and sha256 of the deck it came from. wall/description_2d[0]/type/index is set to 1, the DD identifier for limiter units described with no vessel structure filled.
