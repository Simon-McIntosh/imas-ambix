agent watch now reads the telemetry index read-only. Its report is no longer what keeps the store current: the standing agent ingest service owns the write, and a report reads what that service has already written. This removes the cold catch-up a reader used to pay -- over 300 s on 2026-09-29 -- because a read no longer scans the whole record to bring the index up before answering.

The defect, reproduced before it was repaired. watch_text and watch_document each called discover(directory) and index.ingest(sources) before rendering, so a read appended whatever the record had gained since the last pass. A fixture index was built from a receipts directory, a second source was then written into that directory, and the watch call was pointed at it. Under the old path the index's own file bytes and its sample_count() both moved -- the read had ingested the new source. With the repair both are exactly what the ingest pass left.

The read-only handle. TelemetryIndex.readonly opens an existing index through a SQLite URI in mode=ro with a five-second busy timeout. It runs neither the schema script nor a migration, and creates neither the file nor its parent directory: a path with no file raises sqlite3.OperationalError rather than materialising an empty index, because a reader that created its own store would report an empty record for a fleet whose ingest has simply not run yet. A write attempted through the handle is refused by SQLite itself, which the tests assert with pytest.raises(sqlite3.OperationalError) around an INSERT.

What the outputs now say. With a file present, both the text and the JSON document carry the index's path and its last-ingest time, taken as the file's modification time in UTC to the second, with its age in seconds. The test sets that modification time through os.utime and asserts the reported last_ingest_at equals the literal 2027-01-15T08:00:00Z. With no file, the text states that no index exists at that path and that the fleet's ingest service (imas-ambix agent ingest) maintains it, prints no period or ledger rows, and the JSON document carries index.exists = false with the path and empty period rows. The path and its parent are still absent afterwards. The --live path is untouched and still constructs no index.
