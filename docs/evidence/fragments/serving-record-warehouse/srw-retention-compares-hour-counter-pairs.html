The retention check compares hour-and-counter pairs and skips pairs no tier carries

Node srw-retention-compares-hour-counter-pairs · date 2026-10-02 · worktree imas-ambix-0405601943d2/0c4316b2-553f-4a0a-ae02-c42d88de747c/srw-retention-compares-hour-counter-pairs

compare_tiers judged a raw receipt against its compactions by totalling every UTC hour the job spans and refusing the file whenever the three tiers were not all present. A row's counter is only recorded once the recorder's row vocabulary carries the engine block, so a file whose early rows predate it — job 1273253's shape — reads as a disagreement in every hour before that byte offset even though no tier ever recorded the counter there. The comparison now works on (hour, counter) pairs.

What changed

  • imas_ambix/agent/telemetry_retention.py: compare_tiers returns a TierComparison carrying one CounterComparison per counter plus the number of compared pairs and their distinct hours. Per pair: absent in every tier — no tier's rows in that hour carry the counter — the pair is skipped; a pair present in some tiers and absent in others is a disagreement; a pair present in all three is compared, and agrees when the raw, minute and hour partitioned totals are equal. A tier's presence for a pair is decided by the rows themselves (_window_holds_counter), so an hour whose rows exist but carry no counter reads as absent. FileVerdict gains compared_pairs and compared_hours; a file is eligible only once at least one pair was compared and every compared pair agrees, and a file with no compared pair is kept with the reason no hour carries the counters. render_listing and the manifest print both counts per file.
  • tests/test_telemetry_retention.py: four new tests. A hybrid file whose old-format hours carry no counter in any tier and whose covered hours agree is eligible (6 compared pairs over 2 hours). A pure old-format file is kept with the new reason and 0 compared pairs. A pair present in raw and hour but absent in minute is refused. A pair present in all three with unequal totals is refused, and was compared rather than skipped. A fifth test asserts the listing prints both counts.
