The index's tier fall-through skips a raw file with no parseable row

Node srw-index-falls-through-a-raw-file-with-no-parseable-row · date 2026-10-02 · worktree imas-ambix-0405601943d2/0c4316b2-553f-4a0a-ae02-c42d88de747c/srw-index-falls-through-a-raw-file-with-no-parseable-row

The tier fall-through keyed absence on a non-blank line alone, so a raw receipts file holding a line that was present but not a record was still offered as the finest tier. The job was pinned to a file carrying no sample, and its window read as uncovered while the minute tier that held its rows went unread. The predicate now judges a line by whether it parses as a JSON object, mirroring the reader's own record grammar, so a raw file whose every line fails to parse is absent exactly as a blank one is. A raw file holding at least one parseable record is still offered, so a later unreadable line is refused in place by the read rather than hidden.
