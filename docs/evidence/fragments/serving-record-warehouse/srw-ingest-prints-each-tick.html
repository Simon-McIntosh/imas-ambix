§5 — The ingest prints one flushed line per tick

Landed imas_ambix/agent/cli.py: agent ingest now passes an on_tick callback to telemetry_ingest.run, which the loop already accepted and invokes once per tick after each pass completes. The callback writes exactly one line to stdout and flushes it, so the fleet allocation's service log shows the loop is alive rather than silent between restarts. The line is stamped with the UTC wall clock time the tick finished, to the second, and names the counts the tick discovered, read and skipped and what the index scanned, inserted, found duplicate or malformed, and read in bytes:

2026-10-02T08:30:04Z ingest tick discovered=118 read=3 skipped=115 scanned=3 inserted=240 duplicate=0 malformed=0 bytes=51234

The stamp is taken at the moment the callback runs, which is immediately after the tick returns, so it marks the tick's completion to the second. The counts come from the TickReport (files_discovered, files_read, files_skipped) and its nested IngestReport (files_scanned, rows_inserted, rows_duplicate, malformed, bytes_read). The line is printed unconditionally, so a tick that discovers and reads nothing still marks the loop as running. The ingest help names the per-tick line and its fields, so the format is discoverable from --help. No other module changes: the loop and its on_tick seam live in tests/test_agent_ingest_cli.py and telemetry_ingest.run already exposed on_tick, which telemetry_ingest.py is left unedited to prove.

Measure. tests/test_agent_ingest_cli.py gains three tests. Two fixtures with distinct counts are handed to on_tick through a stubbed telemetry_ingest.run that drives the real agent ingest command, with the clock frozen by patching cli._utc_now — the command prints two lines, each asserted equal to a literal built from its own fixture's counts and the frozen stamp (discovered=118 … bytes=51234 then discovered=120 … bytes=2048). A second test replaces cli.sys.stdout with a stand-in that records every write and flush call, and asserts the ordering directly: write line 1, flush, write line 2, flush. A third asserts the ingest --help output contains ingest tick and each field name.
