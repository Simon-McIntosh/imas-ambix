imas_ambix/agent/cache_estimate.py derives the third-party cache hit rate from request receipts: a request is a hit when the same caller's previous request to the same model arrived strictly inside the cache lifetime, arrival being the row's timestamp minus its duration. The caller is run_id, else coordinator_session, else none (never a hit). h is hit prompt tokens over all prompt tokens.
