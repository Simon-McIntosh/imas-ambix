The index's tier fall-through skips any tier file with no parseable row

Node srw-index-falls-through-any-tier-with-no-parseable-row · date 2026-10-02 · worktree imas-ambix-0405601943d2/0c4316b2-553f-4a0a-ae02-c42d88de747c/srw-index-falls-through-any-tier-with-no-parseable-row

The check that drops a tier file carrying no record line was restricted to the raw tier, so a minute file whose every line was blank or unparseable was still offered as the job's finest tier. The job was pinned to a file with no samples and its window read as uncovered while the hour file that held its rows went unread. The check now judges the file rather than its resolution: any tier file, raw, minute or hour, with no parseable record line is dropped and the selection falls through to the finest tier that carries rows.
