The lane document's live_runs, capacity, margin and worker_slots now come from one _AdmissionLedger record. A run is live while a request of it is in service, while it waits at the gate, or while it made a request inside the working horizon the per-session share uses (WORKING_HORIZON_SECONDS, 180 s); a run that ended inside that horizon holds a slot, one that ended earlier holds none. Capacity is floor(margin * width / offered_load), the margin is read from the gate's control file and defaults to 1.25, and slots are the capacity less the live runs, zero on a paused verdict. The old capacity sized from every run in the averaging window is gone, not kept beside the new one.
