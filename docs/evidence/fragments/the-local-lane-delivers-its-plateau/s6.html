Window utilisation and the split of time below width

The lane document's admission block carries a utilisation object with two windows — the averaging window and the last hour — each stating the mean requests in service, the share of time at the gate width, the delivered completion-token rate, the plateau rate estimated from the same requests, and a partition of the time spent below width into slots_offered_not_taken_seconds and no_slots_offered_seconds. Both windows are cut from one record of request intervals: the admission ledger the slot figures already read, which now also records when each request arrived at the gate and the completion tokens its relay accounted, and retains intervals for the longer of the slot window and an hour. mean_in_service is published beside the block as the same window figure.

A slot is offered at an instant while the capacity its own window's offered load implies exceeds the runs live then; a run is live while one of its requests is in service or it was admitted within the working horizon. A paused gate offers none, and the pause is recorded when it happens because publication runs after it; the same pause record is what carries a pause that has since ended. Pool composition drops the block rather than copying one engine's figures under a pool's name.
