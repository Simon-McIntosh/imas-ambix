Gate wait bound: measured instrument

Implementation: _AdmissionLedger.snapshot publishes gate_wait_p90_seconds over the same record's last five minutes and zeroes worker_slots while it exceeds wait_bound_seconds (read from the gate's control file, 30 s by default). One field, worker_slots_reason, names a pause or a wait closure.

High-margin run (the pass condition the plan states)

§5's done-when asks for a margin at which the bound-disabled arm exceeds 45 s p90 in some five-minute window while the bound-enabled arm stays under 45 s in every settled window. At the default margin the offered-load rule holds the pool at that margin's equilibrium, so the two arms agree and the scenario does not arise; the run below is the calibration that reaches it, and it is the node's stated measure.

§3 instrument calibrated from the committed fed window 04:45–06:40 UTC on 18 November, 4.5 h, bound 30 s, margin 2.6. Five-minute windows start at the end of the 1800 s warm-up; the settled set drops the first ten minutes after it.
