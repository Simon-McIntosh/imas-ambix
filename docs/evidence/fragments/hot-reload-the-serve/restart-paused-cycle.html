Paused engine reload

agent restart now runs through an isolated reload coordinator. It selects the serve through the shared scheduler helper, saves the running batch script, pauses the admission gate, and cancels the old job only after a fresh measured lane reading reports zero. The replacement must reach scheduler RUNNING, pass /v1/models, and return at least 200 completion tokens. Failed readiness or validation resubmits the saved script. The coordinator resumes every pause it owns and records the cycle in lane-cycles.jsonl. The runbook's manual pause, relaunch, validation and resume steps are replaced by the restart command.

Evidence: 38 cycle, pause and dry-run tests passed; restart-specific CLI tests passed (2); the serving-interpreter parse test passed (1); whole-tree Ruff passed. The required combined gate also ran, with 222 passing and three failures in unchanged serve-help and clive checks: test_agent_serve_gpu_help_matches_core_scaling and the two parameter cases of test_clive_openrouter_opt_in_starts_proxy_and_presents_picker. Their implementation is outside this node's granted paths.
