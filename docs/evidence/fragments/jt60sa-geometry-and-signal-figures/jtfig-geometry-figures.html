JT-60SA OP1 and OP2 geometry, rendered through imas-ink

Two figures of the JT-60SA poloidal cross-section, read from the converted description store addressed through the packaged jt-60sa machine map (load_packaged_machine_map("jt-60sa") joined with description_store_root_path(); each phase opened with NetCDFTransformEngine.open and its wall, pf_active and magnetics IDSs read with imas.DBEntry). Both figures are drawn entirely by imas-ink: imas_ink.extract.extract_geometry feeds imas_ink.figures.geometry_figure_mpl in imas-ink's own DEFAULT_STYLE; the script scripts/figures_jt60sa_geometry.py lays out the axes and draws no element, holds no colour, label or style constant of its own, and writes exactly the two SVGs embedded below — no PNG twin.

The measure: uv run --no-sync ruff check imas_ambix tests scripts/figures_jt60sa_geometry.py exits 0, and the script prints the per-phase counts above, each equal to the count the store holds before extraction.
