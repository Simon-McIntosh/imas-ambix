The cached JT-60SA signals, drawn through imas-ink

imas_ambix/data/eddb.py gains read_channel(cache_root, shot, category, dname) beside write_channel, the raw read the cache did not have. It returns the same ChannelRecord the writer stored — the two-dimensional data array, the channel's own time base and the UNIT_ATTR unit — read from channel_path and channel_time_path; an absent or half-written channel is refused rather than reported as an empty record. The module docstring now names read_channel as the raw read beside the engine path instead of saying the cache needs no cache-specific reader. The section adds this one public name and retires nothing.

scripts/figures_jt60sa_signals.py draws three figures and holds no colour, label or style constant of its own. It reads only the cache under JT60SA_ROOT. The channels it draws, and the factor it applies, come from the packaged maps: load_packaged_signal_map("jt-60sa", "pf_active") serves the MMSYS coil-current chain chosen for each PF coil and load_packaged_signal_map("jt-60sa", "magnetics") the PSRC plasma current. Each bound channel's values come through the engine path those maps feed (VirtualZarrView, whose VirtualArray applies the signal's factors), and its unit is taken from VirtualArray.attrs; every channel's time base — and every flux-loop channel, which the maps leave unbound — is read whole through read_channel. The figures render through imas_ink.figures.time_trace_figure_mpl in DEFAULT_STYLE and are written through imas_ink.io.render_to_bytes, so the drawn paths take the resolution bound the style sets; the only style the script names is the replace that dashes the raw flux loop. No series carries a legend label: each panel's first series names the EDDB channel it draws (rule.source_array, for example curCS1LKAT or Ip) and its unit on the y-axis, and the stacked panels share one time axis, labelled once at the bottom of the figure. The served signal each bound channel feeds (rule.semantic_id) is named in the printed report and in the captions below, not on the axis, so the labels stay short enough to fit a panel. Per figure the script prints the served signal names and units it drew and says when a channel's time base differs from its neighbour's.
