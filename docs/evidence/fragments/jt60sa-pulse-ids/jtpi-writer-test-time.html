tests/data/test_pulse_writer.py::test_write_covers_every_description_ids had hard-coded homogeneous_time == 1 for a fixed set of three IDSs. That held while magnetics served only ip; it is wrong now that the map serves 45 magnetics signals on more than one time base, so the writer correctly writes magnetics with homogeneous_time = 0 and each leaf carrying its own time vector. The test now derives the expected value from the writer's own receipt: 1 when every leaf the receipt names for the IDS carries its base at the IDS-level {ids}/time path, 0 when the leaves carry their own time vectors, 2 when the IDS has no time-dependent leaf. For a heterogeneous IDS it also resolves each leaf's time_path and asserts each written element's time vector has as many samples as the leaf's data. The receipt path names the struct array rather than the element, so the resolver expands every element the writer filled. No imas_alambic source changed.
