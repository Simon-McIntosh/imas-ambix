A restart now validates a tool call and the checkpoint index

imas-ambix agent restart accepts a replacement only when it both completes text and answers a tool call in each dialect. The OpenAI-dialect check is the formerly inline check from the tools benchmark category, factored into bench.check_tool_call; the Anthropic dialect check is bench.check_tool_use. Both are wired into the validate callback the paused and overlap cycles already take (cli.py), so a failing probe restores the saved script and resumes in the pause path, and leaves the old serve routed while cancelling the held replacement in the overlap path. Before anything is paused, weights_preflight reads the profile's own model.safetensors.index.json and every shard it names; a missing file refuses the restart, and --dry-run prints the same verdict without touching the lane.
