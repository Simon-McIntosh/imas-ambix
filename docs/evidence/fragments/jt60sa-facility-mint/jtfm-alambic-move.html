the mint engine is a workspace member with by-name bundle discovery

Node jtfm-alambic-move · date 2026-10-07 · plan jt60sa-facility-mint §2 · commit d97a9302

The mint engine moved into packages/imas-alambic (import imas_alambic) by git mv: machine_map, signal_map, transform_engine, virtual_zarr, eddb, eddb_remote, pulse_mint and the COCOS layer, with the map schema. It declares requires-python ≥ 3.12, its own hatch-vcs version, and depends only on numpy, imas-python, zarr, pyyaml and nova-cocos. The engine's packaged roots and its lookup against ambix's paths module are replaced by bundle discovery over the imas_alambic.bundles entry-point group and IMAS_ALAMBIC_MAP_PATH; ambix's entry-point target returns a MapBundle whose named store roots come from imas_ambix.data.paths, so a store-root path has one owner and the directory layout has one description. The COCOS layer depends on the standalone nova_cocos distribution, which installs on Python 3.12, so every engine module imports in a clean environment. The mint retires from imas-ambix data and becomes imas-alambic mint.
