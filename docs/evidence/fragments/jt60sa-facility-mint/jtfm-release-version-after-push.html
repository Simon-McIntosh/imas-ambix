the local bundle version is written only after the push succeeds, atomically

Node jtfm-release-version-after-push · date 2026-10-08 · plan jt60sa-facility-mint §18 · node 98dci4-clu-2002 job 1281970

In imas_ambix/maps_cli.py, release no longer writes the local bundle.json before the push: stage_bundle already carries the version into the staged copy, so the local descriptor is written only after push_tree returns, and the read-and-restore of the original bytes on push failure is removed because nothing local changes before the push. _write_bundle_version writes to a sibling temporary file in the same directory and moves it over the original with os.replace, so neither a concurrent reader nor an interrupted write sees a partial descriptor. The replacement takes the descriptor's own permission bits before it is moved into place, so the 0600 mode mkstemp gives it does not become the published descriptor's mode; the mode is taken through stat.S_IMODE, so only the permission bits reach os.chmod and not the file-type bits st_mode carries. released_paths leaves out a stray bundle.json.*.tmp, so a process killed between the mkstemp and the os.replace cannot put that file into the tree digest or the staged tree.

Measure: tests/test_maps_cli.py runs whole at base 033d84d6 (27 passed) and head 8af5104d (32 passed), each to a log ending in the pytest summary and an EXIT= line; the five added tests are a stubbed-push_tree test that reads the local descriptor mid-push and asserts it still names the deployed version, a test whose os.replace raises and that asserts the original bytes are intact, a test that places a stray bundle.json.<x>.tmp in the machine directory and asserts the digest and the staged tree are unchanged by it, a test that pins a 0644 descriptor at 0644 after a release, and a test that records the modes passed to os.chmod and rejects any carrying file-type bits. The existing failed-push test still passes.

Negative control: moving the local write back before the push makes the during-push test fail (EXIT=1, test_release_leaves_the_local_bundle_unpublished_while_the_push_runs), and reverting the chmod to the raw st_mode makes test_release_chmods_only_permission_bits fail (EXIT=1). uv run --no-sync ruff check imas_ambix tests packages exits 0. All tests use the stubbed registry with no network call.
