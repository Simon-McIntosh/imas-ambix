a write fetches the EDDB channels its signal maps declare before writing the pulse

Node jtfm-write-fetch · date 2026-10-07 · plan jt60sa-facility-mint §15 · commit c5d959a2 · node 98dci4-clu-2018 job 1277272

At the facility the EDDB cache is empty, so a write of an uncached pulse had no channels to read and refused. write_pulse now builds one ChannelRequest per distinct (category, dname) the signal maps declare, addressed by the pulse's full EDDB token, and passes them to eddb.fetch_channels before it reads anything; a channel already cached makes no transport call. The transport is a setting: settings.py resolves eddb_host from --eddb-host, then IMAS_ALAMBIC_EDDB_HOST, then unset, and eddb_remote.extractor_for_host is the one owner of the setting-to-transport mapping — unset keeps the ssh route to jt-60sa, a host name composes it through ssh_command_for_host (keeping -F ~/.ssh/config and the remote module-load shell), and local gives an empty ssh_command with the engine's own interpreter as remote_python, because the analysis server's default python lacks numpy. DEFAULT_SSH_COMMAND is ssh_command_for_host("jt-60sa") and imas-alambic config prints eddb_host with its source. A channel EDDB refuses is skipped rather than read — the view would refuse an uncached channel — and stays visible on a new WriteReceipt.refused field, so the write proceeds and the refusal is reported. The installed launcher exports IMAS_ALAMBIC_EDDB_HOST=local beside IMAS_ALAMBIC_HOME, so the facility reads EDDB in place rather than hopping back over ssh.

test_write_fetch.py drives the write against a synthetic flat bundle and eddb_standin.py over the local transport: a write on pulse 900001 with no cache fetches its mapped channels and writes ids/900001_0.nc (one transport call), a second write with overwrite makes no further call, and a refused channel is reported with its code while the served channel is written and the refused one stays uncached. test_settings.py pins the flag-beats- variable precedence, the unset jt-60sa ssh route, the local transport with sys.executable, the composed ssh command keeping the config file and the module shell, the config line and the launcher's export. Gate: whole-tree ruff exit 0; packages/imas-alambic/tests 50 passed, EXIT=0, against a base of 42 passed; negative control — a write that skips the fetch — fails the no-cache test with the existing no-EDDB-cache refusal, EXIT=1.
