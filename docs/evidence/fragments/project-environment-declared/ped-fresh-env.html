Collection gap: the suite does not collect under a plain sync

Two test modules error during collection in the fresh environment because they import apps.playable.camera from the nova sibling, which imports bokeh at module level:

  • tests/worldmodel/test_nova_frame_decoder_contract.py
  • tests/worldmodel/test_flux_conditioned_decoder.py

bokeh is declared only in the viz extra of imas-ambix (and the bokeh extra of nova), so a default uv sync installs neither and the import fails with ModuleNotFoundError: No module named 'bokeh'. The shared environment carries bokeh 3.10.0, which is why it collects those seven tests. The two counts therefore differ: 3980 + 2 errors fresh against 3987 shared. This is a declaration/coverage gap outside this node's write scope; it is recorded for a later section rather than fixed here.
