The fresh-environment import walk, carried by the census module

Node ped-import-walk · import walk joined to tests/test_declared_dependencies.py

The fresh-environment import walk moves from the §4 run directory into the tree. One function writes the hand-off — the optional distribution set from build_census() and module_distribution_map() — to a JSON path; one imports every module under imas_ambix/ in the running interpreter and classifies each failure against that hand-off; and main gains the two modes. No new module is added: the census module already owns the optional boundary and the module-to-distribution map, and its entry point already exists.

Classification rule

  • A module outside an optional subsystem root (OPTIONAL_SUBSYSTEM_ROOTS) must import; any failure is a hard failure.
  • A module inside one may fail only with ModuleNotFoundError naming a module the hand-off resolves to a distribution the census classes optional; that is optional-missing.
  • Anything else — a failure outside the optional roots, a missing module that maps to no optional distribution, or an exception that is not ModuleNotFoundError — is a hard failure.

Unit test: the classifier on synthetic modules

test_walk_classifies_synthetic_import_failures builds a synthetic package under tmp_path, adds it to sys.path, and points the walk at it with a synthetic hand-off. Each case asserts the classifier's verdict, so a mutation that widens the rule turns one red:

Synthetic moduleOutcome
optional-root module missing an optional distribution optional-missing (passes)
optional-root module missing a default distribution hard failure — the case the declared mutation breaks
non-optional module that fails to importhard failure
module raising an error other than ModuleNotFoundError hard failure
