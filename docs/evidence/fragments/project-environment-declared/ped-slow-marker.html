Registering the slow marker in the pytest configuration

Node ped-slow-marker · revision 40d0280a · fleet compute node 98dci4-clu-2018, job 1277272 · run r-20261005T202405168165

tests/latent/test_synthetic_truth.py and tests/latent/test_temporal_operator.py carried @pytest.mark.slow while the configuration registered no such marker, so --strict-markers (set in [tool.pytest.ini_options]) refused to collect either file. The marker is declared once in pyproject.toml as "slow: a test that runs long by design", which is the only change to product configuration; the two files then collect.
