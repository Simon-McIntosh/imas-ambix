Refuse a hand-off target the Data Dictionary does not define

The imas-codex coils re-export carries one row targeting tf/coil/conductor/current/data, a path DD 4.1.1 does not define (conductor has no current element). Before the change score-handoff aborted on that row with a KeyError raised from the COCOS-label lookup, hiding the score of every other row. The import now reports such a row as unresolved, naming the path and the hand-off's DD version, and the scorer's label lookup declines a path its dictionary does not define instead of raising from the walk.

Reproduction before the change, on /work/projects/imas_gpu/jt60sa/handoff/jt-60sa-coils-handoff.json: 

$ imas-ambix maps score-handoff jt-60sa /work/projects/imas_gpu/jt60sa/handoff/jt-60sa-coils-handoff.json
Error: "Invalid path 'coil/conductor/current/data', 'conductor' does not have a 'current' element."
EXIT=1
