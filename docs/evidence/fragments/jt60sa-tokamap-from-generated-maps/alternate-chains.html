Declared alternate acquisition chains

A hand-built SignalRule may now carry an optional alternate_sources array. Each entry names another acquisition chain that measures the same quantity, as source_group, source_array and evidence. The field is validated on load, and a rule without it serialises byte-for-byte as before: as_dict omits the key when the list is empty, so a map that declares no alternate round-trips unchanged.

The hand-off score gains a chain_differs count, beside conflicting, on every IDS, structure and total row. An imported rule on a hand-built target whose source matches a chain the target's rule declares as an alternate is listed under chain_differs with both arrays — the imported (source_group, source_array) and the hand-built (source_group, source_array) — and is not counted under conflicting. The match is on declared alternates only; nothing is inferred from array names.
