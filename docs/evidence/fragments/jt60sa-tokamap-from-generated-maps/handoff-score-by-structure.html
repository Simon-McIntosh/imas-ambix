Score each system, not only each IDS

The hand-off score now groups every row by structure as well as by IDS. A structure is the target path's first segment after the IDS name, so magnetics/b_field_pol_probe, magnetics/ip and magnetics/flux_loop score as separate rows under one magnetics IDS, and pf_active/coil stays distinct from tf/coil when the coils export arrives. score_handoff returns a by_structure block beside by_ids and the total. Each structure's agreement is compared against hand-built rules for that same structure, so a structure with no hand-built rules reads no reference. The IDS-level rows are unchanged and the structure rows reconcile to them: the structure exported, imported, unplaced and refused counts sum to the IDS row's, and a structure carrying rows but no values reads no reference.

Focused tests: tests/data/test_handoff_score.py splits one IDS's rows across two structures (test_one_ids_splits_into_separate_structure_rows) with separate five-number rows — magnetics/b_field_pol_probe at exported 4, imported 2, agreeing 1, unplaced 1, refused 1, and magnetics/flux_loop at exported 1, imported 0, agreeing no reference, unplaced 0, refused 1 — so a structure without hand-built rules reads no reference rather than borrowing its sibling's rules.
