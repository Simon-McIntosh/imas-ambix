Score the JT-60SA magnetics, ECH and gas hand-offs

Three more imas-codex re-enrichment exports were scored with imas-ambix maps score-handoff jt-60sa <file> --json <out>. The JT-60SA machine description holds a store only for magnetics, pf_active, pf_passive, tf and wall, so the ec_launchers and gas_injection IDSs have no store to place their rows against. The scorer now names that cause per IDS — no machine-description store for <ids> — as an unplaced reason, and reports it apart from a row that carries no member pattern at all. The score JSON gained an unplaced_reasons counter (per IDS, per structure and in total), which the printed table now lists alongside the refused reasons.

Conflicts, with both source arrays

None of the three hand-offs carries a conflicting row: conflicting is 0 in every by_ids, by_structure and total entry, so every conflicts array is empty. magnetics/flux_loop imports all 6 rows but agrees with 0 hand-built loops (the hand-built flux_loop rules bind other members), and magnetics/b_field_pol_probe agrees on 10 of its 11 imported rows; neither disagreement is a conflict, which is reserved for an imported row whose target the hand-built rows already bind to a different source array.

Unplaced reasons, counted

The unplaced rows are classified by the scorer as the importer's unresolved rows whose reason the scorer reads as unplaced (member identifier …, no machine-description member array, no machine-description store for … or target path, member identifier …).

  • magnetics — unplaced 7: member identifier '18'…'23' has no identity match in machine-description magnetics/b_field_pol_probe (6, one reason per member), no machine-description member array covers magnetics/b_field_phi_probe/field/data (1). Refused 2: source_property='value' cannot target time (1), value partner unresolved: no machine-description member array covers magnetics/b_field_phi_probe/field/data (1).
  • ec_launchers — unplaced 18 split between the two causes: no machine-description store for ec_launchers (7 — rows carrying a member identifier) and target path, member identifier, and source array are required (11 — rows whose member_identifier is null). Refused 3: unexpanded: ec_launchers/beam/o_mode_fraction was deprecated in DD 4.1.0 and is not part of DD 4.1.1 (3).
  • gas_injection — unplaced 5, all target path, member identifier, and source array are required (every gas row carries a null member_identifier, so the missing-pattern cause names them before the missing store does). Refused 0.

The split is what lets imas-codex's study read the two causes apart: on ec_launchers the 7 member-carrying rows are held by the absent store, while gas_injection's 5 rows are held by the missing member pattern. The unit test test_an_ids_without_a_description_store_is_reported_unplaced_by_name pins the split; the CLI-path test test_scoring_can_leave_an_ids_without_description_members_unplaced pins that a store-less IDS does not abort the score.
