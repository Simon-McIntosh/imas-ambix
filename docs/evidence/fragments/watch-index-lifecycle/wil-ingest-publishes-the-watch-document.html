Before the change, the CLI inspection printed ingest_options ['record_dir', 'index_path', 'cadence', 'once', 'retention', 'manifest_dir'] and the manual publisher callback referenced run. The ingest now calls watch_publish.one_iteration from its tick callback with the index path it opened. A monotonic clock records every publication attempt, so a failed derivation waits for the next publication interval before retrying. The manual publish-watch command requires --once, and its standing loop is gone. The default output resolves watch.PUBLISHED_WATCH_PATH at call time; an autouse test fixture redirects that path to each test's temporary directory.
