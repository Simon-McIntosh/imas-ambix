The base query still reproduced the planned defect: its gauge window function selected every row with a timestamp before applying the period bounds, and its counter query selected every matching row before the period end. The committed implementation stores measurement names and kinds once, maintains source-hour counter and gauge summaries in the ingest transaction, reads raw samples at the two partial hours, and reads each period's cards in one bounded statement.
