Daily index snapshots run outside ingest ticks

Implementation commits 043fdb62140bbd44a1661194f4459b906332fac1 and 123c238c49b7d18da0db17cd6d30a29ad6ec11a0.

The prior tick callback called snapshot_if_due(index) inline. The new callback schedules one worker while the ingest continues. That worker opens its own read-only SQLite connection, backs up into a local scratch file with journal_mode=OFF and synchronous=OFF, and runs PRAGMA quick_check there. It streams the backup through zstd into the snapshot directory while hashing the uncompressed bytes, then streams the written archive back through SHA-256. A small digest receipt lets later daily checks use the same stream path; snapshots without a receipt retain the SQLite verification path. Scratch files are removed on success and failure.
