Index schema, installation and counter rollups have single owners

TelemetryIndex.requires_rebuild now owns the measurement-schema predicate, and placement delegates to it. Placement exposes snapshot_exists and install_index; restore uses the install path to remove stale SQLite sidecars before replacement. New rollups store counter segments without a separate difference column, while indexes that already carry that column remain writable.
