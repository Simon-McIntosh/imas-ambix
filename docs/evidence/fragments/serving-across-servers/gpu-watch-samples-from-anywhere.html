gpu-watch run on a login or fleet node now samples each declared server through one srun --jobid <job> --overlap step into a running job on that server, instead of printing not sampled from this host for every server but the local one. The step runs python -m imas_ambix.agent.gpu_watch.sampler, an entry point that frames node_probe.NodeProbe.stream as JSON lines, so the probe and its physical card numbering keep one owner and nothing is copied onto the server. A step also needs -n1 -c1 --cpu-bind=none: without it SLURM refuses with More processors requested than permitted or CPU binding outside of job step allocation and the step never runs — measured against job 1294597 while building this.
