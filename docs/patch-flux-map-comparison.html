§1 — What this report is

The first contour-space validation of the shipped patch-current-force-balance equilibrium layer: the P3 winner-config variational inverse (bounded discrepancy λ₀=3, target 1.5×m₀, λ≤100, 800 Adam steps) was run on 16 held-out slices — one rampup and one flattop per held-out shot (18502–18505, 12143, 12145, 12189, 12190) — and its total-flux ψ(R,Z) overlaid on the EFIT ground-truth flux map with imas-ink's equilibrium_figure_mpl reference-overlay primitive. EFIT enters as the firewalled referee only (evaluation, never a fit input). Slice times snap to EFIT's sparse (~5–20 ms) time base; script: scripts/patch_flux_map_report.py, metrics: imas_ambix/latent/artifacts/patch_gate/flux_map_report.json.

§2 — Data conventions resolved (recorded for every future map comparison)

  • The efm ψ map's own metadata is wrong: efm/psirz is stored (time, profile_z=65, profile_r=129) while its shape attribute claims [t, 65, 65]. Only 65 of the 129 R-columns are finite, and those columns' coordinates are bit-identical to efm/gridr — the real map is (Z=65, R=65), recovered by selecting finite columns. Orientation verified by landing the flux extremum on the referee axis.
  • Units: EFIT ψ is per-radian [Wb/rad]; our patch layer carries total flux Φ = 2πR·Aφ [Wb]. All comparisons multiply EFIT by 2π.
  • Sign: ψaxis > ψboundary (axis = flux maximum) in both frames — matches our sign-aware topology read; imas-ink falls back to matched ψN contours automatically where absolute frames disagree.

§4 — Findings and where they feed

  • Position is solved. Sensor data + the structure residual place the magnetic axis at referee accuracy across regimes (2.4 cm flat-top median on maps snapped within 15 ms of EFIT times) — consistent with the P3 gate (+0.019 axis skill, 2.8 cm median over 160 slices).
  • The boundary deficit is a flat-top phenomenon with a specific shape. Not noise: a systematic under-sizing of the flat-top LCFS while rampup boundaries agree. Working hypothesis (recorded, to be measured): the sensor null space lets the inverse concentrate current more than the true profile, and the boundary-flux read (innermost saddle / limiter contact on free-current ψ) compounds it. This is exactly Workstream A4 of patch-equilibrium-wm-integration (LCFS read robustification + current-smoothness soft rung, kept only if load-bearing) — this report is its baseline measurement.
  • Misfits stay honest everywhere (0.02–0.27 whitened mean-square; Ip respected) — the boundary deficit is not a data-fit failure, it is prior-dominated interior structure, which is the argument for the physics-side fix rather than more sensor weight.
  • Conventions institutionalised: §2's psirz shape/unit/sign facts are now in code (scripts/patch_flux_map_report.py) and in this doc — the next map consumer does not re-derive them.

Verdict for the programme: the reduced-order-physics-wrapped-in-ML pattern holds up in the most direct visual test available — the flux surfaces are real, the axis is referee-grade, and the one systematic deficit is localised, measured, and already owned by a queued workstream of patch-equilibrium-wm-integration.
