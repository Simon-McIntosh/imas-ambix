The cost of leaving it: every future edit that touches these files either inherits the debt silently or couples an unrelated cleanup into its diff — exactly the trade the migration workers had to navigate. A dedicated scrub, in its own focused commits, is the mechanism the naming rules themselves prescribe for debt this broad.

§2 — Scrub by mechanism, not by pattern-match

The user-global agent guidelines define both the violations and the sweep that finds them; this plan applies that sweep as the work item rather than as a pre-stage gate. Four passes, each with a recorded receipt:

  • Label sweep — plan/stage/sprint/deliverable identifiers in filenames, symbols, comments and docstrings. Every hit is renamed to what the code does (mechanism or measured quantity), never merely deleted: a tolerance constant named after a gate id becomes a name stating what it bounds.
  • Changelog-prose sweep — comments and docstrings that narrate edits ("previously", "the old behaviour", "after this fix") are rewritten as the invariant they defend, or removed when the code already states it. Runtime state described in the past tense is the known false positive and is kept.
  • Anchor audit — every comment, docstring or symbol that cites a file, section, or numbered item is opened and confirmed to exist; dead pointers are repointed or rewritten as self-contained statements.
  • Lint and formatting — the 75 statespace findings and the 66 analysis-script formatting findings are cleared with ruff check --fix and ruff format at the scope the formatting-scope decision selects, run before staging, never via a mutating pre-commit hook.

Behaviour neutrality is demonstrated, not assumed. statespace/engine.py and enkf_baseline.py are consumers of the declared description path and sit beside the frozen-spine chain, so the scrub ends with one frozen CPU stamp: the residuals must sit within the 0.1245% representation budget of the current declared-source references (greens-matvec 0.6698197452949048, grid-delstar 0.6697723807926145, 36/36 coverage per arm). A pure rename-and-format scrub that moves the stamp has changed behaviour and must stop and report rather than proceed.

§ Decisions

How far does the formatting cleanup reach beyond the two statespace modules?

User selected: format every analysis script once, in one dedicated commit. Clearing all 66 findings ends the debt permanently; blame churn is contained to a single formatting-only commit, and mixed-style files would keep re-tripping formatting diffs on every future edit — the plan's own thesis.
