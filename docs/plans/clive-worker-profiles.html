§1 — Why, and what clive owns

The cost. Every clive worker starts at a median of 66.5k input tokens. About 22.5k of that is the global ~/.agents/AGENTS.md, loaded whole into every worker whatever its role. The study behind this plan (~/.config/reckon/crew/reports/reckon/s21-coord/worker-context-budget/context.md) estimates that a role-scoped digest, plus narrowing the MCP servers and built-in tools, saves about 18–25k tokens per worker. On the local lane that is also less KV per session held against the 4M-token device pool, which the gate in local-lane-admission-control is sizing around.

The split. The lead approved per-role digests, opt-in first and default later. Reckon owns the digest generator (which role gets which blocks) and an opt-in --worker-profile on crew dispatch. That work is tracked in reckon's the-local-lane-is-the-default. Clive owns the launch: it accepts a profile, turns it into Claude Code flags that claude --help actually lists, and records what it loaded. This plan is that clive half. It changes nothing for a launch that passes no profile.

Three hazards the expansion must not walk into, each read from Claude Code 2.1.282's own help text on 2026-09-25:

  • --bare skips CLAUDE.md auto-discovery, and with it the repository's guidance, not only the global file. A worktree's CLAUDE.md @-includes ~/.agents/AGENTS.md, so restoring context through --add-dir would load the global file again and undo the saving. The repository's own AGENTS.md must therefore be supplied explicitly, beside the digest.
  • --bare also skips hooks defined in settings and plugins. Any hook that enforces worker safety stops firing. The profile must say, in its recorded expansion, which hooks are therefore absent, so the loss is visible rather than silent.
  • --tools with an empty string disables every tool. A profile naming no tools must be refused, never expanded to "".

§2 — clive accepts a worker profile and records its expansion

The profile. A small JSON file with three keys. digest is the path of the role digest Reckon generates. mcp_config is the path of a minimal MCP configuration, or null for none. tools is a non-empty list of built-in tool names. Clive gains --worker-profile PATH, alongside its existing --mode and --selector options, and stops with a named error when the file is missing, a key is malformed, a path does not exist, or tools is empty.

The expansion. With a profile, clive adds --bare. It supplies the digest and the working directory's own AGENTS.md (when present) through the system-prompt route claude --help lists, alongside the dispatch guidance clive already appends. It adds --strict-mcp-config --mcp-config <path> when mcp_config is set, and --tools <comma list>. It keeps every existing clive setting: the model picker settings file, the context and output ceilings, and the auto-compact window. Under --bare the only accepted credential is ANTHROPIC_API_KEY or an apiKeyHelper, so the node confirms that clive's fixed key still reaches the harness. The record. Before exec, clive writes one JSON line naming the profile path, each file's sha256 digest, and the exact argument vector it added. It goes to $CLIVE_PROFILE_RECEIPT when that variable is set and to stderr otherwise, so the run receipt shows exactly what was loaded.

Hooks travel with the profile, or --bare is not used. The worker safety hooks in force on 2026-09-25 live in ~/.claude/settings.json. They are the Stop hook reckon/hooks/worker_stop.py, installed that day as the fix for early turn endings, and the PreToolUse guards native_agent_guard.py and shell_function_recursion_guard.py. A profile that dropped them would undo those fixes. At expansion time, clive therefore reads the hooks block from the user settings (read, not copied into the generator, so it cannot drift) and merges it into the settings file it already passes with --settings. The record lists every hook command it carried. --bare's help says it skips hooks defined in settings yet accepts --settings as explicit context, so whether a hook given there fires under --bare is decided by measurement, not by reading. A stub Stop hook that writes a marker file is launched under the expansion, and the marker must appear. If it does not, the expansion drops --bare and uses only the narrower flags (--strict-mcp-config, --tools, --setting-sources) with the digest appended. It accepts the smaller saving, and the record says which route was taken.

Done when tests over the generated launcher show four things. (1) With no profile, the exec line is byte-identical to the base revision's. (2) With a profile, the added arguments are exactly the expansion above, every flag appears in a recorded claude --help capture from the installed 2.1.x, and the record carries the three file digests. (3) Each malformed-profile case is refused with its named error, including an empty tools list. (4) A working directory without AGENTS.md expands without it rather than failing. (5) The expansion's settings file carries the hooks block read from a fixture user-settings file, and the record lists each hook command. (6) A recorded live launch shows the stub Stop hook's marker file appearing under the chosen route. Declared negative control: adding --add-dir . to the expansion must fail an assertion that the global file is not reachable from the launch. §3 — Qualify each role on a live worker before it becomes the default

A saving on paper is not a qualification. Once Reckon's generator and dispatch option have landed, and after the launcher carrying §2 is deployed from the main checkout (with its diff against the installed /work/projects/imas_gpu/agents/clive read first), run one throwaway worker per role (report, review, implement, test) twice: with its profile and without. Done when a table records, per role, the first-request input tokens both ways, together with a positive-control call of each tool the profile keeps and an MCP call where the profile keeps a server. The saving is stated as measured tokens, and a role whose control call fails is withheld from the default. Each role also carries two hook controls under its profile. A text-only stop with an in-progress manifest must be refused by the Stop hook, and a native Agent tool call must be refused by the guard. A role where either control passes through is withheld too.
