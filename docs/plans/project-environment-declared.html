One environment, rebuilt from what the project declares

Project Environment From Its Declaration

The shared project environment at .venv works only because it holds packages the project never declared. A plain uv sync, the command the repository's own instructions tell every agent to run, removes them. This plan makes the declaration match what the code and tests need, so a plain sync produces the working stack and nothing a session relies on lives outside pyproject.toml and uv.lock.

§1 — What a plain sync does today

Measured 2026-10-05 in the main checkout, while landing the tokamap exporter's new dev dependency: uv sync uninstalled 130 packages and installed one. The removed set included pytest, pytest-xdist, pytest-timeout, ruff, mypy, linkml and linkml-runtime, imas-ink, reckon-plans and the editable imas-ambix install itself, and the newly declared tokamap was not installed. Two causes account for all 130:

CausePackagesWhy a plain sync drops them
Declared only as extras61The dev, docs, viz, agent, data and train stacks are [project.optional-dependencies], which uv installs only with --extra or --all-extras; the environment had been built with all of them.
Declared nowhere68Absent from uv.lock: installed into the environment by hand at some earlier point, among them linkml, pytest-xdist, pytest-timeout, sphinx, mcp, sqlalchemy and reckon-plans (a path install of ~/Code/reckon).

The environment was restored the same day: uv sync --all-extras brought back the 61, the 68 were reinstalled at the versions the sync log recorded removing, and reckon-plans was reinstalled editable from ~/Code/reckon, which also brought playwright and pyee and matplotlib 3.11.2 (reckon requires matplotlib>=3.11.2; imas-ambix declares no matplotlib requirement of its own). uv pip check then reported all 296 installed packages compatible. That restore is the debt this plan retires: it put the undeclared packages back by hand, which is exactly what the project's rule against imperative installs exists to prevent.

§3 — Declare and relock

The declaration follows the census. A default distribution imported by code under imas_ambix/ goes in [project.dependencies]; one imported only by tests/, and the test and lint tooling, go in a [dependency-groups] dev group, which uv installs on a plain uv sync, and the dev extra is removed. The docs, viz, agent, data and train extras keep every member the census classed optional; a member it classed default moves out by the same rule. Two corrections to the census come first. Its optional-subsystem roots cover imas_ambix/agent and imas_ambix/train only, so they gain the FAIR-MAST acquisition modules that import the data extra's members. And five libraries are imported only inside functions, for video rendering (demo/runner.py: imageio, imageio-ffmpeg), perceptual metrics (eval/metrics.py: lpips, torchvision), a torchvision-based fine-tuning step (tokenizer/finetune_decoder.py) and frame preprocessing (data/preprocess.py, worldmodel/exposure_balance.py: opencv). None is installed today, so no session relies on them. They go in a new video extra, and the classifier lists them by name as that extra's lazily imported members rather than classing them default. The relock rewrites the declaration that tests/physics/test_dependency_contract.py already guards: test_project_and_lock_declare_editable_nova_checkout asserts the nova path source and its uv.lock projection, so it must pass after the relock as well. That test and the census both resolve an editable install's checkout from direct_url.json, and the census's copy omits the unquote the existing one applies, so both move onto one shared helper in tests/distribution_sources.py. A version bound is added only for an incompatibility that has been observed and is named in the commit; nothing else is pinned. The existing path sources in [tool.uv.sources] (imas-ink and nova-stella) keep their entries, and no new path source is added, because the census found no import of reckon. The pytest configuration gains a default per-test timeout of 300 s, raised only for a test whose measured duration needs more.

The node edits pyproject.toml and regenerates uv.lock with uv lock only. It never runs uv sync against the shared environment, because a sync from a worktree repoints the shared editable install at that worktree. Its tests run with --no-sync against the restored shared environment, which already holds every package the census found.

Done-when: uv lock --check passes; tests/test_declared_dependencies.py passes; the dev extra no longer exists; and pytest --collect-only -q run before and after the edit, each logged, reports the same test count and zero errors.

§4 — Prove it on a fresh environment

The proof builds a new environment from the declaration alone, on node-local disk so the shared one is never touched: UV_PROJECT_ENVIRONMENT=/tmp/ped-fresh-<run> uv sync with no flags, where /tmp on the fleet node is local disk. Against that environment it imports every module under imas_ambix/. A module outside the optional subsystems must import; a module inside one must either import or fail with ModuleNotFoundError naming a distribution the census classed optional, and any other failure fails the proof. It also runs the imas-ambix console script's --help, collects the whole test suite, and runs ruff check imas_ambix tests, then removes the fresh environment. The worker does only this. The coordinator then runs a plain uv sync in the main checkout and checks its removal list against the census: every removed package must be one the census classed optional, unused or transitive, and nothing classed default may go.

Done-when, for the worker: in the fresh environment every non-optional module imports and every optional module either imports or fails naming an optional distribution, the console script answers, test collection reports zero errors and the same count as the shared environment, and ruff exits 0, all in one gate log. For the coordinator: the main checkout's plain sync removes nothing the census classed default.

§ Decisions

Where do the test runner, its plugins, the linter and the validator live?

They are declared today as the dev extra, which a plain uv sync does not install.

Lead's direction 2026-10-05: plain uv sync must produce the working stack, with the libraries that are truly default declared as default. The test and lint tooling is what every agent session runs, so it belongs in the group uv installs by default. Rejected: keeping the extra, which leaves a plain sync without the test runner.
