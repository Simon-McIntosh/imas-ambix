Parallel enabling track (P0) of sprint S16. Runs alongside stage 1 from day one — it is model-independent (reads EFIT as a firewalled referee, raw signals, and the plan), so it does not wait on the substrate or the engine. Full design + sequencing in the parent machine-agnostic-latent-world-model (§10, §14). Front-loading the bars learns the acceptance targets early (the S9/Stage-3 lesson) and unblocks the stage-2 and stage-4 gates.

§1 — Objective & scope

Build the honesty-spine eval infrastructure that the model stages are graded against. Five non-overlapping, model-independent components:

  1. Firewalled EFIT referee. A reader/judge over EFIT's reconstructed outputs (boundary/X-point/ψ/q) that is evaluator-only — provably never on the training input path (boundary guard). The weak tier of the validation honesty hierarchy (agreement-with-EFIT = sanity check).
  2. Absolute-magnetics equilibrium oracle. The probe that maps absolute magnetics → equilibrium geometry (axis/X-point/boundary) — the measured bar (skill 0.5–0.7) the stage-2 GS readout must match. Reuses/extends the prior feasibility oracle (scripts/feasibility_calibrated_magnetics_oracle.py).
  3. Raw-held-out + EnKF prediction bar. The strong tier: predict withheld raw observables the model never saw (held-out probes; MSE on beam-on slices) vs persistence and the classical EnKF current-recovery bar (reuse sequential-current-da-v1 + the D1 held-out-MSE harness).
  4. Powered ΔN-M controllability gate. True-plan vs random-plan rollout divergence on the latent (not brightness), n=10 random plans, collapse-rejecting, bootstrap CI, on excited held-out windows. Adapt the existing controllable_eval.py to the new latent interface.
  5. Excitation-window selector. Score windows by genuine actuator excitation (|dI/dt|, coil ramps, plan changes, ramp-up/down) to curate the training distribution and define the excited held-out cohort the controllability gate runs on — the device that breaks the causal-under-identification confound.

§2 — The gate (verifiable done-when)

  1. All five components built + unit-tested; the firewall boundary guard proven (the referee's EFIT store is never opened by any input/training path).
  2. The bars are measured on existing data before the WM exists: the absolute-magnetics oracle skill (the 0.5–0.7 target for stage 2); the persistence + EnKF raw-held-out bar (the target for stage 4); the ΔN-M noise floor characterised at n=10.
  3. The excited held-out cohort defined + its excitation justified (windows where the command demonstrably should move the state); the train/eval split is leakage-audited.
  4. Tests green; outcome recorded; plan collapsed to a landed summary.

§3 — Approach

Each component is an independent module reusing prior assets (the feasibility oracles, the D1 MSE harness, controllable_eval.py, sequential_da.py). They share only the corpus + the split definition, so they parallelise cleanly. Deliver them as separate file sets, then wire the shared split + cohort definition last.

§4 — H200 footprint

Light — model-independent, mostly CPU/data + small probe training. The absolute-magnetics oracle is a small probe; the EnKF bar + raw-held-out harness are data/assimilation; the ΔN-M gate is rollouts (later, against the model). Runs on a card or standard compute; GPU nodes read /work directly. Not a heavy consumer — its value is in unblocking the heavy stages, not in compute.

§5 — Fleet suitability & inherited decisions

Fleet-suitable. The five components are non-overlapping and model-independent — a clean parallel dispatch (supervisor owns scope; each agent its exclusive paths; stage only your assigned files). Locked decisions are inherited from the parent: firewall-definition = code-outputs-only (EFIT = referee, never training; sensor geometry free); the controllability metric = powered n=10 ΔN-M on the latent. No new architectural decisions here.
