LCFS by Outermost Closed Flux Contour

Successor to the flux-comparison + geometric-annulus-cap boundary read in toroidal-harmonic-annulus-read. Reads the boundary as a continuous shape — the outermost closed flux contour that encloses the axis and fits inside the limiter — and lets the stationary points and the limited/diverted class EMERGE afterward as diagnostics. Deliberately NOT an EFIT-class topology extractor: one contour push, one code path, no discrete classification. Deterministic, per-slice, firewall-safe (EFIT scores only).

§1 — The trap to avoid: limited/diverted is a continuous transition

The obvious approach — find the X-points, decide whether one bounds the plasma, otherwise use the limiter tangency — is exactly how an EFIT-class topology extractor grows: a pile of special cases chasing wall contacts, X-point fluxes, and ψ-extrema on limiter surfaces. It is the wrong target because limited ↔ diverted is a CONTINUOUS transition:

  • A just-limited and a just-diverted equilibrium are near-identical — they differ only by a hair's-width of current-carrying plasma extent, and their boundary SHAPES coincide at the crossover.
  • So a discrete class is ill-posed exactly at the transition (the two states are degenerate) and only well-posed far from it — where the answer is obvious and does not matter. EFIT's own limited/diverted flag flickers there; chasing a perfect match to it near the transition is chasing its discretization noise.
  • Can the magnetics even tell them apart? Away from the transition, YES — a clearly diverted plasma puts a real saddle in the EXTERNAL vacuum field (an X-point in the annulus the sensors see); a clearly limited one does not (the plan premise: Braams 1991; Alladio–Crisanti 1986). But as the plasma grows into the divertor that saddle moves continuously onto the boundary — there is no sharp magnetic signature at the crossover. The magnetics resolve the class only where it is unambiguous. That is a reason NOT to build a classifier, not a reason to build a cleverer one.

The earlier attempt confirmed the hazard empirically: a limited-vs-diverted flux comparison guarded by a geometric annulus-cap classified one shot correctly but did NOT generalise — train X-point-set skill −0.23 → held-out −5.92 (the cap severely overfits). See toroidal-harmonic-annulus-read (Gate C landed + f-thar-startup-lowip).

§2 — The reframe: push the LCFS first; let the rest emerge

What we actually need — for scoring against EFIT geometry and for feeding the fixed-boundary interior spine — is the LCFS shape (the 8 radii), which is continuous across the transition. So define it continuously, with one code path:

The LCFS is the outermost closed flux contour that encloses the axis and still fits inside the limiter.

A single monotone sweep of the flux offset outward from the axis, tracing one contour (contourpy), keeping the largest axis-enclosing ring that lies inside the limiter. It handles both topologies identically: for a diverted plasma the ring grows until it pinches at the X-point (just past it the level set opens along the divertor legs, so the last closed-inside-limiter ring is the separatrix); for a limited plasma the ring grows until it touches the wall. Same operation, no branch.

The elegant part (the reversal). This inverts the chicken-and-egg. We do NOT find stationary points to decide the boundary. We find the boundary first (continuous), and THEN — with a confident LCFS in hand — the stationary points and the class fall out: locate the ∇ψ=0 saddles and ask how close each is to the boundary ring. An X-point ON the ring ⇒ diverted (report it); the ring on the wall with no nearby X-point ⇒ limited (X-slots empty). This is a soft read-off by proximity, undefined near the transition, and never switches a code path.

§3 — Algorithm

Per slice, on the masked total flux ψtot (harmonic plasma + thick-cylinder coil), origin from the interior estimate (current centroid):

  1. Start outside the garbage. The near-pole interior (where the toroidal-harmonic ring functions diverge — the "garbage") is already masked to a plateau. The push begins at the plateau edge and moves OUTWARD, so the interior TH nulls never enter the contour search (§4).
  2. Push the flux offset outward. Sweep a level from ψaxis outward; at each level trace the flux contour and select the ring CONTAINING the axis (contourpy → the polygon whose interior contains the origin).
  3. Stop at the outermost closed, in-limiter ring. Keep the largest level whose axis-ring is a single closed curve lying entirely inside the limiter polygon. That ring is the LCFS; read the 8 fixed-angle radii from it directly (no outward ray-march).
  4. Emergent stationary points + class (diagnostic, after the boundary). Find the ∇ψ=0 critical points (reuse find_critical_points, excluding the masked interior). An X-point within a tolerance of the LCFS ring ⇒ report it and mark diverted; otherwise (ring on the wall) ⇒ limited, X-slots NaN. Tolerance is a soft margin, so near the transition the class is genuinely undefined rather than forced.

No X-point is needed to find the boundary; no limited/diverted decision gates the LCFS; no ψ-extrema-on-limiter-surface comparison. Far-field garbage (a spurious feature at |Z|≈1.7) is a separate contour ring, excluded by the enclose-the-axis + inside-limiter tests with NO tuned distance cap.

§4 — "Start outside the garbage" (the interior-null exclusion)

The harmonic field is invalid inside the near-pole disk, where the P-ring functions diverge and produce spurious interior O/X nulls. The existing mask_invalid_interior fills that disk with a confined plateau; because the sweep starts at the plateau edge and pushes OUTWARD, and only axis-enclosing rings in the valid annulus are kept, those interior nulls can never be mistaken for the boundary or for a boundary X-point. This is the concrete mechanism behind the lead's requirement to begin the LCFS push outside the garbage.

§5 — Library choice

  • Contour ring extraction (the axis-enclosing polygon at a level, for the LCFS radii and the stop test): contourpy — matplotlib's engine, already transitively present; returns line rings at a level, pick the one containing the axis. Alternative skimage.measure.find_contours (marching squares).
  • Containment tests (ring encloses axis; ring inside limiter): point-in-polygon on the ring vertices (the existing _inside_polygon). scipy.ndimage.label remains available if a grid-connectivity check is cleaner than a ring test for the stop condition.

No new heavy dependency. The masking, origin (current centroid), and firewall are inherited from the harmonic plan unchanged.

§6 — Integration & gate

Score on the SAME 160-slice held-out protocol, firewalled EFIT, paired-bootstrap CIs. The LCFS shape is the PRIMARY scored quantity. The X-point set is emergent/secondary — reported only where the boundary X-point is unambiguous, NaN near the transition; we do not optimise it against EFIT's discrete flag. The limited/diverted agreement with EFIT is reported as a DIAGNOSTIC (per phase), not a tuned objective. Pass = LCFS skill ≥ the current harmonic read (−2.48) with a cleaner, single-path, cap-free boundary that reads sensibly across breakdown → termination.

§7 — Scope guard (binding)

Explicitly OUT of scope — if the implementation starts reaching for any of these, STOP and reconsider, because it is the EFIT-extractor trap:

  • a discrete limited/diverted classifier as a code-path switch;
  • chasing wall-contact points / ψ-extrema on individual limiter surfaces;
  • per-surface X-point ↔ limiter matching logic;
  • tuned distance caps on candidate critical points.

The whole read must remain: one flux-offset push, one axis-enclosing ring test, one inside-limiter test; class and X-points are emergent diagnostics only.
