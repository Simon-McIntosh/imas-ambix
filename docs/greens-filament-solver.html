§1 — Overview: drop the grid solve, keep the physics

The problem. The reanalysis engine solves the free-boundary Grad–Shafranov equation by evaluating the gridded elliptic operator Δ*ψ on a 65×97 R–Z grid every Picard sweep, three solves per slice. Two costs follow. First, throughput: the §4 held-out-MSE run took ~20 min for 112 shots, and the label factory must run this same solve over the ~12.6k-shot corpus to feed the learned operator — ~37 core-days at today’s rate, and every physics term we are about to add (interior-closure-hardening) makes each slice more expensive. Second, and more insidiously, flux-surface-averaging integrity: the 1D metrics that drive the resistive current diffusion (V′, g2, g3, ⟨1/R⟩) are computed by binning the finite grid cells onto flux surfaces, and that binning is noisy. Measured on a real 937 kA slice, the diffusion coefficient d = g2·g3/ρ̂ carries a relative second-difference roughness of ~0.5, and it gets worse with more surfaces (0.45 → 0.72 as nρ goes 16 → 96) — fewer cells per surface, noisier averages. That noise sits in the transport coefficient diffuse_psi integrates against, so the §3 dynamics coupling is running on corrupted metrics, not just a bumpy plot.

The fix (validated against the nova code). Keep GS force balance; drop only the gridded Δ*ψ evaluation. The coaxial finite-area mutual-inductance kernel is the free-space Green’s function of Δ*, so ψ = Σ G(target, filament)·I is an analytic Δ* inversion — the same hybrid_greens kernel already used for the coils and vessel (this is the locked one-interaction-matrix decision, finally extended to the plasma). The plasma becomes finite-area toroidal filaments carrying effective turns that sum to 1 by construction (nturn = area/Σarea), so the net current is Ip exactly. The interaction matrices are built once per campaign and cached; every ψ evaluation is then a matvec. The free-boundary equilibrium is a Jacobian-free Newton–Krylov fixed point on ψ.

Firewall. This is a solver-substrate change, not a physics change: GS force balance is preserved exactly (the pointwise jφ(ψ) relation on the filaments), all field evaluations stay on the hybrid_greens finite-area kernel (standing directive), and EFIT enters nowhere. The soft priors survive unchanged in kind — the current centroid is linear in the filament turns (∫R jφ = Rc·Ip), and the passive/vessel eddies are already Green’s-represented.

The binding gate (go/no-go, pre-declared). The grid-free solver is adopted only if it clears a spike: (a) it reproduces the grid-GS equilibria on held-out slices to tolerance (axis, LCFS, and profile within pre-set bounds); (b) it is measurably faster (the per-iteration matvec + NK vs the elliptic Picard); and (c) the flux-surface metrics it yields are cleaner (the d roughness falls materially). If any leg fails, we keep the grid solve and fall back to Anderson-accelerated Picard + Green's caching for the runtime target — recorded honestly, no forced adoption.

§ Decisions

Replace the gridded Δ*ψ evaluation with a Green's-function / filament plasma solve?

Locked by the lead (2026-07-20). The gridded elliptic solve is both the throughput bottleneck for the corpus-scale label factory and the source of the noisy flux-surface metrics that corrupt the resistive-diffusion coefficient (measured d roughness ~0.5, worsening with resolution). The nova code proves the elliptic operator can be inverted analytically by the Green's kernel with GS force balance preserved. Adoption is gated by a go/no-go spike so the change is de-risked, never forced.

Which Green's kernel represents the plasma filaments?

Locked by the standing directive that all couplings use the hybrid_greens finite-area cylinder kernel (never point-filament). Using it for the plasma filaments makes the plasma join the coils and vessel in ONE interaction system — the locked one-interaction-matrix decision — and keeps the plasma-driven field consistent with the coil-driven field.

Is GS force balance retained, or is this a current-tomography fit?

Locked by the lead (2026-07-20): "obviously we still keep GS force balance — it is just the gridded GS operator eval that we can avoid." The fixed point enforces self-consistency (the current that produces ψ equals the current force balance demands at that ψ); it is a genuine free-boundary GS equilibrium, not a current tomography.

Which fixed-point scheme drives the free-boundary loop?

Newton–Krylov is nova's validated accelerator and converges faster/robustlier than plain Picard on the free-boundary fixed point. Anderson-accelerated Picard is evaluated in §4 as the interpretable fallback (per the lead's request to investigate Anderson damping). The scheme is a means to the go/no-go and runtime gates, not a physics choice.
