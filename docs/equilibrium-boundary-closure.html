§1 — Thesis: the boundary and the interior are separate low-order problems

The force-balance-spine review reached a clean verdict: we had drifted into rebuilding EFIT. Chasing the LCFS ray-cast through a free-boundary Grad–Shafranov fixed point produced the outboard attractor, the reseed lever, and a −3.70 boundary bar that no coil-model correction moved — the same machine-specific topology tar pit that imas-efit (359 shipped plans, a Reeb/separatrix/wall-race apparatus) is still debugging. That is not our mission. Our North Star is a machine-agnostic, data-led world model, and the boundary is machine-dependent only through geometry — which belongs as a conditioning input, not as hand-coded per-machine topology.

The correction is to stop coupling two problems that are naturally separate:

  • The boundary is a property of the field OUTSIDE the plasma. There the poloidal flux is source-free (Δ\*ψ = 0); its eigenfunctions are the toroidal harmonics (half-integer Legendre ring functions). Fit the raw external magnetics + the known coil field + Ip + li to a truncated harmonic expansion and ψ is known throughout the vacuum annulus — the boundary is a contour, X-points are its saddles, limited-vs-diverted is a classification of that smooth field. No interior current, no EFIT. This is the classical result (Braams 1991; Alladio–Crisanti 1986) and it is what real-time codes do.
  • The interior is a force-balance problem SOFTLY anchored to that boundary. The annulus read is low-order — it carries only ~1–2 boundary DOF and is ~6.7 cm uncertain. Its higher-order shape (the Shafranov shift, edge/X-point sharpening) is set by the interior current and cannot be extracted from external moments. So we do not fix it as an exact Dirichlet boundary — that would assert unmeasured DOF as truth, a misplaced assumption. Instead solve Δ\*ψ = μ₀R·jφ(ψ) on the plasma domain as a free-boundary force balance whose emergent boundary is softly anchored to the read (via the vacuum-annulus ψ-consistency penalty), with current admitted in the confined core AND the public SOL out to soft ψN≈1.1. The low-DOF closure keeps this the well-posed reconstruction the spine already does well (axis 3.7 cm, effective rank ~1–2); the soft anchor is precisely the constraint the unanchored free boundary lacked, so it should remove the outboard attractor rather than requiring the reseed lever to fight it.

Do diverted and limited plasmas look different to magnetics? Yes. A diverted plasma carries an external X-point (a poloidal-field saddle) just outside itself that reshapes the external field; a limited one is set by wall tangency. Same Ip and gross shape → different external magnetics through that saddle. Ip and li break the residual field→boundary degeneracy. So a low-order boundary IS recoverable from low-order external moments — our own thread-1 moment read already recovered the X-point class held-out (−0.61 → −0.15); its LCFS was poor only because it reconstructed an interior current and re-imported the ambiguity. The source-free read removes that. The −3.70 was self-inflicted, not information-limited.

§2 — Boundary route (LANDED): the source-free toroidal-harmonic annulus read

Owned by toroidal-harmonic-annulus-read (a hard depends_on), now shipped. It fits ψ in the Δ\*-eigenfunctions (order-1 half-integer Legendre ring functions) in the vacuum annulus, matched to raw external magnetics + coil field + Ip + li, and reads the separatrix / X-point / LCFS + limited-vs-diverted class off that smooth source-free field — no interior current, EFIT-firewalled. Held-out (n=160, firewalled EFIT): best-in-class LCFS ~6.7 cm, connectivity X-point-set −1.80, and — the load-bearing number for §3 — a vacuum-annulus ψ-consistency of 0.068–0.089 (the interior carrier ψ vs the harmonic ψ agree in the shared annulus, confirming the source-free premise). Two properties define how §3 must consume it: it is a low-order read (order 3; order 5 aliases), and it is valid ONLY in the annulus (the axis stays with the interior carrier). Both say the same thing — it is a boundary prior, not a boundary fact. It is also the classical baseline the learned operator (§4) must beat.

§3 — Interior spine: soft-prior force balance (NOT a fixed-boundary Dirichlet solve)

Why not fix the boundary. The tempting move — take the §2 LCFS as an exact Dirichlet condition and solve the interior on the domain it encloses — is a misplaced assumption. A fixed boundary asserts the full 2-D boundary contour as truth, but §2 measured only ~1–2 boundary DOF to ~6.7 cm. The higher-order boundary shape (Shafranov shift, edge and X-point sharpening) is produced by the interior current — the very thing §3 solves for — so fixing it either freezes in the read's low-order error or forces the interior to fight a boundary it should be shaping. Decoupling the two problems was right; ossifying the handoff is not.

The soft-prior solve. Keep the landed free-boundary Grad–Shafranov fixed point (solve_equilibrium_lsq) and its machine-agnostic parts — the low-DOF flux-function closure jφ(ψN), the passive rank-8 sidecar, the identifiability harness. Change three things:

  1. Anchor the emergent boundary softly. Add a vacuum-annulus ψ-consistency penalty to the per-sweep least-squares: the interior-solve ψ, extrapolated into the shared annulus, must agree with the §2 source-free harmonic ψ there. This is exactly the RMS the harness already computes (0.068–0.089), now promoted from a diagnostic to a regulariser. Its weight is tuned leakage-free on train shots and is set to reflect the read's ~cm uncertainty — a prior with a covariance, not a hard constraint. The boundary still emerges from force balance; it is merely pulled toward the source-free read where both representations are valid.
  2. Admit public-SOL current, softly. Replace the hard ψ_N<1 current mask (a discontinuity that itself feeds the attractor) with a smooth edge reaching the public SOL at soft ψN≈1.1. Filaments inside the LCFS and just outside it in the common flux region may carry current — physically the edge/halo current that does not vanish exactly at the separatrix — and the closure jφ(ψN) is redefined to decay smoothly through ψN=1 (the (1−ψ_N)^α form goes negative past 1 and must be replaced, e.g. a decaying foot). Force balance, not a hard mask, then places the LCFS.
  3. Let the attractor machinery fall away. The outboard attractor, the reseed lever, and the scout-certify recipe were mitigations for an unanchored free boundary. The soft prior supplies the missing anchor, so they should become inert. Test that held-out — retire them only when the numbers show they are no longer load-bearing (an honest negative, that the prior does not tame the fixed point, is a real and recordable outcome).

Everything the solve needs beyond the boundary — ψaxis, the interior ψ, ψN throughout the plane — it produces itself, self-consistently, with the §2 read pinning only the near-edge annulus field. Re-gate the interior metrics (axis, interior flux) AND the emergent LCFS held-out with CIs vs the free-boundary winner-arm baseline; the boundary is now a shared responsibility (softly from §2, refined by §3), not a metric owned by one side.

§3.2 — Ablation ladder, tuning protocol, and quantified gates

Arms (each scored held-out with the shared geometry_target/score protocol; skill = 1 − RMSE/RMSE(train-mean baseline), EFIT referee only):

  • A0 — winner-arm reproduction. Re-run the free-boundary closure winner-arm unchanged to refresh the paired baseline on the current code.
  • A1 — anchor only. Annulus ψ-consistency penalty added; hard ψN<1 mask kept. This is the protected fallback: if A2 degrades, A1 ships.
  • A2 — anchor + soft SOL edge. A1 plus the smooth current edge to soft ψN≈1.1 with a C¹ decay-foot closure (§3.3g). Run only against A1, never bundled past it.
  • A3 — machinery-retirement test. Best of A1/A2 with the reseed lever OFF and scout-certify bypassed; retire the machinery only if this arm matches the levered arm.

Tuning protocol. λanchor swept in decades (with a fine local refinement around the best decade) on the tune split (n=80), selection on LCFS skill subject to axis non-inferiority; foot width w and the ψN cap tuned the same way; all frozen, then scored ONCE on eval (n=160). Report the full sweep curve (skill vs λ): a flat plateau means a robust prior, a knife-edge means fragility — record either honestly.

Gates (paired bootstrap CIs throughout):

  • Axis non-inferiority: Δaxis_skill (arm − A0) CI must not extend below a −0.05 margin. The anchor must not buy boundary at the cost of the interior.
  • LCFS: must beat A0's LCFS skill with the CI clear of zero. Reference bar: the §2 read's own held-out −1.96 / 6.7 cm — the solve sees strictly more information than the prior (sensors + force balance + the prior itself), so falling well short of the prior's own skill means the coupling is mis-weighted; that outcome is diagnostic, not a tuning licence.
  • Attractor: instrument the reseed-trigger rate (axis R beyond reseed_axis_r_max with cost above the convergence limit) with the lever OFF, anchor on vs off. Retire reseed/scout-certify only if the trigger rate collapses to ≈0 AND skill is unchanged without them (A3). An honest negative — the anchor does not tame the fixed point — is recordable.
  • Consistency (report, don't gate): the annulus RMS of the anchored solve — now an optimised quantity, no longer a diagnostic — for continuity with the 0.068–0.089 record.

§3.3 — Implementation notes (for the shipping agent)

  1. Gauge invariance (critical). The harmonic fit has no absolute flux gauge: the gate's consistency metric removes a per-slice mean offset before scoring (consistency_rms, scripts/boundary_harmonic_gate_eval.py:124-144). But this is NOT because the harmonic field is intrinsically gauge-free (see §3.4): the offset the metric removes is a slice-dependent DC disagreement between two independent reconstructions, weakly pinned because only 12 of 81 sensors are flux loops. The metric centres it out to isolate SHAPE for a source-free-premise check. The §3 penalty should instead exploit the shared flux-loop gauge, not discard it. Two admissible forms, to be chosen by measurement (§3.4): (i) field-matching — penalise ∇ψ (equivalently Bpol) in the annulus, manifestly gauge-independent and matching the best-measured quantity (the 69 B-probes); or (ii) absolute-ψ with a fitted gauge term — add ONE shared scalar offset as a free DOF tying the interior-solve ψ and the harmonic ψ to the common flux-loop-anchored level, penalising the residual after that single offset (a rank-1 gauge nuisance parameter, not a per-point mean-projection that throws the DC information away). A blind mean-projection is the fallback, not the design.
  2. Like-for-like flux. The gate compares TOTAL flux (harmonic plasma + coil vs carrier total). Use the same thick-cylinder coil term on both sides — equivalently cancel it and compare plasma(+passive) ψ against the harmonic plasma ψ, with the gauge handled per (a). Evaluate the harmonic side with harmonic_psi_on_grid / harmonic_columns (imas_ambix/latent/boundary_harmonic.py:446-459, 231-264).
  3. Where the penalty rows go. solve_equilibrium_lsq assembles a whitened least-squares per Picard sweep (imas_ambix/latent/gs_solve.py:1162-1294). ψ at annulus points is LINEAR in the DOF (Green's ψ images of the basis columns, gs_solve.py:1212-1228, plus passive psi_cols and the fixed coil/vacuum term), so the anchor enters as extra weighted rows beside the magnetics block b_mat (gs_solve.py:1229-1235) — or into the regulariser block s_full (gs_solve.py:1257-1261) in Gram form — and as an extra rows.append in _bounded_profile_lsq (gs_solve.py:917-934) for the nonneg path. The Ip KKT equality row (gs_solve.py:1241, 1264-1270) stays hard and must INCLUDE the SOL-band current — the per-sweep rescale (gs_solve.py:1163-1166, 1299-1302) already sums all filaments.
  4. Annulus point set — fixed per slice. Take the gate's annulus definition (inside limiter ∧ outside the confined region, boundary_harmonic_gate_eval.py:147-166) but define the confined region from the §2 read's OWN boundary flux, frozen per slice — never from the solve's evolving boundary — so the penalty domain does not move inside the Picard loop.
  5. Per-slice robust weighting. fit_harmonic exposes per-slice misfit and coeff_cov (imas_ambix/latent/boundary_harmonic.py:348-407) which the gate currently discards. Weight the penalty per slice by the read's own uncertainty and/or robust-clip the residual: per-slice consistency has heavy tails (median 0.066 vs mean ~4·10⁴ on one recorded config), so a single global weight on raw RMS will let outlier slices dominate.
  6. Frozen prior artifact. No per-slice harmonic-coefficient cache exists (the gate persists scalar results only). Land one — coeffs, labels, cfg, misfit, coeff_cov per slice (NPZ/JSON per split) under imas_ambix/latent/artifacts/patch_gate/ — so the interior solve loads a FROZEN prior instead of refitting, and in-flight jobs are pinned against editable-install drift.
  7. Support-mask and closure-foot redesign. Today current support is the axis-connected component of ψN<1 with basis images zeroed outside (gs_solve.py:1193-1198, 1221; also :74, :549, :859), and ψN = (ψ−ψaxis)/(ψbnd−ψaxis) with ψbnd from the X-point/limiter read (_read_boundary_psi, gs_solve.py:362). For A2: extend the connected-support cap to ψN<≈1.1 (still axis-connected, inside limiter) and replace the closure past the separatrix — the (1−ψ_N)^α / (1−ψ_N)^{e_k} forms (gs_solve.py:61-74, 827-885) go negative or complex for ψN>1 — with a value-and-slope-matched decay foot, e.g. j(ψN>1) = j(1⁻)·exp(−(ψN−1)/w), dimensionless w tuned on train (start w ≈ 0.03–0.05 by analogy with the halo-budget scan). All parameters dimensionless / geometry-scaled — never metres.
  8. SOL-band connectivity. ψN>1 also holds in the private-flux region below an X-point. Restrict the SOL band to the connectivity component adjacent to the LCFS (common flux region), not to all ψN∈(1, 1.1).
  9. Scoring and instrumentation reuse. Score through the shared geometry_target/score protocol (train-mean baseline). Reuse scripts/closure_gate_eval.py's ladder arm and its reseed-lever block (~313–361) as the attractor instrument: the trigger condition is already the metric §3.2 gates on.

§3.4 — Is the harmonic field really gauge-free? No — and that changes the penalty

The consistency metric removes a per-slice mean offset before scoring, and an in-code comment attributes this to the harmonic fit having "no Ip gauge." That framing is misleading, and it matters because the §3 penalty was initially specified to inherit the same mean-projection. The physics, read off the actual fit:

  • The basis has no constant mode. Every harmonic column (harmonic_columns, boundary_harmonic.py:231-298) is a spatially varying source-free solution R·√(coshη−cosθ)·P1n−½(coshη)·{cos,sin}(nθ) — including the n=0 term h0, which grows toward the pole and is not a constant. There is no DOF that can absorb an arbitrary additive constant, so the fit does not leave ψ gauge-free.
  • Flux loops are in the fit and pin the level. harmonic_sensor_matrix (boundary_harmonic.py:323-342) gives flux-loop rows the absolute ψ column and B-probe rows the projected field ∇ψ. The 12 flux loops (of 81 channels) carry the absolute poloidal flux, so ψ is determined absolutely — the user's observation is correct: the flux loops already gauge the field.
  • What the metric actually removes. B-probes are gauge-blind (they see only ∇ψ), so the DC level of ψ in the annulus is constrained by the 12 flux loops alone — the weakest-determined direction of the whitened fit (69 B-probes dominate the objective, _fit_one, boundary_harmonic.py:366-407). The consistency metric compares TWO independent reconstructions (the current-moment carrier and the harmonic read); each is individually flux-loop-gauged, but they disagree on that weakly-pinned DC level by a slice-dependent amount. The mean-projection removes that inter-reconstruction DC disagreement to isolate SHAPE — the right choice for a source-free-premise check, the wrong default for a penalty that has the flux loops available to it.

Consequence for §3 (and why it is not a one-line code fix now). The penalty should keep the flux-loop gauge, per §3.3(a): match ∇ψ in the annulus (gauge-independent, uses the 69 B-probes' strength), or match absolute ψ with a single fitted rank-1 offset DOF (uses the flux loops' DC information, absorbs only the residual inter-model nuisance). The choice is decided by measuring the removed offset — its magnitude relative to the annulus dynamic range, and whether it is slice-random (fit noise → field-matching is safe and simplest) or systematic (a real level bias → the fitted-offset form is needed and the bias itself is worth understanding). The gate stores only the post-removal RMS, so this measurement needs one instrumented run (recompute both ψ fields on the annulus, record the offset per slice) — it is folded into the §3 shipping task rather than applied blind. A separate, optional refinement is to enable the ip_anchor poloidal-circulation constraint (HarmonicFitConfig.ip_anchor, currently an unimplemented config knob) so the harmonic read carries an explicit Ip/gauge tie of its own; that is orthogonal to the penalty design and stays with the §2 read's owner.
