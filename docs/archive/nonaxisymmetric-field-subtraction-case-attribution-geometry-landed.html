§1 — f-nfs-lever2: bay-loop bimodality attributed to the P3 case-current columns

The vacuum-window per-case scale fit (scripts/case_scale_vacuum_fit.py, artifact case_scale_vacuum_fit.json, commit e47a561) fit a multiplicative scale k (empirical ≈ k·model) for all 8 measured coil-case G_pf columns on the 430-shot coil-only vacuum cohort, controlling for the co-located coil winding. Firewall: coil-only vacuum slices, raw amb magnetics + raw amc currents + geometry-only operator; no EFIT, no plasma inversion.

  • Attribution — case, not winding. The bimodal systematic sits on the *_case_current columns: p3l_case_current k≈2.32, p3u_case_current k≈1.77, constant across each case's exposed sensors (drive-data class). The co-located *_coil_current windings carry only milder, separate offsets (0.61–1.19, geometry class) — not the bimodality carrier.
  • One common case scale does NOT hold across the 8 cases (dispersion fails the CI-overlap test); only the P3 cases are cleanly identifiable — the P2/P4/P5 cases are non-identifiable nuisances on vacuum data.
  • k≈2.40 vs the old 0.66–0.71 reconciled — no sign flip. The exposed-sensor estimator (k≈2.40, reproduces the lever-1 bay-loop value) is the coupling on the sensors that actually see the case; the global single scale (k≈0.66) is dragged toward zero by the many sensors that barely see it, plus the old audit predated the dedicated 1-turn case column. The gap is sensor-set dependence of a case column whose geometry pattern is imperfect off the bay loops.
  • Decision (b): fix upstream, no blanket scale. Route the P3 case-channel amplitude to an upstream audit (turns / xmult / units + name assignment before G_pf assembly) so k→1; leave the other 6 cases as fitted nuisances; do NOT bake a per-case SOLENOID_RESPONSE_SCALE analogue (the one-scale hypothesis failed). Gate G-A input: the bay-loop anomaly is a drive-data amplitude error on the P3 case columns — layer D — NOT a passive-screening mechanism, so G-A should not expect the passive eddy model to have to reproduce it.

§2 — Geometry-fidelity: field-fidelity collapse gate

Commit 3fc81a1. The filament-lattice collapse (collapse_rectangular_circuits) previously gated on a crude area-fill count (fill ∈ [0.75, 1.25]), which smeared the staggered P4/P5 coil packs into a bounding-box cylinder that mis-placed their current by 3–5 mm. It now gates on a multipole-match test: a circuit collapses to one equivalent cylinder only when its current-weighted centroid coincides with the box centre (dipole match — rejects staggered packs) AND its second moments match a uniform filled box (quadrupole match — rejects hollow frames and gapped packs). Regular windings with uniform insulation gaps (solenoid 4×164, P2, P3) still collapse; the staggered P4/P5 packs and the hollow coil cases now keep their exact filament lattice. Affected coil columns shift 0.5–2.4%, in the direction of correctness; 153 gs tests pass. This implements the "single rectangle for a true rectangle, exact filaments for the extra bits" requirement at the coil level.

§3 — Corrected passive picture: vessel + stability plates already ingested

The geometry audit against the MAST Data Catalog reference (commit 80898e2) initially reported the vessel structures as "not field sources". That was incorrect — it inspected the amm point-only passive (genuinely diagnostic-only) and missed the efm structural circuits. Direct check: the operator carries 80 inferred passive field-source columns (g_passive 73×80, circuits 22–101), and the 78 mastapp pf_passive vessel + stability-plate elements (botcol, topcol, endcrowns, incon, lhorw, uhorw, mid, vertw, ring, rodgr, and the P2 arms p2larm/p2uarm + divertor plates p2ldivpl/p2udivpl) match them to 0.0 mm — element-identical, same EFIT source. passive_resistance.py already fits vessel regions (vessel:inboard/outboard/ends/mid).

Consequence for the earlier ramp-up null: the case+vessel resistivity extraction that showed no ramp-up gain already included the vessel + stability plates — as axis-aligned bounding boxes. It was not missing them. The genuine remaining gap is a geometry-fidelity one: ~8 elements are true slanted parallelograms in the reference (crowns ±64.7°; P2 arms 45°/40°; P2 divertor plates) carried as axis-aligned boxes by efm. Refining those is a targeted improvement, routed to the new polygonal-section-coil-fields plan (analytic axisymmetric polygon-section Green's from Urankar Part V), which replaces both the bounding-box smear and the multi-filament proxy with an exact kernel — the principled way to represent the slanted passives before re-running the resistivity extraction.
