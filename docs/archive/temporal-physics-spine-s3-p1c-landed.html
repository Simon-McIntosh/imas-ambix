Tier A — missing measured drives: a clean, exact negative

The unconsumed amc siblings were tested as linear identities against the consumed channels on every pool shot (worst-case relative residual 1.9×10⁻⁷ — machine precision of the plant data stream):

  • *_feed_current = *_coil_current / N with N the integer turns count (P2 inner 12, P2 outer / P3 8, P4 / P5 23) — turns-scaled duplicates carrying zero new drive information.
  • <coil>_current (plain) = Σ *_coil_current + *_case_current exactly (for P2: p2l_current = p2il_coil + p2ol_coil + p2l_case). The plain channels therefore CONTAIN the held-back case measurement — inadmissible as discovery inputs under the binding holdback — and nothing else new.

The second identity is itself the discovery: the plant meters the case current as part of the coil's supply circuit. The case is not an isolated flux-driven ring — it shares the feed circuit galvanically. That converts tier A's negative directly into tier B's sharpest hypothesis.
