The polygonal-section kernel (Urankar Part V) and its forward-operator wiring shipped in the polygonal-section-coil-fields plan; this is the real-data application (tracked as f-psc-03). The eight slanted MAST in-vessel passives — the botcol/topcol vessel end-column crowns and the P2 arm / divertor plates — were carried as axis-aligned boxes because their vertices were never ingested. They are now attached as analytic PolygonSections and the passive inductance path is area-corrected. The question this closes for gate G-A: does faithful shaping of these elements move the passive-layer result? Answer: no — it is reconstruction-neutral.

§1 — What landed

  • Convention confirmed against the catalog. The MAST Data Catalog pf_passive shape-angle rule (*_shapeAngle1/2) was transcribed as geometry.shaped_section_vertices and verified to machine precision against parallelogram_vertices(90−a₂) for the side-edge shear; the top/bottom (a₁) shear is the transposed case the R-shear helper cannot express, so the two-angle rule is used directly.
  • Eight elements ingested. geometry.mast_slanted_polygon_sections matches each catalog slanted element to its inferred_passive fcoil circuit by centroid (all eight match to < 1 mm, single-filament) and builds the true parallelogram; build_table_for_shot now populates polygon_sections. GEOMETRY_TABLE_VERSION → v3.
  • Area was already correct. The efm width/height store the true parallelogram edge lengths, so box area ≡ parallelogram area to machine precision. The ring resistance 2πRρ/(w·h) and the section_scale are therefore unchanged — the correction is purely the source-side field shape, not the area.
  • Shaped couplings wired in the two passive paths that consume geometry: boundary_disc.passive_coupling_matrices (sensor + grid) and temporal_operator.build_passive_circuit_system (the inductance L source column). The two-section observer of the inductance path deliberately keeps the box — the flux another circuit links over these small sections varies negligibly across the shear.
  • Tests green: 246 gs tests (incl. 6 new slanted-passive unit tests + the polygon byte-identity baselines); tests/latent/test_temporal_operator.py 23/23.

§2 — Magnitude of the shaping

Measured directly at the real sensor set (shot 30421), box vs polygon column norms for the eight shaped circuits: the shift is 0.3–7.5% on 8 of 80 passive columns, largest for the strongly-tilted vessel crowns (botcol 7.5%, topcol 6.3%) and small for the P2 plates (0.3–1.5%). Absolute ψ couplings are ~10⁻⁶–10⁻⁷ Wb/A. Real, bounded, and confined to the vessel end-column + P2 structures — not the P4/P5-adjacent conductors that would screen the bay loops.

§4 — Verdict & consequence

Faithful shaping of the eight slanted passives is reconstruction-neutral for gate G-A. This strengthens the already-adjudicated verdict: the bay-loop coupling deficit is layer C (a per-era effective-area / coupling recalibration against the stable far set), not a passive-eddy effect — the exact geometry of the vessel/P2 structures does not carry it. The shaped geometry is the more faithful forward model to keep (the crowns and P2 plates are genuinely slanted and now modelled as such), but it is not the mechanism behind the scorecard's P4/P5 loop-gain collapse. The layer-C per-era cross-calibration (f-nfs-layerc) remains the route.
