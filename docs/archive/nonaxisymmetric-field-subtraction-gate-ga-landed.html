The vessel passive R was already fitted (vacuum_passive_resistance_fit.json, 2026-07-17): it drops the held-out vacuum aggregate magnetics loss 28× (0.337→0.012). Gate G-A asks the narrower, decisive question: does that modelled vessel eddy reproduce the scorecard's P4/P5 bay-loop coupling deficit — the −30–50 % "gain collapse" that biases the pin? The answer is no, on both the fit's own held-out pool and the scorecard's own coil-sweep regime.

§1 — The test

scripts/passive_bay_loop_gate.py takes the frozen resistance calibration and, per bay loop, pools the coil-only vacuum slices to compute the effective coil gain (empirical/model) before the eddy model (the scorecard's collapsed gain) and after adding the tuned vessel eddy, plus the fraction of the bay-loop eddy-signal variance the model explains. The centre-column control loops (fl_cc*, era-stable in the scorecard) are the discriminator: a physical correction must leave them ≈1. Firewall: coil-only vacuum, raw amb + raw amc winding drives + geometry operator + frozen calibration; cases are held-back state; no EFIT; operator unchanged.

§2 — Result: the vessel eddy does not carry the bay loops

Cross-checks that make this a real negative, not a harness artefact: the control loops behave (gain 0.97, eddy 5 % of their coil signal, correctly tiny), and the same vessel calibration that fails here reduces the aggregate held-out vacuum magnetics loss 28× — i.e. the vessel eddy is real and modelable, but its 28× win is carried by the near-vessel probes, not the bay loops. This also matches the reconstruction-neutral dynamic-passive result (tuned R gives axis skill Δ≈−0.2, flat-top no better).

§3 — Verdict: layer C, not layer A

Gate G-A was defined make-or-break: passive reproduces the collapse → subtract it (layer A); it cannot → the collapse re-routes to layer C (instrument / effective-area), corrected by per-era cross-calibration anchored on the stable far set. The passive model — case and vessel — explains < 10 % of the bay-loop deficit, so G-A takes the layer-C branch. Combined with this session's earlier results, the bay-loop bimodal anomaly is:

  • not a case-channel units/turns/name bug (all verified correct);
  • not the case passive R (the case is a few-% sensor term);
  • not the vessel passive R (explains < 10 %, gate G-A fail);
  • ⇒ a time-invariant, coil-specific coupling / effective-area error (layer C/D) exposed by drive mix (the §2 bimodality), whose correction is a per-era gain recalibration of the bay loops against the era-stable far set (centre-column loops + obr), applied upstream of the fit (D5), not a passive-eddy subtraction.

The vessel passive model stays in the engine for what it genuinely does (near-vessel probe eddy on ramps); it is simply not the bay-loop lever. The 3D RMP geometry (D2) is not required to close this question.
