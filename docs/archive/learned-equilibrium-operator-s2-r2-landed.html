The training bug — two suspects, one root cause

The first full pipeline silently skipped ~98.6% of training steps ("non-finite loss") while unit tests, single-sequence forwards, and synthetic pretraining all ran clean. Two defects were found; only the second was the root cause:

  • fp64 decode renormalisation (real, fixed, not the root cause). The Ip-renormalisation in profile_greens_decoder.cell_currents clamped the summed cell current at 1e-30, so a correction that nearly annihilates the current produced an unbounded ip/total gain with an exploding backward. Fixed with a bounded gain (floor at 1e-3·|Ip|, inactive at any physical decode) plus a finite-gradient guard and grad-norm clip in the trainer — kept as defence in depth.
  • Empty-timestep max-pool sentinel (the root cause). Mixed-length batches pad the sequence tail with token_mask all-False steps. The token pooling's emptiness test ran on a denominator already clamped to ≥ 1 (denom > 0 — always true), so fully-masked timesteps emitted the −1e30 max-pool sentinel into the trunk. The sentinel overflows fp32 downstream into NaN, and because padding was masked multiplicatively (NaN × 0 = NaN) the poison spread through attention into every timestep and every loss component of the batch entry. This is why: single-sequence forwards were clean (no padding), synthetic pretraining was clean (equal lengths), the val monitor looked finite (np.nanmean hid poisoned val batches), and all four loss components went NaN together. A CPU repro pinned it in minutes once the component-level NaN logging showed leash = NaN — the leash term sees only the network's own output, so the NaN had to originate inside the forward, not in the decode. Fix: pool on the true valid count and mask outputs by selection (torch.where), with a regression test that pins finite outputs, exact zeros at padded steps, and padding-invariance of the valid prefix (test_fully_masked_padded_tail_stays_finite_and_padding_invariant). The pre-existing padding test missed the bug by leaving token_mask random (mostly True) at padded steps — the real pad_batch zeroes it.

After the fix the definitive run trained with 0 skipped steps at every sweep point (503 shards, 428 train shots / 75 val shots, warm-started from the synthetic checkpoint).

Reading the negative — where the rung actually stands

  • The operator learns sensors, not boundaries. Val whitened sensor misfit improves 5.87 → 4.38 (best sweep point), yet every sweep point pushed the quasi-flat-top boundary past the 0.75 cm drift bound (0.83–3.95 cm) — model selection fell back to the most-regularised point (leash 10, ridge 3, val 5.16, drift 1.22 cm). Under the current self-supervised signal, sensor-reconstruction gains are bought with boundary drift; nothing in the loss rewards boundary fidelity directly.
  • The selected model is spine-adjacent. Per-shot G2 panels show the operator hugging the D2 spine; its headline "wins" over the disc read on ramp-up are the spine's, not the time axis's. The temporal irreducibles remain unexploited.
  • The measurement chain itself is proven. Byte-exact spine reproduction, paired bootstrap, figures, split harness, synthetic pretraining, and eigenbasis handling all ran end-to-end twice — the FAIL is attributable to the training signal, not the harness.
  • Open defect: the p′/FF′ split scorer's operator arm returns NaN (spine arm scores 0.120) with invalid value in sqrt warnings from the classical ladder refit (imas_ambix/gs/operator.py:163) — the operator-corrected currents push the refit outside its valid domain. Must be fixed before the split criterion can gate anything.

The bounded iteration — topology terms in the training signal (SUSTAINED negative, 2026-07-17)

The f-leo-05 iteration put the topology of a valid boundary into the objective (imas_ambix/latent/topology_objectives.py, commits dbceba0 + ef44cc1; pipeline job 1229633, _temporal_operator_cycle_1229633.log):

  • Terminator-consistency anchor on 9,819 spine-trusted quasi-flat-top slices: the induced gradient change ∇δψ at the spine's X-point candidates (full projector) and limiter-contact point (tangential projector), plus a softmax-weighted differential-flux-consistency term across terminator candidates. Delta form through interpolation rows over the exact Green's matrices — identically zero at zero correction, unit-tested against the cylinder-kernel pointwise field.
  • Critical-point integrity regulariser (label-free, unconditional): penalises gradient erosion below the spine field's own capped margin — a spurious interior null cannot form where the spine had a healthy gradient. Fades out at legitimate nulls with no exclusion zones.
  • Drift-aware composite selection (val misfit + drift-excess penalty, never anchor satisfaction) over a widened sweep — leash {3, 10, 30} × ridge {0.3, 3} × terminator weight {1, 10} — bracketing the 0.75 cm drift bound from both sides.

The anchors work; the thesis doesn't move. Selected point (leash 10, ridge 0.3, terminator weight 10): val sensor misfit 4.62 (spine 5.87) at boundary drift 0.70 cm — inside the bound for the first time (the first test's fallback sat at 1.22 cm and val 5.16), 0 skipped steps, byte-exact spine reproduction at eval. Non-inferiority vs the spine now PASSES (axis Δskill +0.026 [−0.006, +0.044], LCFS +0.006 [−0.024, +0.040]) — the saddle-degrading corrections of the first test are gone (X-point-set Δ [−0.089, −0.003] remains mildly negative but no longer drags axis/LCFS). Reading the sustained negative. Two clean, fully-instrumented tests of the temporal thesis now agree: the operator reliably converts sensor history into whitened sensor-misfit gains (5.87 → 4.4–4.6 val, ~21%), and with the topology terms those gains are now bought without boundary drift or saddle damage — but they do not convert into referee-measured equilibrium skill anywhere: not flat-top boundary, not ramp-up boundary, not axis, not the p′/FF′ split. The ramp-up advantage over the disc read (7.9 vs 11.3 cm) is inherited from the D2 spine (8.4 cm), not learned. Per the iteration's stop rule this is a sustained negative: no further training-signal iterations; the temporal thesis goes back to planning (followup f-leo-06). The split-scorer NaN of the first test did not reproduce with this checkpoint (the defect is data-dependent in the classical ladder refit — a separate hardening fix with a regression test is in flight).

What's next

Re-plan the temporal thesis before any further R2-class training (followup f-leo-06). The open question is no longer plumbing or objective degeneracy — both are now controlled — but where the temporal information can actually enter: the frozen-ψ_N linearised decode caps how far any correction can move the boundary in the ramp-up regime where the spine itself is wrong; real-data boundary truth is unavailable by construction (EFIT firewalled); and synthetic-truth sequences (exact boundaries, exact eddy histories) remain the only genuinely supervised boundary signal. Candidate directions for the re-plan: synthetic-first supervised training with domain transfer, an iterated decode (re-solve ψ_N after correction), a ramp-up-scoped gate where the irreducibles provably live, and an information ceiling probe on synthetic machines.
