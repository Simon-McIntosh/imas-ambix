Solenoid response attribution landed — the ~8% error is a uniform response scale, and it was not the LCFS blocker (2026-07-13)

Per-stage record for force-balance-spine followup f-fbs-07 (the sharpened f-fbs-05 remainder). Protocol unchanged: leakage-free, EFIT referee eval-only, bootstrap CIs, machine-agnostic corrections only (never per-shot tuning). The lead's directive drove the attack: use the vacuum pulses to discover the true underlying solenoid structure — is a section undriven (a hidden parallel/series circuit)? — and re-arm the follow-ons with the finding.

Headline

  • The solenoid under-prediction is a UNIFORM ~8.25% response scale — not a hidden circuit. On the pooled coil-only vacuum stratum (85 shots / ~111k slices), the empirical/model solenoid response is k_sol = 1.0825 [1.0625, 1.1009], significantly ≠ 1. Decomposing that response against per-axial-band pieces of the model solenoid column adjudicated the mechanism: a single uniform scale beats both a per-band free current profile (ΔBIC −12.3; the recovered profile is flat, all six bands 1.07–1.10) and an axial-extent/offset perturbation (ΔBIC −8.4; the fit returns the identity s_z=1.000, dz=0.000). The modelled solenoid EXTENT and POSITION are therefore correct; only its overall RESPONSE is low.
  • The "undriven section" hypothesis is rejected on two independent grounds. Sign: k>1 means the model UNDER-predicts the field — an undriven winding section would UNDER-drive → k<1. Structure: no axial band collapses toward zero (the lowest band is 1.068, still ~7% above unity), so no section carries anomalously little current. The efm circuit-1 solenoid (656 filaments, Z∈[−1.48, +1.48], Σxmult=328, series solenoid1+solenoid2 on one sol_current channel) is structurally faithful. The residual is a turn-count (effective amp-turns ≈8% low) or a sol_current channel-scale — degenerate in the forward map, so it is carried as one response constant on the column.
  • Correcting it barely moves the winner-arm gate — the solenoid was NOT the LCFS blocker. With the scale applied (cylinder-sensors-v4) and the lever off, the held-out winner arm (ladder K=2 + passive-8) reads axis skill −2.40→−2.40 (uncal) / −2.39→−2.39 (cal) and LCFS −4.07→−4.06 (uncal) / −3.99→−3.98 (cal). The f-fbs-05 framing that the coil model was THE binding constraint on LCFS is only partly right: the largest quantified coil-model error is real physics but does not unlock the boundary.
  • The winner-arm degradation under cylinder-sensors-v3 was a NUMERICS problem, and the reseed lever fixes it. The outboard-attractor coverage lever (reseed the confined branch when a converged slice reads its axis outboard of R=1.4 m with high cost) is surgical: it recovered shot 18505 from axis R=1.81 m / 93.9 cm error (the non-physical outboard corner) to R=0.77 m / 11.1 cm (the confined branch), reseeding all 20 of its slices while leaving the other 7 held-out shots (140 slices) byte-identical. That single recovery lifts the aggregate axis skill −2.40 → −0.357 [−1.10, −0.06] — back to the best-ever level (the case-circuits-v2 winner was −0.31) — and LCFS −4.06 → −3.70 [−4.47, −3.06].
  • Vacuum validation holds. The additive instrument offset on quasi-static coil-only intervals stays at 0.0038σ (held-out 0.0011–0.0013σ) under v4 — the multiplicative solenoid correction leaves the additive offset at ~0, exactly as a response-scale should.

What's next

The residual coil-model error that matters for the boundary is in the main-coil pairs, not the solenoid. The coil audit already showed the P2 quartet and the P3/P4/P5 up–down pairs are un-separable in operating + vacuum data (only 9/21 columns separable), and the case-circuit scales are unstable. Correcting the one separable, dominant coil error (the solenoid) does not move LCFS — so the next attack on the boundary is the un-separable main-coil up–down pairs (needs a symmetry-breaking excitation, or an engineering-source turns/geometry cross-check that vacuum data cannot provide), together with the low profile-DOF budget the identifiability harness measured (magnetics effective rank ≈1.2). The reseed lever should be promoted to a default coverage guard on the winner arm.

Rotation Stage B re-arm: the solenoid-scale error is now removed from the misfit floor, but the winner-arm re-gate shows the floor is still dominated by the boundary (LCFS −3.7) and the main-coil pairs — not the ~50× smaller rotation term. Stage B still waits on a broader-CXRS cohort to power the stratified test; the error budget it competes against is now cleaner but not yet rotation-limited.
