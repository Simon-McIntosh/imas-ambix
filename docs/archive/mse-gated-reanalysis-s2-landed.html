§2 record — the well-posed position-controlled free-boundary solve (PASS)

Verdict (2026-07-19): §2 PASS. Seeding the free-boundary Grad–Shafranov solve from the validated staged-disc read and constraining the R + Z current centroid holds the current on the physical inboard branch instead of drifting outboard through the radially-unstable in-vessel-coil band. Using only Ip + the current centroid — no full magnetics — the solve reproduces the full-magnetics reconstruction axis to a few cm, confirming the diagnosis premise: the current position is externally determined; the axis follows; the internal profile is the residual (earned from dynamics in §3–§4, never fabricated).

Gate verdicts (pre-declared in f-mgr-01)

The mechanism

  • Seed — the validated disc. Each slice is seeded from the staged-disc read (imas_ambix.latent.boundary_disc.disc_read), which places a uniform current inboard at the measured current centroid. The disc is the already-validated boundary read (staged-disc SHIPPED); it supplies both the compact inboard seed and the centroid target.
  • Constraint — the current-centroid moment. The R and Z centroid moments ∫R jφ = Rc·Ip and ∫Z jφ = Zc·Ip are linear-homogeneous in the profile coefficients — the same form as the Ip anchor ∫jφ = aanchor·c — and enter the per-sweep LSQ as strong soft rows (moment_priors.centroid_moment_rows, SoftPriors.centroid_{r,z}_target). The centroid is a direct field moment of the plasma current (firewall-safe), never an EFIT output.
  • Profile — the stable free-sign K=2 brancher. With no magnetics to pin an edge-capable non-negative profile, the basin-fragile n=3 nonneg spine dropped 2/12 mid-flat-top slices; the free-sign K=2 profile (np=nf=1) — the same brancher the reconstruction's reseed scout uses — holds the confined branch robustly (11/12 confined, 36/36 outboard-seed recovery). The non-negative profile is the residual certified downstream (§3–§4).

Notable findings

  • The position solve is sometimes MORE robust than the full reconstruction. On shot 11772 the recon reference itself drifted outboard on 2 slices (axis 1.64 and 1.13 m) while the position-controlled solve held inboard (0.90 m). The minimal Ip+centroid position lever is a strong stabiliser, not merely a weaker proxy for the magnetics.
  • The residual is the interior null, not a solve failure. Where G2a is finite the position↔recon axis gap is a few cm, set by the different profile peakedness (βp+li/2) each arm chooses — exactly the externally-invisible DOF the binding gate was moved off (onto held-out MSE). The position is held; the profile is the open DOF §3–§4 earn.
  • Stop rule NOT invoked. The centroid constraint holds the inboard branch across the shot set from physical seeds; no EFIT-derived position or profile prior was added.

Made the default (no back-compat)

Per the lead directive, the disc-seed + centroid position-controlled solve is the default label-engine forward routine — not an opt-in flag. The drifting seedless free solve (the “trial that did not work”) is retired: it survives only as the labelled before/after diagnostic in the gate figures. The frozen full-magnetics reconstruction (which passes) is untouched — the new SoftPriors centroid fields default off, so the reconstruction stays byte-identical (verified in test_position_constraint.test_centroid_off_is_byte_identical); §3 builds the dynamics coupling on this position-controlled spine.
