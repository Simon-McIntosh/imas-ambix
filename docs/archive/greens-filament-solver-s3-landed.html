§3 record — flux-surface averaging on the analytic ψ (GPU-native, contour-free)

Verdict (2026-07-20): §3 PASS, with an honest re-framing. The flux-surface metrics that drive the resistive current diffusion (V′, g2, g3, ⟨1/R⟩, d = g2g3/ρ̂) are re-based on the smooth analytic ψ by an accelerator-native, contour-free JAX kernel — a fixed-iteration flood-fill core (no scipy.ndimage.label) and a smooth-CDF coarea surface average (no argsort), jit / vmap / grad-safe, fixed-shape, fp64 — added as an opt-in fsa_mode="connectivity" with the host coarea path byte-unchanged. It is at least as smooth and resolution-stable as the committed coarea baseline, materially smoother per-slice, provably contour-free, closes Ampère + volume, does not regress the dynamics coupling, and was demonstrated running on the H200.

Reconcile first (the plan mandated it) — the cited pathology is not real. §3 was motivated by a claim that the cell-binned FSA d-roughness is ~0.5 and worsens with resolution (0.45 → 0.72 as nρ 16 → 96). That figure has no committed diagnostic behind it. The committed spine_bench metric on the actual contour-integrated geo.d_face (baseline stamp aa0b5e2, 6 shots) measures the opposite: median roughness 0.343 at nρ=32, 0.174 at nρ=96, resolution slope −0.058 (it improves with resolution). So the coarea read is already smooth and resolution-stable. §3's genuine deliverable is therefore not "fix a pathology" but "provide a fixed-shape, GPU-batchable FSA that matches-or-beats that baseline" — the forward requirement for the corpus labeller, since the coarea path (argsort + scipy.ndimage.label) cannot batch on a device.

What the connectivity read is

Two fixed-shape device primitives on the full grid, in imas_ambix/latent/flux_surface_connectivity.py (jax.numpy, fp64):

  • Flood-fill core. The axis-connected component of the confined set {ψN < 1 ∧ inside-limiter} grown from the axis cell by a fixed number of 4-neighbour dilations (jax.lax.fori_loop) — the same connectivity rule as topology.classify_regions, but a fixed-shape kernel instead of scipy.ndimage.label. It matches ndimage.label exactly (test) and rejects disconnected private pockets.
  • Smooth-CDF coarea average. ⟨X⟩(u) = ∂u∫ψN<uX dV / ∂u∫ψN<udV, computed as a difference of cumulative volume integrals with the hard sorted-cumsum step replaced by a Gaussian CDF on a fixed ψN level grid. As the bandwidth h → 0 it reduces exactly to the coarea estimator; at finite h it is the same estimator with the cell-binning noise smoothed and no argsort. Being a difference of cumulatives it is edge-unbiased.

Only the geometric surface average changes; the F / ρ̂ / ψ assembly and the ψ→I initial condition are shared and unchanged, so the two modes differ purely in how the surfaces are averaged. The default (fsa_mode="coarea") is byte-identical to before (test + the coarea benchmark numbers reproduce the aa0b5e2 baseline).
