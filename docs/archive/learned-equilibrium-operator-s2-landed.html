What was built

  • imas_ambix/latent/profile_greens_decoder.py — the differentiable decode: profile-DOF corrections about the classical solution → cell currents (non-negativity clamp + exact Rogowski-Ip renormalisation) → sensors and ψ(R,Z) exclusively through the precomputed finite-area thick-cylinder Green's matrices (PatchBasis — the physics layer is load-bearing; freehand fields are not representable). ψ_N is a fixed input (the solve's own converged map) so the decode is a linearisation: gradients analytic, dc=0 exact. tests/latent/test_profile_greens_decoder.py (11) pins torch-vs-numpy basis parity (both kinds), fp64 gradcheck, autograd vs the closed-form Jacobian (1e-9), the exact round-trip, and the exact Ip anchor.
  • imas_ambix/latent/residual_operator.py — the per-slice learner: geometry- encoded sensor tokens (value, spine residual, mask, kind, R, Z, orientation — the machine-agnostic positional encoding), masked mean+max pooling, zero-initialised head emitting K=6 profile-DOF corrections. Untrained operator == the classical spine.
  • scripts/spine_label_factory.py + spine_label_fleet.sh — the frozen classical solve (staged-disc soft prior + n_p=n_f=3 nonneg ladder, config pinned by sha256 3b50b94d…) manufactures labels over train-split shots, referee-free (held-out/eval shots refused outright); per-shot NPZ shards carry currents, ψ, ψ_N, targets, and the full payload snapshot with provenance.
  • scripts/train_residual_operator.py — self-supervised whitened sensor reconstruction + DOF-space leash to the spine labels; leakage-free model selection on train-split val shots under a bounded median boundary-shift criterion.
  • scripts/residual_operator_gate_eval.py — the paired gate: both arms share the frozen chain, the push-out reader, and the bootstrap draws (shared seed → paired Δ); reports spine drift vs the frozen arrays.

Label corpus and compute (§4 + §5, measured)

  • Corpus: 4,301 labelled slices over 158 train-split shots (91.5% of candidates; near-vacuum shots skip cleanly), one campaign signature, Ip closure exact to 4e-16, reseed fraction 0.6% mean. Shards at /work/projects/imas_gpu/mast/spine_labels/.
  • Throughput (the §5 first work item): 5.8 s/slice on a single sequential warm-started chain (sun CPU core) → ~4,900 slices/node-hour at 8 chains/node. The 4-node × 16-chain sun_debug fleet labelled the 200-shot manifest depth in ~25 min. Full-corpus (12.6k shots, O(10⁵–10⁶) slices) extrapolates to ~20–200 node-hours — a routine fleet run when R2 needs it.
  • Training is CPU-sized at this rung: the ~60k-param operator trains through the fp64 Green's matmuls in ~80 s/leash on one CPU node (5-leash sweep ~7 min). The H200 substrate becomes load-bearing at R2 (sequence model over 1 kHz histories), not here.
  • Chain semantics matter: warm-starting from scored-but-non-converged slices diverged three shots' Picard trajectories vs the frozen run (up to 10 cm on single slices, one slice masked). Strict-converged warm-starting reproduces the frozen arrays byte-for-byte — pinned in both the factory and the gate.

Decisions enacted

  • residual-vs-end-to-end → residual-first (locked): R1 predicts corrections about the classical solution; the shipped gate validates the composition. Direct-DOF emission remains an R2 ablation arm as the option text specifies.
  • physics-embedding = load-bearing-layers (honoured): every operator output becomes a field only through the exact Green's matrices; the spine is simultaneously label factory and paired baseline.
