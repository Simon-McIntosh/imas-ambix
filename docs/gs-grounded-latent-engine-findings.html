Scope. This document records the build and first real-data gate run of the GS-grounded latent engine (v0 stage 2 of the machine-agnostic latent world model). It states plainly what landed, what is verified, and the honest gate verdict — including a first-class negative result.

§1 — What was built (the stage-2 engine)

Six coherent primitives, each test-driven, in the new imas_ambix/latent/ package:

  • Differentiable GS observation operator (gs_observation.py) — lifts the geometry-only Green's-function ForwardOperator into torch: the latent plasma-current amplitudes θ map, differentiably, to predicted magnetics at the freely-known sensor locations (matches the numpy operator bit-for-bit) AND to the reconstructed poloidal-flux field ψ(R,Z) on a grid. Everything downstream of θ is a constant matmul, so the GS residual and the topology readout both back-propagate to the latent.
  • Topology read from ψ (topology.py) — deterministic magnetic axis (O-point), X-point null set (saddles), LCFS (8 ray-cast radii matching the evaluator), and public/private split (connectivity, per the §3a multimodal-flux caveat), all read from the one solved ψ. No EFIT labels, no regression heads (locked decision topology-from-psi). Steered by NOVA fieldnull critical-point finding + EFIT contour_tree public/private structure.
  • Flux-diffusion transport prior (transport.py) — the §7a temporal anchor: ∂ψ/∂t = D·𝒟[ψ] + S with a strictly-positive learned diffusivity (η∥>0 ⇒ D≥0 by construction — the arrow of time), the command entering through the source term, and soft dissipation-≥0 + Volt-second guard-rails.
  • Hybrid latent encoder (encoder.py) — absolute-calibrated features → an anchored raw-supervised block (Ip, n_e) ⊕ the θ ψ-representation ⊕ a free closure block, in dimensionless coordinates (resolving the open dimensionless-coordinate-set decision learned-soft).
  • Assembled engine + composite loss (engine.py) — encoder + GS spatial anchor + transport temporal anchor, with the raw-signal objective (GS residual vs raw magnetics + anchored supervision + transport guard-rails + KL/dimensionless).
  • GS-inverse solver + referee scoring (evaluate.py, data.py) — a per-slice ridge GS-inverse for θ (the map the learned encoder amortises) + the oracle-formula RMSE-skill and permutation-invariant X-point-set match against the firewalled EFIT referee.

§2 — What is verified (unit tests)

The mechanism is pinned by 36 tests that need no mirror or network:

  • the torch GS observation reproduces the numpy forward operator exactly, and ψ is the Green's superposition and differentiable w.r.t. θ;
  • topology is correct on analytic fields — Hessian O/X classification, a double-well's two O-points bracketing one X-point, LCFS radii on a circular boundary, and the §3a hard case: two nulls at comparable ψ height separated only by connectivity land in different regions (not confused by height or sign-of-Z);
  • the transport diffusivity is strictly positive for any input (D≥0), the operator is genuinely smoothing (parabolic), the command is load-bearing (zeroing it changes ∂ψ/∂t), and the dissipation + Volt-second guard-rails fire when violated;
  • the assembled engine's encoder→θ→GS chain grounds in raw magnetics — training drives the GS residual down >20× on a synthetic target (the mechanism behind gate 1).

And it grounds on REAL data. A 300-step end-to-end smoke fit of the hybrid-latent encoder on 14,780 real held-out slices drove the whitened GS residual from 12.15 → 2.29 (a 5.3× drop): the learned latent genuinely learns to explain the raw measured magnetics through the GS operator, with no EFIT labels — gate 1 confirmed on the corpus, not just a synthetic target.

§3 — The real-data gate run (firewalled)

On held-out MAST shots (the standing 18502–18505 cohort + OOD-regime shots), using only raw magnetics and the KNOWN coil currents, the engine builds per-campaign GS operators, solves θ per slice, reads ψ topology, and scores axis / X-point / LCFS against the EFIT referee — which is read only inside the firewall guard and never enters the solve. The absolute-magnetics oracle's ~0.5–0.7 axis skill is the bar.

§4 — Results & honest verdict

Gate 1 (mechanism, label-free) — MET. Hybrid latent + GS operator wired; anchored block supervised on raw scalars; the ψ readout produces axis / X-point / boundary with no EFIT labels. Runs end-to-end on real data.

Gate 2 (GS-readout skill matches the oracle 0.5–0.7) — NOT MET (honest negative). The training-free GS-inverse axis readout scores −11.2 (axis-R −6.3, axis-Z −16.1) (axis-R/Z) and −6.3 (X-point set) vs the train-mean baseline — below zero, far from the oracle bar. Root cause: MAST magnetic axes are tightly clustered (train-mean axis MAE ≈ 0.04 (R) / 0.015 (Z) m), and a low-DOF, non-force-balanced linear GS-inverse ψ lands the axis in the plasma region (MAE ≈ 0.39 (R) / 0.50 (Z) m) but cannot beat that mean. The oracle wins by learning the distribution; a physics inverse without a Grad-Shafranov force-balance solve does not. Higher profile order made it worse (under-determined).

Gate 3 (transport temporal anchor) — MET. Learned diffusivity verified strictly positive on the run (D_min = 1.0×10−⁶ > 0 for adversarial inputs); dissipation-≥0 + Volt-second guard-rails active; the command source is load-bearing (Δ = 25.5 > 0 when the command is zeroed).

Gate 4 — MET. All latent tests green; outcome recorded here; plan collapsed.

§5 — Deep review (2026-07-02): foundations audited, ψ decoder replaced

The lead flagged the Fig 1 wall contour as untrustworthy and mandated a full infrastructure review before any training. A three-worker fleet (independent geometry validation, project-docs synthesis, adversarial code review) plus direct prototyping produced four findings — two exonerations and two real foundation defects — and a locked architecture decision.

§5.1 — Geometry: validated, not the problem

The "alarming" contour is the genuine MAST plasma-facing limiter: the 37-point polygon is closed, simple, counter-clockwise, and bit-identical (0.0 m difference) to the official MAST geometry source (lim_mast.010_M4, via the L2 wall group). All 78 B-probes match the L2 sensor positions at zero residual; 13/13 named PF coils match at ~10⁻⁷ m; the flat-top LCFS lies 100% inside the polygon. The six flux-loop outliers are orphan slots in efm's static array with no live channel — not a data-quality issue. All 938 coil filaments lie outside the plasma-facing polygon and all plasma basis nodes inside, so polygon containment is the complete, physical coil/plasma separation (the earlier distance-based exclusion hack is retired).

§5.2 — Data path: three real P0 defects, fixed

  • The anchored "Ip" was the TF current. A hard-coded column index hit tf_current in the alphabetically-sorted amc list; plasma_current lives two columns over. Channels are now resolved by NAME, failing loud when absent.
  • 95% of every shot was silently discarded. The inherited statespace loader drops every slice whose Dα target is NaN — collapsing shot 18502 from ~400 usable slices to 27 spanning 26 ms. A target-free loader now recovers the full plasma (397 slices, genuine Ip 157–782 kA).
  • Imputed sensor values entered the GS residual as measurements. The old loader mean-imputes missing features before returning, so finiteness masks passed everything. Masks now derive from the pre-fill raw array.

The gate-2 numbers in §4 were measured on that broken slice set; the honest-negative conclusion survives (the training-free linear inverse still cannot beat the mean) but the measurement itself is superseded by §5.4.

§5.3 — The ψ representation: the linear basis is structurally incapable

Prototyping on repaired data showed the deeper problem: with the current spread over the whole vessel by ANY linear low-DOF inverse, the total ψ (plasma + coils) has no interior O-point at all — the coil vertical field dominates a broad, low-peakedness current, so no closed flux region forms. Smoothing the sources does not help, and raising the basis order makes it worse (the measured effective rank of the magnetics is ~5–6). Localisation is inherently nonlinear — current inside the LCFS, LCFS from ψ, ψ from the current — and that fixed point is the Grad-Shafranov equilibrium. The psi-decoder-for-topology decision is therefore locked to the free-boundary GS solve: the pre-authorised fallback of the parent latent-to-psi-representation decision, implemented in imas_ambix/latent/gs_solve.py and validated analytically (manufactured-solution stencil test, vacuum limit against the Green's functions, confined-equilibrium fixed point, static firewall test — the jφ(ψ_N; β0, α) ansatz is a generic parametric family that never sees EFIT).

§5.4 — First force-balanced gate-2 numbers (training-free)

Fitting the two profile parameters per slice against the measured magnetics (measured-Ip constraint, known coils) and reading topology from the solved ψ, over the FULL held-out cohort (8 shots × 20 flat-top slices): 83/160 slices scored, median axis error 8.6 cm — versus 39–50 cm for the linear inverse — with 48% of slices honestly masked by the convergence/cost flag (shot 18505 nearly entirely). The distribution is heavy-tailed (mean 0.32 m): the cost limit admits some poor equilibria, and skill vs the 4-cm clustered train-mean remains negative (axis −14.7, X-set −3.3). The levers, in order: a tighter cost threshold (reporting the accuracy/coverage trade both ways), continuous (β0, α) optimisation + vertical-position freedom instead of the 10-candidate grid, passive/eddy currents in the solve (the earlier GS-prior work's early-ramp lesson), and above all the LEARNED encoder amortising this map — now required to consume the stage-1 geometry-aware temporal-window recipe that set the oracle bar, not the flat single-slice MLP it had. That learned measurement is the actual gate-2 design and the open work of f-ggl-02.

Review completion: the adversarial code review delivered late but in full, independently confirming the root-cause chain (point-filament singularities × the un-localisable linear basis × the plasma-only-ψ read) and adding three defects fixed immediately: the corpus trainer had no gradient clipping or non-finite-loss guard (one poisoned batch would silently corrupt the SHARED encoder for every campaign — now clipped, skipped and counted), the axis reader fell back to out-of-vessel O-points when none lay inside the limiter (now honestly None), and checkpoint resume lacked a device map (risky under SLURM's variable GPU indexing). The docs review pinned the exact encoder recipe the learned gate-2 path must adopt: the stage-1 probe that set the 0.59/0.82 bar is a space-time transformer with one token per (stream, sensor, time-step), per-sensor (R,Z,φ,orientation) geometry as positional encoding (tokenizer/geometry_reader.py), machine-frame context tokens (gs/geometry_export.py), attention pooling, and CONTINUOUS values — per-shot quantisation independently costs ~2–3× skill.

§6 — Honest limits & the path to close gate 2

The GS-observation grounding (the differentiable ψ→magnetics anchor and its residual) is sound and is the durable asset. The weak link is reading a precise magnetic axis from a linear least-squares GS-inverse ψ, which is not a force-balanced equilibrium. Three complementary routes, in order of expected payoff:

  1. The learned latent, trained on the corpus (the plan's actual design, not the training-free inverse used here as a lower bound). The anchored block already carries Ip/n_e; training across the corpus regularises θ and the readout, and the belief gives calibrated uncertainty where the axis is under-determined.
  2. A richer, force-balanced ψ representation — a genuine (differentiable) Grad-Shafranov solve for ψ given the current profile, rather than a linear current-basis inverse, so the reconstructed ψ is a true equilibrium with a well-defined O-point.
  3. Score the readout where it is informative — the GS residual and flux-diffusion residual as discovery signals, and per-quantity calibration, rather than a single clustered-axis skill number that a mean predictor dominates.

The transport temporal anchor (D≥0, command-driven, guard-railed) and the whole differentiable engine are ready to carry that training.
