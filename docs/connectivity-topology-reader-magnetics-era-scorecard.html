Research findings for connectivity-topology-reader (followup f-ctr-15), resolving the pin/prior confound left open by the production-spine census (engine-crossval RCA §11). The census could not separate "the centroid pin is worse than the plain spine" from "the pin faithfully propagates a corrupted late-campaign magnetics datum" — the two are observationally identical on a plasma-inversion metric. This work characterises the instrument itself, per era, with no plasma and no EFIT, and routes the verdict.

Method guidance is taken from Hole, Pinches, Vayakis, McIntosh, Hoenen & Paulo, Disambiguation of magnetic sensors in ITER (submitted to PPCF): a magnetic sensor's identity, ordering and polarity form a signed assignment problem solved by the Hungarian algorithm in O(N³), with a confidence metric C = 1 − ε₁/ε₂ (best vs next-best assignment cost) that measures robustness independently of fit quality, and the key result that multiple independent field realisations break the sign/permutation degeneracy that a single field admits. We apply that framework directly to the MAST archive below.

TL;DR

1 — Method: a plasma-free, EFIT-free, common-mode-cancelling scorecard

On a coil-only (vacuum) interval there is no plasma and no inversion; the measured magnetics are linear in the known coil currents,

so every sensor channel s is scored against the geometry-only finite-area cylinder Green's model G_model = fwd.g_pf (cylinder-sensors-v5), with no EFIT and no plasma inversion anywhere. Vacuum fits are leakage-free by construction, so all shots are pooled. Coil-only slices come from two sources: dedicated coil-only shots (plasma never forms) and the pre-breakdown / post-quench windows of plasma shots (|Ip| below 20 kA and the loader's plasma-on flag false).

The frozen model is the lever, not a liability. The geometry / operator layer is frozen per efm signature — one signature covers essentially the entire late archive (12533–30473). So the model response is identical in every era. A per-channel affine fit meass ≈ gains·preds + offsets (robust, one 3σ clip; bootstrap over shots, the correlated unit) therefore carries a common-mode component (the coil model's own known errors, e.g. the 8.25 % solenoid scale) that is the same in every era. Differencing a channel's gain between eras cancels that common mode and isolates the genuine per-channel change:

  • gain ≠ 1 (per era) — effective-area / turns / calibration error;
  • gain < 0 — a polarity (wiring) inversion;
  • offset ≠ 0 — integrator / baseline drift;
  • Δgain across eras, CI-clear of zero — a genuine instrument change (drift, rewire, or relocation) at that channel.

The eras are the documented machine boundaries (M5 11695–14707, M6 14708–19030, M7 19031–25403 [12 in-vessel RMP coils], M8 25404–28389 [RMP set 12→18], M9 28390–30473), i.e. the physical structure the ad-hoc shot 23000 split approximates.

4 — An L1 data-layer finding: late-campaign pickup probes have no vacuum data

The scorecard exposed a caution the L1/L2 structure of this archive imposes. In M9 (>28390), the coil-only windows carry data for the flux loops (fl_*) only — every B-field pickup probe (ccbv*/obr*/obv*) is NaN across the vacuum interval, while the coil currents themselves are fully healthy. The channels are present in the archive (the completeness audit counts them), but the pickup probes are populated plasma-on only in the latest campaign. Two consequences:

  • Vacuum characterisation of the pickup probes is impossible in M9; only flux loops can be scored there. This is a property of the archived L1 signal, not of the method.
  • M5–M8 retain full pickup-probe vacuum coverage — and M5–M8 span the entire confound-critical band (>23000 is mid-M7 onward), so the pin/prior verdict below rests on eras with complete sensor coverage.

5 — Channel-completeness audit: where the erosion goes

Three sequential gates erode the working sensor set: (1) an archived amb column must map to an efm geometry position within 5 cm (else it is unmatched and dropped); (2) the mapped channel must appear in the 73-channel feature schema (else it is never ingested); (3) the channel must carry finite data in the shot. The audit diffs the archived L1 inventory against the mapped geometry set against the measured schema set, per era.

6 — Sensor disambiguation by signed assignment (Hole et al.)

We apply the paper's framework to detect rewiring and polarity. For each era, each channel's empirical response vector rs across the identifiable independent fields is matched against the Green's columns fp of every catalogued sensor position by a signed assignment (Hungarian / scipy.linear_sum_assignment), with per-row confidence C = 1 − ε₁/ε₂. The independent fields are the separable singleton coils plus the summed field of each series-coupled PF pair (the strong, spatially-structured drivers). A best-fit at a different catalogued position is a rewire/swap candidate; a sign inversion is a polarity candidate; C reports whether the call is robust or degenerate.

Validation against the paper. The implementation reproduces Hole et al.'s synthetic tests exactly: a single degenerate coil cos(πk/N) gives 0/20 recovered with C ≈ 0 (their Fig 7), three independent coils give 100 % recovery with C ≈ 1 (Fig 8), and correct sorting holds down to a signal-to-noise ratio 1/η ≈ 20 (Fig 9).

MAST result: uniformly degenerate. Across every era the median confidence is 0.002–0.09 — far below the paper's already-degenerate second-wall case (C > 0.15) — with zero confident swaps and zero polarity flips. The assignment is not wrong so much as uninformative: the axisymmetric PF fields give sensors at similar poloidal angles near-identical response vectors, so identity cannot be pinned. (M9 degrades further to a 73-channel drop-out, the flux-loop-only regime of §4.) This is a clean negative result: the drift scorecard, not the signed-assignment, is the workable instrument on the archive as it stands.

Why this is the expected regime. The paper's high-confidence ITER result (C > 0.97) comes from toroidally localised active coils (the RMP/correction coils) that give each sensor a spatially distinct signature. MAST archived vacuum commissioning energises only the axisymmetric PF coils, whose fields are toroidally uniform and poloidally smooth, so many sensors at similar poloidal angles have near-identical response vectors — the paper's degenerate second-wall regime (C > 0.15), or worse. The recommendation follows the paper's own: dedicated vacuum discharges energising toroidally asymmetric coils would make the MAST-U / ITER sensor set disambiguable; from the MAST archive as it stands, the per-channel gain-drift scorecard is the workable instrument.

7 — Where the disambiguating signal actually lives: three seams for energised in-vessel coils

§6 established that MAST's axisymmetric-PF-only vacuum shots cannot disambiguate the sensor set — the field realisations are too degenerate. The fix the paper points to is toroidally-localised active coils. MAST has them (the in-vessel RMP/ELM coils, the outer saddle coils, and the n=2/n=5 error-field correction coils), and their currents are archived (xma/rog_elm_* ELM/RMP Rogowskis, xmb/sad_out_* outer saddle, xmb/halo_elm_*, xma/hsc* horseshoe, amc/error_field_02/_05). The question is whether any interval has them energised without a confounding plasma or vessel-eddy field. Three seams exist:

  1. Dedicated vacuum shots (peak |Ip| < 50 kA, plasma never forms) with the in-vessel coils pulsed — the whole record is a clean plasma-less interval, exactly the paper's plasma-less commissioning strategy.
  2. Pre-breakdown windows where the n=2/n=5 error-field correction coils (toroidally asymmetric) are already energised. Confirmed present in ordinary shots — error_field_02/05 peak inside the |Ip| < 20 kA vacuum window.
  3. Post-disruption tails — after the current quench and several vessel-current decay times, the plasma is gone and the passive eddy currents have decayed, but the ELM coils can still be powered and swinging. The ELM Rogowski's activity in the eddy-decayed tail, above its pre-shot baseline, flags it. A prototype confirms the seam (e.g. shot 24000: tail ELM-Rogowski activity ≈ 1.7× baseline, versus ≈ 0.3× on non-ringing shots), with the vessel decay gauged from the post-quench fall of the passive case-current channels.

The seams are abundant. A sweep of all 9,802 RMP-era L1 shots (8,967 readable) found 2,074 dedicated-vacuum shots (peak |Ip| < 50 kA), of which 1,957 carry in-vessel-coil channels and 864 have at least one driven >1.0 in raw units (M7 = 474, M8 = 205, M9 = 185). The n=5 error-field correction coil is essentially always energised (error_field_05 median 3.2 across the whole corpus), so seam 2 is pervasive. Representative gold candidates:

These directly enable the paper's high-confidence strategy: the 27394–27560 series in particular steps several distinct in-vessel coils plasma-free, giving each sensor a toroidally-structured signature. Curating these intervals — and integrating each coil's Rogowski to recover the driving current for the Green's forward model — is the concrete route from the degenerate C ≈ 0.03 of §6 toward the paper's C > 0.97. The post-disruption tail (seam 3) adds further intervals inside plasma shots. This is captured as the dedicated-disambiguation follow-on.

Why this matters. A single dedicated vacuum discharge that steps each in-vessel coil individually would give every sensor a spatially distinct, toroidally-structured signature — the paper's C > 0.97 regime — and make the MAST sensor set genuinely disambiguable (identity, ordering, polarity), which the archived axisymmetric shots cannot. Capturing and curating these intervals is a high-value, low-cost seam: the data already exist in the archive. Tracked as the dedicated-disambiguation follow-on below.

8 — Verdict: the pin/prior confound

Verdict: PARTIAL — the late-band drift is partly a real magnetics / model-layer degradation, with an identified mechanism; pin/prior retirement stays withheld, but for a now-diagnosed reason.

The census RCA (§11) could not separate "the pin is worse than the plain spine" from "the pin faithfully propagates a corrupted late-campaign datum." The scorecard resolves it: the late-campaign vacuum magnetics do carry a material, spatially-coherent systematic. In the RMP eras, 16 (M7) and 21 (M8) of 65 vacuum-scored channels drift >10 % from their M5 gain (12 >25 % in M8; median 4–5 %, p90 19–37 %), concentrated in a −30 to −50 % gain drop at the fl_p4/p5 flux loops that sit at the in-vessel RMP-coil bay.

Consequences for the pin/prior decision:

  • The pin's target is a current centroid — a linear moment of exactly these magnetics — so a coherent P4/P5 loop bias maps directly into a centroid displacement the pin then enforces with weight (σ = 2 cm). "Pin worse than spine" and "pin amplifies a data-layer bias" are, as the RCA suspected, the same observation on that census. The census cannot license retiring the pin — confound confirmed.
  • But the mechanism is unmodelled RMP hardware, not a miswired or dead sensor layer (0 confident swaps/flips; the drift is a clean gain change at high correlation). The correct remediation is therefore to model the RMP conductors / correct-or-exclude the flagged P4/P5 loops and re-score — not to retire physics the pin and diffusion prior legitimately carry.
  • Confirmatory next step (engine, not scorecard): re-score the late-band census subset with the flagged loops down-weighted/excluded and check whether the >23000 axis displacement contracts. This is the paired re-score the firewall-clean scorecard motivates but cannot itself run.

Caveat. The scorecard pools all coil-only slices, so on ramps the P4/P5 drop mixes a genuine effective-response change with unmodelled RMP eddy (both are model/data-layer, both corrupt the pin, but they are distinct roots); a quasi-static-gated re-fit would separate them.

8 — Follow-on: when and how to pivot to an IMAS-DD-backed translation

This work makes the case for the pivot concrete. The root difficulty the scorecard kept hitting is that the machine description does not travel with the data: geometry descends from a frozen pre-2004 detectors.dat_M4, channel identity and polarity are implicit in names, calibration lives in code constants, and the archive itself mixes formats (L1 = Zarr V2, L2 = Zarr V3). The IMAS Data Dictionary already has a canonical, versioned home for every quantity this scorecard produces.

When

The pivot trigger is now, at the same seam as the machine-configuration-map registry (f-mcm-01). The registry's job — an era-aware, machine-checkable record of geometry, wiring, and channel state — is exactly what the DD magnetics / pf_active / pf_passive IDSs are for. Building a bespoke JSON registry and later translating to the DD is duplicated effort; the moment we need per-era geometry that travels with the data and a wiring/polarity provenance record (i.e. this deliverable), the DD translation is the registry, and it buys cross-machine transfer (MAST → MAST-U → ITER) for free.

How — and the L1/L2 caution

  • Translate L1 only into the measured IDSs. Raw pickup probes and flux loops (amb) → magnetics (b_field_pol_probe, flux_loop, rogowski_coil, ip); coil currents (amc) → pf_active; vessel/case passive currents (amm) → pf_passive. Keep L2 (EFIT) as the equilibrium IDS referee — separate IDS, firewalled. The DD's measured-vs-reconstructed split enforces our firewall structurally, which the flat zarr layout does not.
  • Geometry travels with the data. b_field_pol_probe/position (R,Z,φ), /poloidal_angle, /toroidal_angle and flux_loop/position carry the per-era sensor geometry the frozen table cannot express — this is the era-aware geometry table the machine-configuration-map plan wants, but in a standard schema.
  • The scorecard outputs become DD metadata. Per-channel gain/offset → the probe's calibration and non_linear_response/b_field_linear; flagged polarity inversions → the sign of the orientation; rewire/relocation candidates → b_field_pol_probe_equivalent (the DD's own equivalent-probe / wiring record). The disambiguation result has a native home.
  • Version discipline (AGENTS.md). Write via imas.DBEntry with an explicit dd_version — MAST is legacy-era data, so pin a DDv3 minor that carries the probe geometry fields (b_field_pol_probe/position is DD 3.24.0+); never default to the latest, which would silently up-convert. One DBEntry per shot, read with imas-python throughout (never h5py).

Recommended sequencing: a thin L1→magnetics/pf_active per-era geometry writer first (low risk, no time-series), validated against the efm-derived table; then populate the measured time-series and fold in the scorecard calibration; then retire the frozen-table code path in favour of the IDS.
