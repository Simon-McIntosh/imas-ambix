How it works

  1. Each decision row above lists its owning plan page.
  2. Open that page and click an option in its Open Decisions section — the choice writes to ~/docs-server/state/imas-ambix/<plan>.json.
  3. Return here (or click Refresh from server) to see the current choice live.
  4. Agents read the same JSON files directly from the filesystem at ~/docs-server/state/imas-ambix/ — humans and agents share one source of truth.

Per-stage landed records (e.g. tokenizers-12-landed.html) have their own separate state files; this aggregator reads the evergreen plan pages only.
