Execution home for v0 stage 4 — the goal gate. Full design, figures (Fig 7 validation honesty hierarchy), glossary, and locked decisions are in the parent machine-agnostic-latent-world-model (§9, §10, §11). Depends on stage 3 (the closed-loop engine). This is the stage that decides whether the redesign delivered controllable dreams.

§1 — Objective & scope

Train the stage-3 closed-loop engine at scale on the full v0 modality set — magnetics + plan + interferometer + SXR + all five cameras + HF signals — excitation-curated (up-weight / preferentially sample windows with genuine actuator excitation: coil ramps, |dI/dt| transients, plan changes, ramp-up/down), with the observation-withholding schedule so filter and forecast train jointly. Then run the honesty-spine evaluation: the powered controllability gate on excited held-out windows, and raw-held-out prediction against persistence + the EnKF bar. EFIT stays the firewalled referee.

§2 — The gate (verifiable done-when)

  1. Trained checkpoint on the full v0 modality set; excitation-curated + observation-withholding.
  2. Powered ΔN-M controllability gate PASSES on excited held-out windows — the true plan moves the latent more than a random plan, CI clear of the noise floor (n=10). This is the bar the prior camera/RSSM work failed. Report ratio + CI + pass-fraction.
  3. Raw-held-out signal prediction beats persistence AND the EnKF current-recovery bar — report per-modality (the strong tier of the validation honesty hierarchy: predict raw observables the model never saw).
  4. Honest controlled-vs-stochastic decomposition + interior-current under-determination reported (calibrated "I don't know" where the data cannot pin it); predict-vs-reality figure(s); plan collapsed.

§3 — Approach

  1. Excitation-window selector: score windows by actuator excitation (|dI/dt|, coil ramps, plan changes); curate / re-weight the training distribution so the command is necessary, breaking the causal-under-identification confound that defeated the flat-top-dominated prior runs.
  2. Full multi-modal DDP training of the closed-loop engine; observation-withholding schedule; frequent checkpoints + clean SIGTERM (resume-safe; coexist with DeepSeek per AGENTS.md).
  3. Controllability gate: the powered n=10 ΔN-M on the latent (not brightness), on excited held-out windows; collapse-rejecting; bootstrap CI.
  4. Raw-held-out eval: predict withheld raw observables (held-out probes; MSE on beam-on slices) vs persistence + the EnKF bar; the firewalled EFIT referee as a weak agreement cross-check only.

§4 — H200 footprint

Heaviest H200 consumer of the v0 sprint. Full multi-modal corpus training (all five cameras + magnetics + interferometer + SXR + HF + plan) is a multi-GPU DDP run — the 6-GPU burst that coexists with the 2-card DeepSeek serve (6+2 = 8/8), per AGENTS.md §1/§2. CPU-sizing caveat: probe with srun --test-only first (~12 schedulable cores while the serve co-runs). Resume-safe, frequent latest.pt, clean SIGTERM (< 5 s) so a give-back costs nothing. The controllability-gate rollouts + raw-held-out eval are lighter (rollout-bound). Plan the big run for fast takedown.

§5 — Inherited decisions

Locked in the parent: v0-modality-scope = magnetics+plan+interferometer+SXR+all-5-cameras+HF; firewall-definition = code-outputs-only (EFIT = referee, never training). Excitation-curation + observation-withholding are the locked training approach (parent §9). No new architectural decisions here.
