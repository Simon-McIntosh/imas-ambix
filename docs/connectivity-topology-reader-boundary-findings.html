Scope. This document records the build and gate of the GPU-native connectivity boundary read (imas_ambix/latent/connectivity_boundary.py), §2 of the connectivity-topology-reader plan. It states plainly what landed, the three gate verdicts (all PASS), the RCA of a systematic boundary-size bias that was found and fixed, and what the read unblocks. All figures are on held-out MAST slices or self-contained synthetic fields; EFIT is never an input.

§1 — The problem: the one GPU-hostile step

The topology read — magnetic axis, X-point(s), LCFS/boundary, core mask — is the single data-dependent step in the batched equilibrium engine, and the place EFIT-class reconstructors sink into a contour-tree / critical-point-classification tar pit. Ported verbatim to a GPU it re-serialises the whole rollout: host round-trips, argwhere loops, union-find connected components, variable-count nulls.

We already resolve the LCFS by connectivity, not stationary-point classification (the shipped topology.lcfs_contour, used as the frozen-spine push-out boundary): the boundary is the outermost closed, axis-enclosing flux contour that still lies inside the wall, found by ONE monotone flux-offset push — continuous through the marginal limited↔diverted transition by construction, because the read never decides which surface bounds; it finds where the axis-connected region stops being closed inside the wall. The algorithm is validated; the implementation used the GPU-hostile primitives (contourpy, a bisection over traced contours). §2 re-expresses the SAME algorithm on-device.

§2 — Method: flood-fill + level sweep + two-sided binding level

The device kernel (boundary_read_jax) is a fixed-shape reduction over the grid — no contour extraction, no host round-trip:

  • Normalised flux. u = (ψ − ψ_axis)/(ψ_out − ψ_axis) maps the axis to 0 and the domain-edge extreme to 1, so the confined side at a candidate level s is simply u ≤ s (sign-agnostic).
  • Axis-connected region. At each level the confined-and-in-wall set is flood-filled from the axis cell by iterated 4-neighbour dilation (the shipped flood_fill_core device kernel from the contour-free FSA) — the axis-connected component, never a disconnected pocket.
  • The binding level, split by connectivity signature. A level is valid while the axis region stays clear of the wall; each escape transition is the largest valid level (monotone → coarse sweep + bisection). ψ_bnd is read at the mean of an inner and an outer escape test — unbiased for an interior SADDLE, so a DIVERTED separatrix lands on the X-point (ψ_N = 1). A LIMITED wall tangency is refined sub-grid: the minimum interpolated ψ_N over the wall boundary points adjacent to the axis region. Limited and diverted are told apart by the region size jump across the binding — a saddle opening merges the region with the SOL/private flux and jumps its size, a tangency grows smoothly — so the sub-grid wall read is applied only to limited plasmas (on a diverted plasma the nearest wall sits outside the separatrix and a min-over-wall would overshoot). See §3a.
  • LCFS radii. Read a hair inside the separatrix by an outward ray-march at the evaluator's 8 poloidal angles — a differentiable interpolated crossing (the same fixed parameterisation the host uses). A ray at exactly ψ_bnd would run down an open divertor leg, so the ray surface is clamped a hair inside; the closed lobe is unaffected.

The only machine input is the wall as a raster boolean mask, so a single loop (MAST), a union of discrete limiters (AUG), or a per-pulse movable wall (WEST) is data, not a new code path — the §4 abstraction is already in place. Everything is jit / vmap / grad-safe.

§3 — Reproduction on held-out MAST slices (T-B1) — PASS

On 36 held-out slices (6 shots × 6 slices; 18 diverted, 18 limited) the device flood-fill read is compared against the host lcfs_contour (the disc-pushout reference, clip_legs=True) on the SAME disc ψ field, axis, and wall mask.

§3a — RCA: a systematic boundary-size bias, found and fixed in two steps

The first device read used a single escape test — the axis region touches the innermost in-wall shell (cells one step inside the wall). That test fires ~one grid cell inside the true wall crossing / saddle, so ψ_bnd came out biased toward the axis and the boundary came out consistently too small: on the 36 real slices the ψ_bnd scatter sat entirely on one side of y = x (median 3.7%).

Step 1 — two-sided mean. Reading ψ_bnd at the mean of the inner escape test and an outer test (dilating the region reaches a still-confined cell outside the wall / on the domain edge, ~one cell outside) removes the sign for the interior-saddle binding: the two brackets straddle a saddle symmetrically, so a DIVERTED separatrix reproduces to +0.4% (lands on ψ_N = 1). But a LIMITED wall tangency's brackets straddle the WALL, whose sub-cell position is not the mean's implicit half-cell, so limited stayed +2.4% too small — all 18 limited points still above y = x.

Step 2 — sub-grid wall tangency for limited only. The limited binding is, by definition, the confined-most flux the closed surface reaches on the wall, so it is read sub-grid as the minimum interpolated ψ_N over the wall boundary points adjacent to the axis region (coil-perturbed and far-wall points excluded by the reachability). Applied indiscriminately this would overshoot a diverted plasma — whose closed lobe's nearest wall sits outside the separatrix — so limited and diverted are separated by the region size ratio across the binding: a saddle opening merges the axis region with the SOL/private flux and jumps its size (~1.4–1.8), a wall tangency grows smoothly (~1.2). The sub-grid read is applied only to the low-jump (limited) class.

Result. Both classes now sit on y = x with scatter either side — limited signed median −0.01% (range [−0.02%, +1.97%]), diverted +0.43%; the radius error dropped from 2.55 cm to 0.09 cm median (limited 0.06 cm), and ψ_bnd to 0.02% of span. Everything stays fixed-shape jnp (flood + interpolated wall min + reductions) — jit/vmap-portable to the GPU, and ψ_bnd differentiable.

§4 — On-device and batchable (T-B2) — PASS

A batch of the six slices sharing one campaign grid runs as a single jax.vmap with fixed shapes, byte-parity with the per-slice read (allclose at 1e-9). The module imports no contourpy, no scipy.ndimage, and calls no argwhere / label (AST-audited). Throughput on CPU: 46 ms/slice batched vs 58 ms/slice looped — and the identical code runs on the GPU whenever a CUDA jaxlib is present (device chosen by the installed jaxlib, not the code), exactly the inner-loop the corpus labeller needs.

§5 — Continuity through the marginal transition (T-B3) — PASS

This is the ill-conditioned case classify-first pipelines fail: a marginal plasma looks identical in flux space, so the height-gate / mode decision jumps. The connectivity read never makes that decision, so ψ_bnd is continuous by construction — the property the differentiable rollout depends on.

§6 — What this unblocks

The read is now doubly load-bearing:

  • Batched GPU throughput (gpu-accelerated-labeler): the boundary half of the on-device topology read is a single vmap over slices sharing one grid — no host contour extraction re-serialising the rollout.
  • The differentiable-solve retest (differentiable-solve-accelerator): the hard-threshold host topology step made the free-boundary map non-differentiable, corrupting Newton–Krylov's Jacobian and Anderson's history. A flood-fill boundary that is continuous through the marginal transition, unbiased in ψ_bnd, and carries a finite jax.grad (verified) is the smooth map those schemes need.
