Scope. This document records the build and gate of the GPU-native connectivity boundary read (imas_ambix/latent/connectivity_boundary.py), §2 of the connectivity-topology-reader plan. It states plainly what landed, the honest gate verdicts (including one qualified pass), and what the read unblocks. All figures are on held-out MAST slices or self-contained synthetic fields; EFIT is never an input.

§1 — The problem: the one GPU-hostile step

The topology read — magnetic axis, X-point(s), LCFS/boundary, core mask — is the single data-dependent step in the batched equilibrium engine, and the place EFIT-class reconstructors sink into a contour-tree / critical-point-classification tar pit. Ported verbatim to a GPU it re-serialises the whole rollout: host round-trips, argwhere loops, union-find connected components, variable-count nulls.

We already resolve the LCFS by connectivity, not stationary-point classification (the shipped topology.lcfs_contour, used as the frozen-spine push-out boundary): the boundary is the outermost closed, axis-enclosing flux contour that still lies inside the wall, found by ONE monotone flux-offset push — continuous through the marginal limited↔diverted transition by construction, because the read never decides which surface bounds; it finds where the axis-connected region stops being closed inside the wall. The algorithm is validated; the implementation used the GPU-hostile primitives (contourpy, a bisection over traced contours). §2 re-expresses the SAME algorithm on-device.

§2 — Method: flood-fill + level sweep + bisection

The device kernel (boundary_read_jax) is a fixed-shape reduction over the grid — no contour extraction, no host round-trip:

  • Normalised flux. u = (ψ − ψ_axis)/(ψ_out − ψ_axis) maps the axis to 0 and the domain-edge extreme to 1, so the confined side at a candidate level s is simply u ≤ s (sign-agnostic).
  • Axis-connected region. At each level the confined-and-in-wall set is flood-filled from the axis cell by iterated 4-neighbour dilation (the shipped flood_fill_core device kernel from the contour-free FSA) — the axis-connected component, never a disconnected pocket.
  • The binding level = the connectivity change. A level is valid while the axis region stays clear of the wall boundary; it becomes invalid the instant the region first reaches the wall — a flux surface going tangent to the wall (LIMITED) or opening through an X-point so the scrape-off connects to the divertor/wall (DIVERTED). This predicate is monotone in s, so ψ_bnd is the largest valid level, found by a fixed coarse sweep bracketing the transition + a fixed-count bisection.
  • LCFS radii. Read a hair inside the separatrix by an outward ray-march at the evaluator's 8 poloidal angles — a differentiable interpolated crossing (the same fixed parameterisation the host uses).

The only machine input is the wall as a raster boolean mask, so a single loop (MAST), a union of discrete limiters (AUG), or a per-pulse movable wall (WEST) is data, not a new code path — the §4 abstraction is already in place. Everything is jit / vmap / grad-safe.

§3 — Reproduction on held-out MAST slices (T-B1)

On 36 held-out slices (6 shots × 6 slices; 18 diverted, 18 limited) the device flood-fill read is compared against the host lcfs_contour (the disc-pushout reference, clip_legs=True) on the SAME disc ψ field, axis, and wall mask.

Verdict — QUALIFIED. The LCFS radii — the boundary geometry the evaluator actually scores — reproduce the host to 2.55 cm median (bar 3.0 cm; diverted 0.82 cm, limited 2.70 cm, p90 max-radius 3.98 cm): the connectivity boundary the device finds is the same boundary the host finds. The scalar ψ_bnd reproduces to 3.7% of the axis→boundary flux span (median; p90 6.2%), just over the self-declared 3% bar — the O(Δψ) binding-cell grid floor that caution (i) of the plan named in advance (on a fine synthetic grid the same read matches ψ_bnd to 0.03%; the coarse 65×97 campaign grid quantises the binding saddle / wall-tangency). The sub-grid ψ_bnd polish is nova's select.subnull quadratic refinement — the explicit deliverable of §3, which locates that null sub-grid anyway. This is a reproduction of the connectivity boundary, not a looser or host-bound read (see T-B2), so it is a qualified pass rather than a stop.

§4 — On-device and batchable (T-B2) — PASS

A batch of the six slices sharing one campaign grid runs as a single jax.vmap with fixed shapes, byte-parity with the per-slice read (allclose at 1e-9). The module imports no contourpy, no scipy.ndimage, and calls no argwhere / label (AST-audited). Throughput on CPU: 41 ms/slice batched vs 52 ms/slice looped — and the identical code runs on the GPU whenever a CUDA jaxlib is present (device chosen by the installed jaxlib, not the code), exactly the inner-loop the corpus labeller needs.

§5 — Continuity through the marginal transition (T-B3) — PASS

This is the ill-conditioned case classify-first pipelines fail: a marginal plasma looks identical in flux space, so the height-gate / mode decision jumps. The connectivity read never makes that decision, so ψ_bnd is continuous by construction — the property the differentiable rollout depends on.

§6 — What this unblocks

The read is now doubly load-bearing:

  • Batched GPU throughput (gpu-accelerated-labeler): the boundary half of the on-device topology read is a single vmap over slices sharing one grid — no host contour extraction re-serialising the rollout.
  • The differentiable-solve retest (differentiable-solve-accelerator): the hard-threshold host topology step made the free-boundary map non-differentiable, corrupting Newton–Krylov's Jacobian and Anderson's history. A flood-fill boundary that is continuous through the marginal transition and carries a finite jax.grad (verified) is the smooth map those schemes need. Note: the scalar ψ_bnd is presently grid-quantised; the §3 sub-grid subnull polish makes it smoothly differentiable, which is the form NK/Anderson require.
